# 全文搜索完整性分析报告（分词/范围/过滤）

## 1. 功能概述
- 定位：对笔记、知识节点/边、附件文本等进行关键词匹配与字段过滤，返回分页排序结果。
- 场景：在标题/正文/标签/分类/时间范围内检索；支持按模块（笔记/知识/社区）范围与过滤。
- 关联：向量检索融合排序、建议与历史、知识图谱搜索、权限与可见性过滤。

## 2. 前端实现分析
- 关键路径：
  - 组件：`src/components/search/SearchResults.js`（主题修复，结果渲染）；
  - 屏幕：`src/screens/search/*`（搜索入口与结果页）；
  - 服务：`src/services/search/*`（API封装）
  - 配置：`src/config/api.js` → `API_ENDPOINTS.SEARCH.TEXT`、`ADVANCED`、`TAGS`；
  - 测试：`src/tests/test_search_api.js`, `src/tests/markdownFeatures.test.js`（相关性）
- 交互：
  - 输入框→debounce→调用后端→显示分页；
  - 过滤：模块/时间范围/标签/分类；
  - 高亮命中：标题/摘要中标注命中词（建议）；
- 状态管理：
  - 查询参数、页码、排序方式持久化；
  - 最近查询缓存与历史列表。
- 主题一致性：
  - 颜色/字体/间距与全局一致（已修复 theme 引用错误）。
- 问题清单（前端）：
  - 需确认：过滤器 UI 是否覆盖模块/时间/标签；
  - 需确认：高亮命中是否统一实现；
  - 需确认：空结果建议（热门/最近）。

## 3. 后端实现分析
- 端点（`backend/search/urls.py`）：
  - `GET /search/text/`（关键词）
  - `GET /search/advanced/`（结构化过滤）
  - `GET /search/tags/`、`/search/history/`、`/search/clear-history/`
- 服务：`backend/search/services/indexer_service.py`（统一 ODM，关键词索引）、`backend/search/services/search_service.py`（格式化/排序）、`backend/search/mongodb_models.py`（索引记录）
- 业务与边界：
  - 字段白名单：title, content, tags, category, created_at, updated_at；
  - 分词策略：中文分词（需确认 ES/结巴/自实现）；
  - 权限过滤：按 user 与可见性；
  - 分页与排序白名单与上限（page_size≤100）；
- 问题清单（后端）：
  - 分词器与多语言支持；
  - 属性过滤的类型校验；
  - 热词统计与缓存。

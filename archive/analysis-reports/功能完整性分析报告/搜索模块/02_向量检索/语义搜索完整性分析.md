# 语义搜索完整性分析报告（嵌入/候选集预筛）

## 1. 功能概述
- 定位：基于文本向量（Sentence Transformers/Embedding API）计算相似度，实现“语义相关”搜索与召回；与全文检索融合排序。
- 场景：查询语义接近但非关键词匹配的内容；跨语言/同义表达检索；知识图谱节点的相似发现。
- 关联：
  - 全文搜索：关键词与语义结果融合排序；
  - 知识图谱：相似节点/相似笔记构建 related_to 边；
  - AI助手：向量召回支持上下文增强。

## 2. 前端实现分析
- 代码路径：
  - 组件：`src/components/search/SearchResults.js`（统一结果渲染/打分展示）；
  - 服务：`src/services/search/*`（建议新增 `semanticSearch(text, filters)`）；
  - 配置：`src/config/api.js` → `API_ENDPOINTS.SEARCH.SEMANTIC`；
- 交互：
  - 切换“语义”开关或自动融合；
  - 显示相似度分数/来源（语义/关键词）；
- 问题清单（前端）：
  - 需确认：融合排序展示与权重可调；
  - 需确认：过滤器与分页策略与全文保持一致。

## 3. 后端实现分析
- 端点：`backend/search/urls.py` → `GET /search/semantic/`
- 服务：`backend/search/services/vector_service.py`（向量器单例/维度校验/词表持久化）、`search_service.py`（融合/阈值/候选预筛）
- 业务：
  - 预筛：先按关键词/标签/时间范围生成候选集（≤1000），再计算相似度；
  - 阈值：`similarity >= t` 才计入；TopK 限制；
  - 融合：BM25 与 cosine 相似度线性归一化 + 权重合成；
- 问题清单（后端）：
  - 维度漂移/模型版本升级的重建；
  - 多语言与域专用模型；
  - 缓存策略（query 缓存/倒排索引 + 向量缓存）。

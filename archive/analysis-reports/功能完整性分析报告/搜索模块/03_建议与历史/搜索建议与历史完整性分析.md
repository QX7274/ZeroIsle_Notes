# 搜索建议与历史完整性分析报告

## 1. 功能概述
- 定位：基于用户输入与历史行为给出实时建议（补全/热词/近义）并记录搜索历史用于个性化与统计。
- 场景：输入联想、常用查询快捷复用、按最近/热门排序的推荐。
- 关联：全文/语义检索、知识图谱搜索入口、限流与安全（脱敏、清理）。

## 2. 前端实现分析
- 路径：
  - 组件：`src/components/search/*`（输入框与建议下拉，`SearchResults.js` 结果页）
  - 服务：`src/services/search/*`（`getSuggestions`, `getHistory`, `clearHistory`）
  - 配置：`src/config/api.js` → `API_ENDPOINTS.SEARCH.SUGGESTIONS`, `HISTORY`, `CLEAR_HISTORY`
- 交互：
  - 输入 debounce（300ms）→ 请求建议 → 展示候选（热词/历史/匹配项）；
  - 点击候选或回车 → 跳转结果页并写入历史；
  - 管理：清空历史、置顶常用。
- 状态：
  - 本地缓存最近N条；
  - 主题：下拉/Chip/列表项风格统一。
- 问题清单（前端）：
  - 需确认：多来源建议（历史/热词/标签/知识图谱节点名）融合与排序；
  - 需确认：隐私模式与脱敏展示（不显示私密关键词）。

## 3. 后端实现分析
- 端点：`backend/search/urls.py` → `/search/suggestions/`, `/search/history/`, `/search/clear-history/`
- 服务：`backend/search/services/search_service.py`（建议生成、历史写入/清理）、`backend/search/mongodb_models.py`（历史/热词）
- 业务：
  - 建议来源：最近查询、热门、标签/分类词表、知识图谱节点标签（阈值过滤）；
  - 融合排序：权重 = recency×α + popularity×β + prefixScore×γ；
  - 历史：保存 user、query、ts；清理与上限；
  - 隐私与脱敏：标记敏感词不计入热门；
- 问题清单（后端）：
  - 限流与防刷（同IP/同user）；
  - 脱敏规则与黑名单；
  - GDPR 删除请求（清除历史）。

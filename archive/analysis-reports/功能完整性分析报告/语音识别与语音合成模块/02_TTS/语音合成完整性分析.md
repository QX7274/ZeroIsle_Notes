# 语音合成（TTS）完整性分析报告（声音/语速/进度回调）

## 1. 功能概述（定位/场景/模块关联）
- 定位：将文本转换为语音并在端侧播放，支持语言/声音/语速/音调参数与进度回调；为 AI 回复朗读、无障碍与出行场景提供听读能力。
- 场景：朗读 AI 答复、笔记听读、无障碍阅读。
- 关联：AI 助手（消息朗读入口）、笔记管理（正文朗读）、通知（错误提示）。

## 2. 前端实现分析（UI组件/交互/状态/主题/问题）
- 代码路径：`src/services/tts/ttsService.js`
  - 初始化：`Tts.getInitStatus()`（Android）、`Tts.setDefaultLanguage('zh-CN')`、`Tts.setDefaultRate(0.5)`；
  - 事件：`tts-start/tts-finish/tts-cancel/tts-error` 上报；
  - 问题：使用 `Tts.setDefaultVoice` 充当“音量”设置（应改为选择具体 voice；音量通常走系统或平台 API）；注释存在编码异常（如“语�?”），需修复为 UTF-8。
- UI与交互（建议落地）：
  - 在 `ChatMessage` 与笔记阅读视图的“更多操作”中加入“朗读/停止”；
  - 朗读设置面板：语言、语速、音调、声音；
  - 进度可视化（句子/段落高亮）可选。
- 状态：
  - 当前 voice/语言/语速的持久化（Redux/Realm）；
- 主题一致性：按钮/底部面板与主题色/圆角/阴影一致。

## 3. 后端实现分析
- 端侧 TTS 为主；可选云端 TTS（Edge/Polly）作为兜底：新增 API `/tts/speak` 返回音频流（非必须）。

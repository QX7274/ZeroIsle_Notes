# 语音识别与语音合成模块（Voice/TTS）完整性分析总览

## 1. 模块职责与边界
- 职责：提供语音转文字（ASR/Transcribe）与文字转语音（TTS）能力，支持在线/离线兜底、平台差异适配（iOS/Android）、错误处理与权限引导；服务 AI 对话与笔记输入。
- 边界：
  - 输入：麦克风流/本地音频文件、文本；
  - 输出：识别文本（语言/置信度）、TTS 播放/可选保存；
- 依赖：
  - 前端：ASR（`src/screens/ai/AIAssistantScreen.js` 第268–379行录音/转写上传；`src/services/audio/nativeAudioService`）、TTS（`src/services/tts/ttsService.js`）、通知（错误提示）；
  - 后端：`backend/ai_assistant/legacy_views.py::transcribe_audio`（上传字段名 file）、`backend/ai_assistant/services/whisper_service.py`（OpenAI Whisper 旧接口）；
  - 文档：`AI功能完成度总结.md`（iOS OCR/手写识别差异）、`docs/realm_setup.md`（平台配置）。

## 2. 数据流
1) 语音识别：前端录音→表单上传（multipart）→ WhisperService 转写→ 返回 text/language → 前端回填；失败→本地模块降级或模拟；
2) 语音合成：前端调用 TTS 引擎 → 播放/停止 → 事件回调（开始/结束/错误）。

## 3. 关键代码与端点
- 前端
  - `src/screens/ai/AIAssistantScreen.js`（321–346：formData.append('audio'...)；应改为 'file' 与后端匹配；524 头部图标）
  - `src/services/tts/ttsService.js`（Tts.setDefaultLanguage / setDefaultRate；存在将 setDefaultVoice 当作音量使用的问题）
- 后端
  - `backend/ai_assistant/legacy_views.py::transcribe_audio`（‘file’字段校验、临时文件保存、安全校验）
  - `backend/ai_assistant/services/whisper_service.py`（openai.Audio.transcribe 旧式；建议迁移新SDK）

## 4. 风险与技术债
- 前后端字段不一致（audio vs file）将导致 400；
- Whisper 新旧 SDK 混用；
- Android OCR/本地 ASR 能力未齐；
- TTS 服务未集成到 UI（朗读入口缺失），且存在 API 误用。

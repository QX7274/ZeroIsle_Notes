# 语音识别与语音合成模块 - 模块总结与改进建议

## 总体评估
- 功能覆盖：8/10（ASR 链路完整、TTS 服务具备；UI 集成/参数面板与SDK一致性待完善）
- 代码质量：7.5/10（TTS API 误用与字符编码问题、ASR 新旧SDK混用）
- 契约一致性：7.5/10（转写字段名 audio vs file 不一致，错误码未统一）
- UI一致性：8/10（提示/按钮多数一致，TTS入口与设置面板缺失）
- 错误处理：8.5/10（多级兜底良好，统一提示与重试策略需补）
- 性能优化：8/10（端侧TTS充足；ASR可考虑分段上传/降噪）
- 文档完善度：8/10（需补接入指南/错误码与权限清单）

## 关键问题
- 🔴 转写表单字段不一致导致 400 风险；
- 🔴 Whisper 新旧 SDK 混用；
- 🟡 TTS 未接入 UI，且 `setDefaultVoice` 被当作音量使用；
- 🟢 权限与错误提示的统一拦截与文案。

## 改进建议
- 后端：统一到 OpenAI 新 SDK；错误码与 `Retry-After`；
- 前端：改表单字段为 `file`；新增“朗读/停止”入口与设置面板；修正 TTS API 与注释编码；
- 体验：分段朗读与高亮同步；ASR 权限拦截与重试/设置引导。

## 验收标准
- 转写成功率 ≥ 99%；字段一致性 100%；
- TTS 入口可用，设置面板参数生效；
- 错误码统一，前端提示一致且可重试。

# 安全策略完整性分析报告（密码/风控/审计）

## 1. 功能概述（定位/场景/模块关联）
- 定位：规范密码策略（复杂度/有效期/冻结）、登录风控（限速/验证码/设备识别/IP黑白名单）、审计与告警，保障账号安全与合规。
- 场景：弱口令攻击、撞库、异常登录（异地/非常用设备）、内部越权等。
- 关联：认证与授权（JWT/刷新）、通知（安全告警）、同步/笔记/知识库（权限边界）。

## 2. 前端实现分析（UI组件/交互/状态/主题/问题）
- 路径：
  - 认证UI：`src/screens/auth/*`（登录/注册/重置）
  - 服务：`src/services/auth/*`（密码重置/修改/验证码）
  - 配置：`src/config/api.js` → `API_ENDPOINTS.AUTH.PASSWORD/*`, `SEND_VERIFICATION_CODE`, `VERIFY_RESET_CODE`
- 交互建议：
  - 密码强度提示（强度条/规则说明）；
  - 验证码/二次确认；
  - 异常登录提醒切换与通知渠道配置；
- 问题清单（前端）：
  - 需确认：登录限流提示（429）与验证码触发逻辑；
  - 需确认：设备记住/多端登录管理UI。

## 3. 后端实现分析（API/模型/业务/鉴权/问题）
- 路径：
  - `backend/users/auth.py`, `backend/users/jwt_auth.py`, `backend/users/permissions.py`, `backend/users/views/*`, `backend/users/serializers/*`
  - 验证码/邮件/短信：`backend/users/views/*`（需结合 `API_ENDPOINTS.AUTH.SEND_VERIFICATION_CODE`）
- 业务：
  - 密码：PBKDF2/Bcrypt（项目已引入 `react-native-bcrypt` 端侧；后端 PBKDF2 推荐）复杂度校验、密码历史（防重用）、冷却期；
  - 风控：登录失败次数锁定、验证码阈值、IP/设备黑名单、异常登录告警；
  - 审计：登录/重置/修改密码/绑定解绑的日志（用户、来源IP、设备、时间、结果）。
- 问题清单（后端）：
  - 统一错误码与429返回；
  - 多因子认证（MFA）可选开关；
  - 设备指纹/会话撤销（跨设备登出）。

## 4. 规划一致性检查
- 文档：`Info/安装和部署指南.md`, `Info/开发者总体指南.md`
- 偏差：若限流与验证码策略未统一、审计不全、MFA 未提供，与规划存在差距。

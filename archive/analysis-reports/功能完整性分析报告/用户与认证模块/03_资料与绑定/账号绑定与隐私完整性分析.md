# 账号绑定与隐私完整性分析报告

## 1. 功能概述（定位/场景/模块关联）
- 定位：提供第三方账号绑定/解绑（微信/QQ/邮箱/手机）、个人资料管理（头像/昵称/签名/地区）、隐私设置（可见性、数据导出/删除）。
- 场景：快捷登录、找回账号、跨设备协同、隐私合规（GDPR/数据导出）。
- 关联：认证与授权（JWT/刷新）、通知（绑定/解绑提醒）、搜索/社区（可见性过滤）。

## 2. 前端实现分析（UI组件/交互/状态/主题/问题）
- 路径：
  - 屏幕：`src/screens/settings/ProfileSettings.js`（头像/资料，已见 UI 强化）；`src/screens/auth/*`（绑定/解绑流程入口）
  - 服务：`src/services/auth/*`（绑定/解绑/验证/发送验证码）
  - 配置：`src/config/api.js` → `API_ENDPOINTS.AUTH.BIND_* / UNBIND_* / VERIFY_*`
- 交互建议：
  - 绑定：校验+确认；解绑：二次确认+风控（近期登录校验/验证码）；
  - 隐私设置：资料可见范围（仅自己/关注/所有）；
  - 数据导出/删除申请入口（下载打包/触发后端异步生成）。
- 问题清单（前端）：
  - 需确认：解绑的“安全二次校验”与提示文案；
  - 需确认：隐私设置是否贯穿搜索/社区可见性；
  - 需确认：数据导出/删除的状态与下载入口。

## 3. 后端实现分析（API/模型/业务/鉴权/问题）
- 路径：
  - `backend/users/views/*`（绑定/解绑、验证码、资料修改）、`backend/users/serializers/*`, `backend/users/permissions.py`
- 业务：
  - 绑定：OAuth 回调并校验；邮箱/手机验证码校验；
  - 解绑：近期登录校验/验证码/风险拦截；
  - 资料：字段白名单与格式校验（昵称敏感词过滤）；
  - 隐私：可见性字段落库并贯穿查询过滤；
  - 数据导出/删除：异步任务+状态端点（建议）。
- 问题清单（后端）：
  - 绑定风控与频次限制；
  - 隐私可见性的落库与查询过滤一致性；
  - 导出包签名与下载有效期。

# 导入导出完整性分析报告（MD/HTML/PDF/图片）

## 1. 功能概述
- 定位：将外部资料导入为笔记（或附件）并支持多格式导出，作为跨工具协作与备份的重要能力。
- 场景：导入 Markdown/HTML/PDF/图片/纯文本；导出 Markdown/HTML/PDF；批量导入导出与日志可追溯。
- 关联模块：文档转换与预览（转换链路）、搜索（索引刷新）、同步（本地/远端一致）、知识图谱（导入后自动抽取）。

## 2. 前端实现分析
- 关键路径：
  - 上传/选择：`src/components/common/FileUploader.js`（如存在）、`src/components/viewer/*`（预览）
  - 屏幕：`src/screens/note/NoteEditorScreen.js`（导入为新笔记/插入到当前笔记）
  - 服务：`src/services/notes/noteService.js`（导入/导出请求）、`src/services/document/*`（文档处理）
  - 配置：`src/config/api.js` → `API_ENDPOINTS.NOTES.IMPORT_* / EXPORT`
- 交互：
  - 选择文件 → 识别格式 → 上传/转换 → 预览与确认 → 生成笔记/附件引用 → 索引与图谱触发；
  - 导出：选择范围（当前/批量）、格式（MD/HTML/PDF）→ 后端异步生成 → 通知下载。
- 主题一致性：按钮/进度/结果卡片风格统一；失败重试与提示文案规范化。
- 问题清单（前端）：
  - 需确认：批量导入/导出的UI与任务状态；
  - 需确认：大文件进度与断点续传；
  - 需确认：导出结果缓存与下载过期时间提示。

## 3. 后端实现分析
- API端点（`src/config/api.js` → NOTES）：
  - `POST /notes/import/pdf/`, `/notes/import/word/`, `/notes/import/image/`, `/notes/import/text/`
  - `POST /notes/export/`
- 后端代码：
  - 文档转换：`backend/document_converter/*`（`services.py`, `views.py`, `websocket_views.py`, `tasks.py`）
  - 笔记：`backend/notes/views/*`, `backend/notes/serializers/*`, `backend/notes/mongodb_models.py`
  - 任务：可接入 Celery 队列与 WebSocket 进度（见 `document_converter/websocket_views.py`）
- 业务与边界：
  - 文件校验：类型/大小白名单（参见 `common.utils` 校验方法，用于上传安全）；
  - 转换链路：PDF→文本/OCR、Word→HTML→Markdown、图片→OCR（iOS本地/Android待补）
  - 幂等：重复导入去重策略（按文件hash/标题+时间）；
  - 导出：长任务异步，完成后提供下载URL与过期策略；
- 问题清单（后端）：
  - 批量与异步任务的状态端点与错误明细列表；
  - 导入映射（标题/标签/分类）与缺省规则；
  - OCR平台差异（Android待实现）。

## 4. 规划一致性检查

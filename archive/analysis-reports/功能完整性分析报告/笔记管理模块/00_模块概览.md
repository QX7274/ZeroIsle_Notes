# 笔记管理模块（Notes）完整性分析总览

## 1. 模块职责与边界
- 职责：提供笔记的创建、编辑、组织（分类/标签）、历史与版本、导入导出、安全与权限、批量操作等完整能力；为搜索、知识图谱、AI助手、同步模块提供核心数据源。
- 边界：
  - 输入：用户编辑操作、导入文件（MD/HTML/PDF/图片/纯文本）、AI处理结果（文本变换/摘要/关键词）。
  - 输出：持久化笔记与元数据（本地Realm + 远端MongoDB），导出文件，事件/通知。
- 依赖：
  - 前端：`src/components/note/*`、`src/screens/note/*`、`src/services/notes/*`、`src/adapters/noteAdapter.js`、`src/models/Note.js`、`src/schemas/noteSchema.js`。
  - 后端：`backend/notes/*`（models|mongodb_models|serializers|services|views|urls|permissions），`backend/common/*`。
  - 规划文档：`Info/功能模块详细说明.md`、`docs/ARCHITECTURE.md`、`PROJECT_SUMMARY.md`。

## 2. 数据流与交互
1) 编辑 → 本地保存（Realm）→ 同步（Sync服务）→ 后端（MongoEngine）→ 触发索引/知识图谱构建。
2) 导入 → 解析/校验 → 入库（本地/远端）→ 索引刷新 → 可视化/搜索。
3) 版本/历史 → 自动留痕/对比/回滚。

## 3. 关键端点与文件
- 前端关键：
  - `src/services/notes/noteService.js`（CRUD/列表/收藏等）
  - `src/services/notes/enhancedNoteService.js`（增强逻辑）
  - `src/services/notes/noteToolbarService.js`（工具栏交互）
  - `src/adapters/noteAdapter.js`（前后端模型映射）
  - `src/models/Note.js`、`src/schemas/noteSchema.js`
- 后端关键：
  - `backend/notes/urls.py`（REST路由、分享/导出/导入等）
  - `backend/notes/mongodb_models.py`（笔记数据模型与索引）
  - `backend/notes/serializers/*`、`backend/notes/views/*`、`backend/notes/permissions.py`
  - 导入导出：参考 `API_ENDPOINTS.NOTES`（`src/config/api.js` 定义了 `/notes/export/`、`/notes/import/*`）

## 4. 与其他模块的关系
- 搜索（Search）：全文与向量检索的源数据；
- 知识图谱：自动抽取概念与关系；
- 同步与离线：Realm↔MongoDB 的增量同步与冲突解决；
- AI助手：文本增强、摘要、关键词、改写；
- 文档转换：PDF/Word/图片到笔记的转换与预览；
- 通知/提醒：与笔记复习/提醒挂钩。

## 5. 风险与技术债（摘录）
- 编辑器能力碎片化（Markdown/代码/附件/图片多路径维护）；
- 版本/历史落地与回滚一致性需核对；
- 导入导出端点与前端向导体验需统一；
- 批量操作的性能与事务边界（本地/远端）。

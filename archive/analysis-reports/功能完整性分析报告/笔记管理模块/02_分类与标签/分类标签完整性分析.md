# 分类与标签完整性分析报告

## 1. 功能概述
- 定位：为笔记提供“层级分类 + 多标签”组织能力，支持颜色/图标、批量变更与检索过滤，作为搜索/知识图谱/提醒的基础维度。
- 场景：按项目/课程/主题归档，利用标签做交叉视图与快速筛选。
- 关联：
  - 搜索模块：按分类/标签过滤；
  - 知识图谱：分类→belongs_to、标签→has_tag；
  - 同步：分类/标签字典与笔记关联的一致性；
  - 导入导出：映射外部分类/标签。

## 2. 前端实现分析
- 主要路径：
  - 服务：`src/services/notes/noteService.js`、`src/services/notes/enhancedNoteService.js`
  - 适配：`src/adapters/noteAdapter.js`（若存在分类/标签字段映射）
  - 模型/Schema：`src/models/Note.js`、`src/schemas/noteSchema.js`（categoryId/tags 字段）
  - UI：列表/筛选入口位于 `src/screens/note/CardNoteScreen.js`（需确认筛选面板）
- 交互：
  - 创建/选择分类（单一），添加/移除标签（多选），支持批量操作；
  - 过滤：按分类/标签筛选列表，组合条件；
- 主题一致性：
  - 颜色/圆角/间距与 `src/theme/*` 一致；标签色板与主题色系对齐。
- 问题清单（前端）
  - 需确认：标签颜色/图标的统一配置来源（常量/服务）；
  - 需确认：批量改分类/标签的交互是否支持撤销。

## 3. 后端实现分析
- API端点（`src/config/api.js`）：
  - `GET /notes/tags/`, `GET /notes/categories/`, `PATCH /notes/{id}/`（修改分类/标签）
- 数据模型：`backend/notes/mongodb_models.py`（Note、Tag、Category 文档/索引），`backend/notes/serializers/*`
- 业务与边界：
  - 标签去重/规范化（大小写/空白）；
  - 分类层级（若支持）与移动；
  - 批量接口与事务性（建议提供 bulk PATCH）。
- 问题清单（后端）
  - 标签/分类字典变化对笔记关联的同步（孤儿引用）处理；
  - 批量接口是否支持；
  - 审计（谁在何时改变了哪些笔记的分类/标签）。

## 4. 规划一致性检查
- 文档：`Info/功能模块详细说明.md`、`docs/ARCHITECTURE.md`
- 偏差：若无 bulk 接口与审计/撤销，则与“可回滚/可观测”要求有差距。

# 内容组织与迁移完整性分析报告

## 1. 功能概述
- 定位：将笔记/文档/外部数据迁移至知识库，以“条目”为单位进行结构化组织（分类/标签/目录/模板）。
- 场景：从个人笔记批量沉淀到团队知识库；从外部系统（RDF/JSON-LD/CSV/MD）导入；建立目录/标签体系与模板套用。
- 关联：搜索（范围与权限过滤）、知识图谱（抽取概念关系）、导入导出模块（IO链路）、同步（增量与冲突）。

## 2. 前端实现分析
- 路径：
  - 屏幕：`src/screens/knowledge/KnowledgeBaseListScreen.js`, `src/screens/knowledge/KnowledgeBaseDetailScreen.js`, `src/screens/knowledge/KnowledgeBaseEditScreen.js`, `src/screens/knowledge/KnowledgeBaseSearchScreen.js`
  - 组件：`src/components/knowledge/*`（卡片/工具栏/相关概念/可视化）
  - 服务：`src/services/notes/noteService.js`（从笔记入库）、`src/services/document/*`（从文档导入）
- 交互建议：
  - 批量入库向导：选择来源（笔记/文件）、映射（标题/标签/分类→库字段）、预览→执行→结果；
  - 条目组织：批量移动/批量加标签；
  - 模板：从模板创建库条目；
- 问题清单：
  - 需确认：入库向导 UI 是否存在；
  - 需确认：批量组织与撤销；
  - 需确认：权限范围内的导入导出入口。

## 3. 后端实现分析
- 路径：`backend/knowledge_base/urls.py`, `backend/knowledge_base/mongodb_models.py`, `backend/knowledge_base/serializers.py`, `backend/knowledge_base/views.py`
- 端点建议：
  - `POST /knowledge-base/{kb_id}/import`（multipart，支持 csv/rdf/jsonld/md；返回 `{task_id}` 与状态查询端点）
  - `POST /knowledge-base/{kb_id}/organize/bulk`（批量移动/加标签）
  - `POST /knowledge-base/{kb_id}/template/apply`
- 业务：
  - 映射：外部字段→条目字段；
  - 幂等：hash/外部ID 去重；
  - 权限：仅 kb 成员可操作；
- 问题清单：
  - 批量失败明细与回滚；
  - IO 统一到导入导出模块契约；

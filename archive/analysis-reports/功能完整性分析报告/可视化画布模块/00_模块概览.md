# 可视化画布模块（Canvas/Infinite Canvas）完整性分析总览

## 1. 模块职责与边界
- 职责：提供无限画布的绘制与交互（缩放/平移/套索/形状/文本/撤销重做）、元素与布局管理、导出与共享、以及在大图场景下的性能优化策略；与AI/OCR、知识图谱、笔记等模块联动。
- 边界：
  - 输入：用户手势/工具栏操作、导入图片/截图、AI/OCR识别文本、外部节点数据。
  - 输出：画布元素（节点/连线/文本/图形）与布局、导出图像/矢量、变更事件。
- 依赖：
  - 前端：`src/screens/canvas/FluidInfiniteCanvasScreenNative.js`, `src/components/canvas/DrawingEngine.js`, `src/components/canvas/CanvasStyleModal.js`
  - 其他：`src/components/common/AllInOneToolbar.js`（OCR兜底/AI链路），iOS 原生：`ios/NativeInfiniteCanvasView/*`
  - 文档：`src/screens/canvas/README.md`, `docs/toolbar-implementation-guide.md`（若有）

## 2. 数据流与交互
1) 工具栏选择工具 → 手势绘制/编辑 → DrawingEngine 更新本地状态 → 可选保存/导出；
2) 无选中文本时，触发区域OCR（iOS已实现）→ 文本回填 → 继续AI处理；
3) 布局/样式变更 → 画布重绘 → 导出 PNG/SVG（建议）。

## 3. 关键文件
- 渲染与交互：`src/screens/canvas/FluidInfiniteCanvasScreenNative.js`
- 引擎：`src/components/canvas/DrawingEngine.js`
- 样式：`src/components/canvas/CanvasStyleModal.js`
- 原生能力（iOS）：`ios/NativeInfiniteCanvasView/*`

## 4. 风险与技术债
- Android 平台区域OCR未实现（ML Kit）；
- 大图（>2k元素）掉帧，需阈值与聚合策略（与知识图谱可视化类似）；
- 导出通道（PNG/SVG）与批量快照；
- 撤销/重做与协作并发冲突。

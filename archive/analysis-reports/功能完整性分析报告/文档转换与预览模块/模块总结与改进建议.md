# 文档转换与预览模块 - 模块总结与改进建议

## 总体评估
- 功能覆盖：8/10（PDF/Word/图片/文本链路具备；Excel/公式保真与批量导入增强空间大）
- 代码质量：8/10（services/tasks/views 分层清晰；统一结果Schema与状态契约需固化）
- 契约一致性：8/10（导入状态/错误明细/分块上传契约需要统一文档与实现）
- UI一致性：8.5/10（进度/结果卡片与全局风格基本一致，导入向导与错误提示可再统一）
- 错误处理：8/10（类型/大小校验完善；长任务失败明细回传/回滚策略需补）
- 性能优化：8/10（大文件分块/断点续传/并发转换可优化）
- 文档完善度：8.5/10（路径清晰；需补链路图与参数示例/错误码表）

## 关键问题
- 🔴 无统一“任务状态/错误明细”端点与结果Schema（content_md/images/tables/errors）。
- 🔴 Android 端 OCR 缺失（iOS 端已有区域OCR）。
- 🟡 分块上传与断点续传未落地；
- 🟢 PDF/Office 复杂格式（表格/公式）保真与降级策略需补充。

## 改进建议
- 后端：
  - 分块上传/断点续传；统一状态端点 `/io/import-status/<task>`；错误明细CSV下载；
  - 结果Schema固化：`{content_md, images[], tables[], meta, errors[]}`；
- 前端：
  - 导入向导（识别/映射/预览/执行/结果）；批量任务面板；
  - 预览分页缓存、图片占位/懒加载；
- 平台：Android ML Kit OCR 接入；

## 验收标准
- 10万行CSV分块导入成功率 ≥ 99%，失败明细可下载；
- Android OCR 一致性 ≥ iOS 90%；
- PDF/Office 导入结果Schema统一，前端渲染无分支差异；
- 预览卡顿显著下降（长PDF滚动P95 ≤ 80ms）。

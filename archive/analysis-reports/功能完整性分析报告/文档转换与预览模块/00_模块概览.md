# 文档转换与预览模块（Document Converter）完整性分析总览

## 1. 模块职责与边界
- 职责：提供多格式文档（PDF/Word/Excel/图片/纯文本）的解析、转换为可编辑笔记/可预览内容、OCR 与文本抽取、异步任务与状态、预览缓存与错误处理。
- 边界：
  - 输入：上传文件（multipart）或本地选取；
  - 输出：笔记内容（Markdown/HTML/纯文本）、预览（图片/PDF WebView）、转换结果文件与状态；
- 依赖：
  - 前端：`src/components/viewer/*`, `src/services/document/*`, `src/components/common/FileUploader.js`（如有），`src/screens/note/NoteEditorScreen.js`
  - 后端：`backend/document_converter/services.py|views.py|websocket_views.py|tasks.py`、`backend/common/utils.py`（上传校验）
  - AI/OCR：`backend/ai_assistant/services/image_analysis_service.py`（extract_text）与端侧 OCR（iOS 已有，Android 待补）

## 2. 数据流
1) 选择/上传文件 → 类型识别与校验 → 转换链路（OCR/解析/格式化）→ 生成笔记/预览 → 索引/知识抽取。
2) 长任务 → 返回 task_id → WebSocket/状态端点轮询 → 结果/错误明细下载。

## 3. 关键端点与文件
- 端点（建议/现有）：
  - `POST /notes/import/pdf|word|image|text/`（见 `src/config/api.js`）
  - WebSocket：`backend/document_converter/websocket_views.py`
- 服务：`backend/document_converter/services.py`（核心转换）、`tasks.py`（异步）、`views.py`（HTTP）
- 前端：`src/services/document/*`（请求与进度）、`src/components/viewer/*`（预览）

## 4. 风险与技术债
- Android OCR 缺失；
- 批量导入与状态查询契约未统一；
- 错误明细/回滚策略文档化不足；
- 大文件的分块上传与断点续传。

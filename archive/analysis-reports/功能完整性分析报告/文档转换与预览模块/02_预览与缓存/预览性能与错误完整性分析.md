# 预览性能与错误完整性分析报告

## 1. 功能概述（定位/场景/模块关联）
- 定位：为PDF/图片/Office等文档提供稳定高效的预览体验（分页/缩放/滚动/跳转/搜索），并通过缓存/占位与错误降级保障弱网与大文件场景。
- 场景：移动端查看PDF讲义、图片浏览、Office文档预览、长文分页与搜索。
- 关联：导入链路（转换完成→预览）、搜索（文内查找）、同步（预览资源缓存同步）、通知（错误提示）。

## 2. 前端实现分析（UI/交互/状态/主题/问题）
- 路径：`src/components/viewer/*`, `src/screens/viewers/*`, `src/components/common/AllInOneToolbar.js`（PDF场景OCR兜底入口）
- 交互：
  - 基础：分页/缩放/双击/跳页/滚动条；
  - 搜索：文内关键词定位；
  - 性能：图片懒加载/低清占位，PDF 分页渲染与缓存；
- 状态与主题：
  - 进度条与占位 skeleton；
  - 错误与重试按钮统一样式；
- 问题清单：
  - 需确认：PDF 分页渲染是否开启缓存；
  - 需确认：图片/缩略图缓存策略与失效；
  - 需确认：文内搜索高亮与性能。

## 3. 后端实现分析（API/模型/业务/鉴权/问题）
- 路径：`backend/document_converter/services.py|views.py|tasks.py`（大文件转换后生成可预览资源/分页图）
- 业务：
  - 预览资源生成与CDN/静态缓存（可选）；
  - 错误降级（仅原文件直链/失败重试队列）；
  - 鉴权与签名URL（防盗链/过期）。

## 4. 规划一致性检查
- 文档：`Info/项目结构.md`, `docs/memory-optimization.md`（如涉及图像内存）
- 偏差：若缺分页缓存/占位与降级、签名URL防盗链，与规划差距较大。

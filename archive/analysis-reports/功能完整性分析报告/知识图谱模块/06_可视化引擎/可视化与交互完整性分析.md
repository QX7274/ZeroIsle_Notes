# 可视化与交互完整性分析报告

## 1. 功能概述
- 定位：为知识图谱提供高性能、可交互（缩放/平移/选择/编辑）的可视化能力，面对中大规模图（1k~5k节点）保持可用性。
- 场景：
  - 浏览/编辑专题图谱、对局部区域放大精看、对路径与子图进行分析解释；
  - 复核自动构建结果与推理建议，进行人工校正；
  - 导出当前视图用于展示/汇报。
- 关联：与“多维视图/节点分析/图谱查询/关系推理”联动；渲染在 `GraphVisualization.js`，控制在 `GraphToolbar.js` | `GraphControlPanel.js`。

## 2. 前端实现分析
### 2.1 代码位置
- 核心：`src/components/knowledge/GraphVisualization.js`（react-native-svg + gesture-handler + reanimated）
- 交互：缩放/平移/重置、节点/边点击/长按、布局切换（force/radial/hierarchical）
- 工具：`GraphToolbar.js`（过滤/导出/布局/视图）| `GraphControlPanel.js`（过滤阈值/图层开关）

### 2.2 性能现状与建议
- 现状：SVG 渲染在中等规模图下表现良好；>1k 节点可能掉帧。
- 建议：
  1) 大图阈值与聚合：>1k 节点启用社区/类型聚合，隐藏孤点/长边抽样；
  2) 标签延迟渲染：低缩放隐藏文字，放大后渲染；
  3) 预计算布局：服务端计算 position（存储于 node.position），前端做微调；
  4) WebGL 渲染：在 WebView 中集成 Cytoscape.js 或 Sigma.js，用于 >2k 节点场景；
  5) LOD（多层细节）：远景只渲染聚类/中心节点；近景渲染所有节点与标签；
  6) 命中测试优化：简化交互区域，减少重绘；
  7) 导出：提供 PNG/SVG 导出、CSV（nodes/edges）导出入口（与查询/导出协同）。

### 2.3 UI一致性
- 主题色/圆角/阴影与知识模块一致；
- 工具栏按钮/图层开关/过滤器遵循统一风格；
- 空态/加载态/错误态统一文案与样式。

## 3. 后端配合
- 提供布局计算/社区检测/时间线桶化接口（analysis_service 或新增 layout_service）
- 缓存布局与聚合结果（用户维度），ETag/短期缓存参数；
- 导出接口 `/knowledge-graph/graph/export?format=csv|json|graphml`；

## 4. 规划一致性检查

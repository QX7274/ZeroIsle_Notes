## 📋 核心内容速览

### 问题分析
- 🔴 **高优先级**: 构建可观测性、推理API、查询Schema、大图阈值
- 🟡 **中优先级**: Mongo↔Neo4j一致性、导入导出、GDS统一
- 🟢 **低优先级**: 视图模式、错误码规范化

### 解决方案
- ✅ **第1阶段**: 契约统一 + 可观测 + 阈值策略（1~2周）
- ✅ **第2阶段**: IO与分析增强 + WebGL（3~4周）

### 工期估算
- 后端: 22-28天
- 前端: 18-22天
- 测试: 8-10天
- **总计**: 48-60天（按全职投入）

### 验收标准
- 构建: 1万笔记 ≤ 5分钟
- 查询: P95 ≤ 300ms
- 可视化: >2k节点 ≥ 50fps
- 分析: 指标加载 ≤ 500ms
- 缓存: 命中率 ≥ 80%

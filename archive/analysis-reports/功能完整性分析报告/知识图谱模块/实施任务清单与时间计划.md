# 知识图谱模块 - 实施任务清单与时间计划（执行级别）

本文将“模块总结与改进建议”中的路线图落地为可执行的任务分解，包含端点/Schema、前端组件改造、数据与性能策略、验收标准与时间估算。

## 0. 目标与里程碑
- 目标：统一契约、任务可观测、提升大图性能、完善推理与IO能力。
- 里程碑（建议）：
  - 里程碑A（第1–2周）：构建任务化 + 查询/分析契约统一 + 可视化阈值策略
  - 里程碑B（第3–4周）：推理候选边API + GDS指标与缓存 + IO导入导出 + WebGL通道

---

## 1) 构建任务化与可观测（后端 + 前端）
- 后端改造
  - 新增端点：
    - POST /knowledge-graph/auto/build-graph/ → 响应 `{task_id}`
    - POST /knowledge-graph/auto/build-user-graph/ → 响应 `{task_id}`
    - GET  /knowledge-graph/auto/build-status/<task_id>/ → `{status: pending|running|success|failed|partial, progress:0..100, stats:{nodes_added,edges_added,skipped,conflicts}, errors:[{id,msg,note_id}]}`
  - 服务与数据：
    - knowledge_graph_builder_service.py：输出“变更集（新增/跳过/冲突）”并写入任务结果；
    - Celery 任务队列（若已存在可复用），记录任务开始/结束/失败；
  - 错误码与日志：统一 `{error_code,message,details}`；按用户维度审计。
- 前端改造
  - 组件：src/components/knowledge/KnowledgeGraphBuilder.js 新增“范围/参数/进度条/结果统计卡/错误明细下载/跳转增量子图”。
  - 状态：Redux/Realm 持久化 task_id 与最近一次构建结果；失败可重试。
- 验收标准
  - 1万笔记增量构建 ≤ 5 分钟；重复构建无重复边（source+target+type）与节点；可查看错误明细。
- 预估：后端 2–3 人日；前端 2 人日。

---

## 2) 查询/分析契约统一与安全（后端 + 前端）
- 后端改造
  - 端点：
    - GET /knowledge-graph/graph/search → 请求参数白名单：`page,page_size(<=100),sort(field in ["created_at","updated_at","type"], order in [asc,desc]), filters(DSL)`
    - GET /knowledge-graph/graph/analyze → 返回统一 Schema（见下）
  - 返回Schema建议：
    - 搜索：`{ total, page, page_size, items: [{ node|edge 标准字段 }] }`
    - 分析：`{ stats:{ total_nodes,total_edges,by_type:{concept:..}, by_rel:{related:..} }, central_nodes:[{id,name,type,degree}], timeline?:[{bucket,count}] }`
  - 安全：分页上限、排序白名单、参数化查询；慢查询日志与限流。
- 前端改造
  - 组件：GraphToolbar + 查询面板（结构化条件/分页/排序），结果列表与“在图中高亮”。
- 验收标准
  - P95 查询 ≤ 300ms（缓存命中）；错误提示清晰；返回结构单一无分支解析。
- 预估：后端 2 人日；前端 1–2 人日。

## 3) 大图可视化阈值与聚合策略（前端）
- 策略（GraphVisualization.js + GraphToolbar/ControlPanel）：
  - > 1000 节点：启用社区/类型聚合、隐藏孤点；
  - 低缩放：标签延迟渲染（仅节点点位）；
  - 边抽样与透明度衰减（长边/重叠边降噪）；
  - 预计算布局：后端持久化 position，前端仅微调；
  - > 2000 节点：提供 WebView + WebGL 渲染（Cytoscape/Sigma）切换通道。
- UI：加入“视图模式（主题/时间/关联度）”与“视图预设 保存/加载”。
- 验收标准
  - 2k 节点/3k 边开启聚合后交互 ≥ 50fps；视图切换无崩溃；导出 PNG/SVG/CSV 可用。
- 预估：前端 3–4 人日（含WebGL通道搭建基础）。

## 4) 关系推理：候选边API + 证据Schema（后端 + 前端）
- 后端改造
  - 新增端点：
    - POST /knowledge-graph/auto/suggest-edges → 入参：范围（标签/时间/类型）、阈值、topK；
      - 响应：`[{ source, target, type, confidence:0..1, evidence:[{type:'cooccurrence|path|semantic|rule', score, detail}] }]`
    - POST /knowledge-graph/auto/accept-suggestions → 批量创建边（幂等）
    - POST /knowledge-graph/auto/ignore-suggestions → 记录忽略（节点对/类型/时效）
  - 算法：两阶段（粗筛→精排），可结合 Sentence Transformers 相似度 + 最短路径 + 共邻居 + 规则。
- 前端改造
  - 组件：SuggestionPanel（候选边列表、证据抽屉、批量采纳/忽略、在图中高亮）。
- 验收标准
  - Top@K 采样准确率 ≥ 70%；一键采纳/忽略生效；证据可视化可用（路径/相似度/片段）。
- 预估：后端 3–4 人日；前端 2 人日。

---

## 5) GDS 指标与缓存（后端 + 前端）
- 后端改造
  - 新增端点：POST /knowledge-graph/graph/metrics → 入参：指标集、参数（topK）；
  - 计算：PageRank/Betweenness/Louvain（Neo4j GDS）；按用户维度缓存；
  - 响应：`{ pagerank:[{id,score}], betweenness:[...], communities:[{community_id, nodes:[..]}] }`
- 前端改造
  - 分析面板：指标卡片、排序/筛选、点击高亮。
- 验收标准
  - 指标缓存命中率 ≥ 80%；面板加载 ≤ 500ms。
- 预估：后端 2–3 人日；前端 1 人日。

---

## 6) 导入导出（IO）：RDF/JSON-LD/CSV/GraphML（后端 + 前端）
- 后端改造
  - 端点：
    - POST /knowledge-graph/io/import（multipart）→ `format, mode, mapping, graph_id`；返回 `{task_id}`
    - GET  /knowledge-graph/io/import-status/<task_id>
    - POST /knowledge-graph/io/export → `format, scope, filter`；返回 `{task_id}`
    - GET  /knowledge-graph/io/export-status/<task_id>
  - 导入流程：解析→校验→映射→幂等写入（唯一性：node(user,external_id) / edge(user,src,tgt,type)）→ 错误明细CSV → 统计；支持 dry-run。
  - 导出：流式分页 + 压缩；S3/本地存储，设置过期时间。
- 前端改造
  - ImportWizard：上传/识别/映射/预览/校验/执行/结果查看（错误明细下载、增量子图查看）。
  - ExportPanel：范围/格式选择 + 异步下载。
- 验收标准
  - 10万行CSV分块导入成功率 100%；错误明细可下载；多格式导出可用。
- 预估：后端 3–4 人日；前端 3 人日。

## 7) 数据一致性与并发（后端）
- 并发控制：节点/边更新使用乐观锁（If-Match/updated_at）；冲突返回 409。
- 级联策略：删除节点时的边处理（软删/确认窗口/批量删除端点）。
- 镜像一致性：Mongo→Neo4j 采用队列 + 补偿；失败重试与审计日志。
- 预估：后端 2 人日。

## 8) 文档与错误码规范（后端 + 前端）
- 统一错误码：KG_400_INVALID_PARAM, KG_403_FORBIDDEN, KG_404_NOT_FOUND, KG_409_CONFLICT, KG_422_UNPROCESSABLE, KG_429_RATE_LIMIT, KG_500_INTERNAL。
- OpenAPI 文档：端点、请求参数、响应Schema、示例与错误码对照表。
- 前端：错误提示文案统一（空结果、参数错误、超时、限流）。
- 预估：1 人日。

## 总时间估算（参考）
- 后端：≈ 12–16 人日；前端：≈ 11–14 人日（含WebGL基础）。
- 可并行项：A阶段（构建任务化、契约统一、大图阈值）；B阶段（推理/GDS/IO/WebGL）。

## 风险与回退
- 性能与大图：先启阈值与聚合，再引入WebGL；
- 一致性：镜像失败不阻塞主流程，记录补偿任务与重试；
- 推理准确率：A/B 与人工审核闭环（采纳/忽略反馈用于权重调优）。

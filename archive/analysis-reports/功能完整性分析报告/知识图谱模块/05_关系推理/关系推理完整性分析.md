# 关系推理完整性分析报告

## 1. 功能概述
- 定位：在现有节点/关系基础上，基于共现、路径结构、文本语义相似度与规则，发现“潜在连接”并给出置信度与可解释性证据，供用户审核采纳。
- 场景：
  - 笔记内容更新后，自动发现新概念之间的潜在联系；
  - 构建学习路径前，推荐应建立的关键关系（前置/引用/相似/包含等）；
  - 知识库清理与合并（发现重复/近似节点，建议合并/父子关系）。
- 关联：与自动构建（抽取/相似）、节点分析（中心度/子图）、查询（路径证据）协作；前端提供“候选边列表 + 一键采纳/忽略”。

## 2. 前端实现分析
### 2.1 UI组件与位置（需核对）
- 组件：
  - `src/components/knowledge/RelatedConceptsView.js`（相关概念列表/相似度）
  - `src/components/knowledge/KnowledgeGraph.js` + `GraphVisualization.js`（在图中高亮候选关系）
  - 可新增：`SuggestionPanel`（候选边/置信度/证据，批量接受/忽略）
- 交互建议：
  1) 打开“关系建议”面板，加载候选边（分页）。
  2) 查看每条建议的“证据”（共现文本片段/最短路径/相似度向量TopK）与“理由”。
  3) 单条或批量采纳 → 调用后端创建边；忽略 → 记录黑名单避免重复提示。
  4) 成功后，图中即时渲染新增边并高亮。
- 状态管理：
  - 当前筛选条件（类型/阈值/范围）、分页与忽略列表；
  - 任务状态（加载/失败/空）。
- UI一致性：主题色/圆角/阴影统一；反馈用统一Toast/对话框；空态提示（“暂无候选”）。

## 3. 后端实现分析
### 3.1 API端点（`backend/knowledge_graph/urls.py`）
- 自动/分析：
  - `POST /knowledge-graph/auto/analyze-connections/`（分析连接候选）
  - `POST /knowledge-graph/auto/suggest-related-content/`（推荐相关内容/节点）
- 建议新增：
  - `POST /knowledge-graph/auto/suggest-edges/`（统一返回候选边，含置信度与证据）
  - `POST /knowledge-graph/auto/accept-suggestions/`（批量采纳候选边）
  - `POST /knowledge-graph/auto/ignore-suggestions/`（忽略/拉黑，附范围与有效期）

### 3.2 服务与算法（`services/recommendation_service.py` 等）
- 规则与信号：
  - 共现统计（同笔记/同段/同标签出现频率 → 置信度分量）
  - 结构证据（最短路径长度/路径数、共同邻居数）
  - 语义相似度（Sentence Transformers/SBERT：文本向量余弦）
  - 规则匹配（正则/模式，诸如“引用/包含/前置”语言提示）
- 综合评分与阈值：
  - 置信度 = α·共现 + β·结构 + γ·语义 + δ·规则；
  - 分类型阈值（related/contain/reference 等）与最大候选数限制；
- 可解释性：
  - 返回证据列表：`{type: 'cooccurrence|path|semantic|rule', score, detail}`；
  - 路径证据可由 `/graph/find-path` 或 `get_path_between_nodes` 支持。

### 3.3 数据模型与一致性
- 写入：接受候选后创建 `KnowledgeEdge`，校验 source/target 用户归属与重复；
- 幂等：对同一对节点/类型，避免重复边；
- 忽略：记录忽略规则（节点对/类型/时效），供后续分析过滤。

### 3.4 错误处理与安全
- 参数校验：阈值范围/TopK上限/允许的关系类型白名单；
- 速率限制：防止大规模全图扫描；
- 统一错误：`{error_code,message,details}`；空结果返回空集合。

### 3.5 性能
- 候选生成采用两阶段：
  - 粗筛（共现/标签/类型/时间窗口/倒排索引）
  - 精排（路径/相似度/规则），并缓存TopK；
- 分页/批量：返回分页结果；支持批量接受/忽略。

## 4. 规划一致性检查
- 目标：发现潜在关系 + 置信度 + 证据 + 人机协同采纳；
- 现状：存在“相关内容/连接分析”端点，但统一候选边API与证据返回Schema待固化；前端缺少统一“建议面板”。

### 1.1 后端实现任务

#### 任务1.1.1: 构建任务化与可观测性 ✅ 规划中
**目标**: 将 `/auto/build-*` 端点改造为任务驱动架构

**实现步骤**:
1. 创建 `TaskStatus` 模型（Django ORM）
   - 字段: `task_id`, `task_type`, `status`, `progress`, `created_at`, `updated_at`, `user_id`
   - 状态枚举: `pending`, `running`, `success`, `failed`, `partial`

2. 修改 `knowledge_graph_builder_service.py`
   - 添加任务队列集成（Celery）
   - 实现进度回调机制
   - 返回结构: `{task_id, status, progress, stats, errors}`

3. 新增API端点
   ```
   POST /api/auto/build-graph
   请求: {scope, parameters}
   响应: {task_id, status: 'pending'}
   
   GET /api/auto/build-status/<task_id>
   响应: {task_id, status, progress, stats, errors}
   ```

4. 前端集成
   - 轮询 `/build-status/<task_id>` 获取进度
   - 显示进度条、统计卡、错误明细

**验收标准**:
- 任务状态可查询，进度准确
- 错误信息详细可追踪
- 支持任务取消/重试

**预计工期**: 3-4天

#### 任务1.1.2: 查询与分析结果Schema统一 ✅ 规划中
**目标**: 统一 `/graph/search`, `/graph/analyze`, `/nodes/*` 的返回结构

**实现步骤**:
1. 定义统一的响应Schema
   ```python
   {
     "data": [...],
     "pagination": {
       "total": int,
       "page": int,
       "page_size": int,
       "has_next": bool
     },
     "meta": {
       "query_time_ms": int,
       "cache_hit": bool
     },
     "error": null | {
       "code": "KG_400_INVALID_PARAM",
       "message": str,
       "details": {}
     }
   }
   ```

2. 修改所有查询视图
   - `views/graph.py`: 统一分页/排序参数
   - `views/node.py`: 统一错误响应
   - `views/edge.py`: 统一元数据返回

3. 实现参数白名单
   - 排序字段白名单: `created_at`, `updated_at`, `weight`, `confidence`
   - 分页上限: `page_size` ≤ 1000
   - 过滤操作符白名单: `eq`, `gt`, `lt`, `gte`, `lte`, `in`, `regex`

4. 错误码规范化
   - `KG_400_INVALID_PARAM`: 参数错误
   - `KG_403_FORBIDDEN`: 权限不足
   - `KG_404_NOT_FOUND`: 资源不存在
   - `KG_409_CONFLICT`: 冲突（重复节点/边）
   - `KG_422_UNPROCESSABLE`: 无法处理的请求
   - `KG_429_RATE_LIMIT`: 速率限制
   - `KG_500_INTERNAL`: 服务器错误

**验收标准**:
- 所有查询端点返回统一格式
- 分页/排序参数生效
- 错误码准确

**预计工期**: 2-3天

## 三、风险与缓解措施

| 风险 | 影响 | 缓解措施 |
|------|------|--------|
| 大图性能下降 | 用户体验差 | 启用阈值策略 + WebGL渲染 + 后端预计算 |
| Mongo↔Neo4j一致性 | 数据不一致 | 事件驱动镜像 + 失败补偿 + 重试日志 |
| 推理误报 | 用户困惑 | 人机协同 + 阈值调优 + A/B测试 |
| 导入导出失败 | 数据丢失 | 事务回滚 + 错误明细 + 备份 |

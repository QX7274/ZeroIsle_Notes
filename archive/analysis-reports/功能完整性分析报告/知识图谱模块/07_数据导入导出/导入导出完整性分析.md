# 导入导出完整性分析报告

## 1. 功能概述
- 定位：将外部知识数据导入到系统知识图谱（节点/关系/属性），以及将系统中的知识图谱按标准格式导出（用于迁移、备份、共享与分析）。
- 典型格式：
  - 导入：RDF（Turtle/TTL、N-Triples、RDF/XML）、JSON-LD、CSV（nodes.csv/edges.csv）
  - 导出：RDF（TTL/JSON-LD）、GraphML、CSV、JSON（系统内部Schema）
- 关联：自动构建（批量导入→自动抽取补全）、可视化（导入后增量子图呈现）、查询（导入结果验证）。

## 2. 前端实现分析
### 2.1 UI与流程建议（需核对现状）
- 导入向导（Wizard）：
  1) 上传文件（支持多文件/分块）
  2) 格式识别（文件头/扩展名）
  3) 字段映射（外部字段→系统字段，如 label→title, id→external_id）
  4) 预览与校验（显示前50行/三元组样例，错误列表）
  5) 执行导入（显示进度/统计）
  6) 结果页（新增节点/边数、跳过/失败明细可下载CSV、支持“在图中查看增量子图”）
- 导出面板：
  - 选择范围（全量/当前筛选/当前子图/选中节点集合）
  - 选择格式（RDF/JSON-LD/CSV/GraphML/JSON）
  - 异步导出（后台任务 + 下载链接）
- 组件位置：`src/components/knowledge/*`（建议新建 `ImportWizard.js`、`ExportPanel.js`），屏幕：`KnowledgeGraphScreen/GraphTab` 集成入口。
- UI一致性：表单/进度/结果卡片与全局规范一致；错误列表支持筛选/导出。

## 3. 后端实现分析
### 3.1 建议端点
- 导入：
  - `POST /knowledge-graph/io/import`（multipart）
    - params: `format=csv|rdf|jsonld|graphml`、`mode=create|upsert|merge`、`graph_id`（可选，将数据导入指定图谱）
    - body: 文件/分块 + 字段映射 `mapping`（JSON）
  - `GET  /knowledge-graph/io/import-status/<task_id>`（任务状态 + 统计 + 错误清单下载URL）
- 导出：
  - `POST /knowledge-graph/io/export`（异步）
    - body: `format=csv|rdf|jsonld|graphml|json`, `scope=all|filter|subgraph|selection`, `filter`（JSON DSL）
  - `GET  /knowledge-graph/io/export-status/<task_id>`（任务状态 + 下载URL）

### 3.2 处理流程（导入）
- 解析 → 校验 → 映射 → 幂等写入 → 统计/错误记录 → 结束（可选：触发自动构建/抽取）
- 幂等策略：
  - 节点：`(user, external_id)` 或 `(user, label, type, unique_key)` 唯一；
  - 关系：`(user, source_id, target_id, type)` 唯一；
- 回滚与部分成功：
  - 默认部分成功（记录失败明细CSV）；
  - `mode=merge|upsert` 支持更新属性；
  - 提供“试运行 dry-run”模式：仅校验/预览，不写入。

### 3.3 字段映射建议
- 统一映射Schema（示例）：
```json
{
  "node": {
    "id": "external_id",
    "label": "name|title",
    "type": "type",
    "properties": {"color": "color", "size": "size"}
  },
  "edge": {
    "source": "source_id",
    "target": "target_id",
    "type": "relation_type",
    "label": "label",
    "weight": "weight"
  }
}
```
- RDF/JSON-LD：
  - IRI/Blank Node 解析为系统ID或 external_id；
  - RDF predicate → edge.type 或 node.property；
  - 支持可配置的 predicate→type 映射表。

### 3.4 模型/索引（`mongodb_models.py`）
- `KnowledgeNode/Edge/Graph` 已具关键索引：user/type/title/source/target；
- 建议新增：`external_id`、`(user, label, type)` 复合唯一索引（可选）。

### 3.5 错误处理与安全
- 分类：
  - 400：格式不支持/字段缺失/映射错误；
  - 413：文件过大；
  - 422：校验失败（记录错误明细）；
  - 429：限流；
  - 5xx：内部错误；
- 风险与防护：
  - 大文件分块上传 + 合并；
  - 速率限制/并发限制；
  - 资源隔离（按用户维度/图谱维度）；
  - 审计日志（操作者、时间、范围、统计、失败TopN样例）。

### 3.6 性能
- CSV：流式读取（逐行/分块），批量写入（bulk_write），批大小阈值（500~1000）
- RDF/JSON-LD：使用流式解析（rdflib/ijson等）+ 批量写入；
- 导出：流式生成（分页/游标）+ 压缩（gzip）
- 任务与缓存：Celery队列，状态轮询；生成文件存储（S3/本地），设置过期时间。

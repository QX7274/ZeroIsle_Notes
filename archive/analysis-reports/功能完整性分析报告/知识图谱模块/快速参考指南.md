## 二、错误码速查表

| 错误码 | HTTP状态 | 含义 | 示例 |
|--------|---------|------|------|
| `KG_400_INVALID_PARAM` | 400 | 参数错误 | 缺少必需参数 |
| `KG_403_FORBIDDEN` | 403 | 权限不足 | 无权访问他人数据 |
| `KG_404_NOT_FOUND` | 404 | 资源不存在 | 任务ID不存在 |
| `KG_409_CONFLICT` | 409 | 冲突 | 重复的节点/边 |
| `KG_422_UNPROCESSABLE` | 422 | 无法处理 | 数据格式错误 |
| `KG_429_RATE_LIMIT` | 429 | 速率限制 | 请求过于频繁 |
| `KG_500_INTERNAL` | 500 | 服务器错误 | 内部异常 |

## 四、常用查询参数

### 分页参数

```
page=1                    # 页码，默认1
page_size=20             # 每页数量，默认20，最大1000
sort_by=created_at       # 排序字段（白名单：created_at, updated_at, weight, confidence）
sort_order=desc          # 排序顺序（asc|desc）
```

### 过滤参数

```
type=concept             # 节点类型过滤
created_at__gte=2025-01-01  # 创建时间范围
weight__gte=0.5          # 权重范围
```

### 聚合参数

```
aggregate=true           # 启用聚合
threshold=1000          # 聚合阈值
hide_isolated=true      # 隐藏孤点
```

## 六、常见问题速查

### Q: 如何创建构建任务？
A: 
```bash
curl -X POST http://localhost:8000/api/auto/build-graph/ \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"scope": "all", "parameters": {}}'
```

### Q: 如何查询任务状态？
A:
```bash
curl http://localhost:8000/api/auto/build-status/<task_id>/ \
  -H "Authorization: Bearer <token>"
```

### Q: 分页参数有什么限制？
A: 
- `page_size` 最大1000
- `sort_by` 只能是白名单字段
- `sort_order` 只能是 asc 或 desc

### Q: 如何处理错误响应？
A:
```javascript
try {
  const response = await fetch('/api/graph/search/', {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  const data = await response.json();
  
  if (data.error) {
    console.error(data.error.code, data.error.message);
  } else {
    console.log(data.data);
  }
} catch (error) {
  console.error('Network error', error);
}
```

### Q: 候选边的置信度如何理解？
A: 
- 0.0 - 0.3: 低置信度（不建议采纳）
- 0.3 - 0.7: 中置信度（需要人工审核）
- 0.7 - 1.0: 高置信度（可以自动采纳）

### Q: 大图如何优化性能？
A:
1. 启用聚合: `aggregate=true`
2. 设置阈值: `threshold=1000`
3. 隐藏孤点: `hide_isolated=true`
4. 使用WebGL渲染（>2k节点）

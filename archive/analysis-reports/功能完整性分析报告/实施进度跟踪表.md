- [x] backend/users/jwt_auth.py - ✅ 自定义认证增加黑名单校验（拒绝黑名单access）

**关键代码**:
- 后端：
  - 自定义认证：命中黑名单→AuthenticationFailed
  - 刷新：旧refresh→黑名单；返回新access+refresh
  - 登出：拉黑refresh；解析Authorization尝试拉黑access
- 前端：
  - 刷新失败→clearTokens()→拦截器调用handleUnauthorizedError()强制登出

**验收标准**:
- [x] Token刷新失败自动强制登出
- [x] 登出后旧Token无法继续使用（access尝试拉黑，refresh必拉黑）
- [x] 黑名单机制正常（缓存命中+DB回查，DB缺失时降级不影响运行）

**备注**: 需在后续迁移时生成migrations（当前DB缺失时自动降级到缓存黑名单）

# 计划与重复规则完整性分析报告

## 1. 功能概述（定位/场景/模块关联）
- 定位：支持一次性/周期性/复杂重复（每日/每周/工作日/自定义RRULE）提醒与复习计划（SRS间隔）。
- 场景：学习复习、任务到期提醒、重复例会、知识再学习。
- 关联：通知与执行（触达）、数据一致性（延期/取消/过期）、同步与离线（本地计划、回连触发）。

## 2. 前端实现分析（UI组件/交互/状态/主题/问题）
- 路径：
  - 组件/屏幕：`src/components/reminder/*`, `src/screens/reminder/*`
  - 服务：`src/services/reminder/*`, `src/services/calendar/*`
  - 配置：`src/config/featureFlags.js`（如有开关）
- 交互建议：
  - 创建/编辑表单：时间、时区、重复（每日/每周/工作日/自定义）、结束条件（次数/日期/无）、优先级、颜色；
  - 复习计划：依据复习算法（记忆强度）计算下次时间；
  - 列表分组：今天/即将/过期；
- 状态管理：
  - 本地Realm保存 + `is_synced` 标记；
  - 延期/取消/完成操作实时回写。
- 主题一致性：按钮/Chip/日期选择器与主题风格一致。
- 问题清单：
  - 需确认：自定义RRULE UI 是否提供；
  - 需确认：时区与夏令时切换的显示；
  - 需确认：跨设备编辑的并发提示。

## 3. 后端实现分析（API/模型/业务/鉴权/问题）
- 端点：`backend/reminder/urls.py`
  - `/reminder/reminders/`（CRUD）
  - `/reminder/today/`, `/reminder/upcoming/`, `/reminder/overdue/`
- 模型：`backend/reminder/mongodb_models.py`
  - 字段：`scheduled_time, repeat_rule, repeat_end_date, status (planned|done|cancelled|overdue), priority, color` 等
  - 索引：`(status, scheduled_time)` 复合索引（已在优化报告中提及）
- 业务：
  - 计划生成器：根据 repeat_rule 生成下一次 `scheduled_time`；
  - 复习计划（SRS）：根据结果（完成/遗忘）调整间隔；
  - 终止条件：达到 `repeat_end_date` 或次数上限停止。
- 问题清单（后端）：
  - 复杂RRULE（如每月第N个工作日）支持范围；
  - 时区统一（服务器端计算 vs 客户端本地）；
  - 并发编辑（乐观锁）。

# 同步与离线模块 - 模块总结与改进建议

## 总体评估
- 功能覆盖：8.5/10（Realm 本地 + Mongo 远端，同步/冲突/增量具备）
- 代码质量：8.5/10（分层清晰，Mongo/TLS 安全加固已实施）
- 契约一致性：8/10（push/pull 契约与分页/上限/游标需统一）
- UI一致性：8/10（同步状态与失败明细可视化尚未统一）
- 错误处理：8.5/10（冲突分类与批量结果统计良好；指数退避/熔断需文档化）
- 性能优化：9/10（批量写、索引、阈值；建议引入游标与服务端时间统一）
- 文档完善度：8.5/10（离线/Realm 文档齐全；需补字段映射/会话统计说明）

## 关键问题（分级）
### 高优先级
1) 会话级可观测性：缺统一“会话ID+统计+失败明细”查询与前端展示；
2) per-model 高水位与服务器端统一 `updated_at` 未全面落地；
3) push/pull 分页/上限/游标与错误码未完全契约化。

### 中优先级
4) 冲突详情可视化与导出；
5) 本地容量/清理/归档策略；
6) 仅 Wi‑Fi 同步与后台策略（夜间/低电量限制）。

### 低优先级
7) 字段级合并策略模板；
8) 同步策略按模型/字段可配置。

## 改进建议
- 后端：
  - `/sync/sessions` 与 `/sync/session/{id}` 查询；`/sync/pull` 游标化；统一 `updated_at` 由服务器生成；
  - 错误码与限流（429/503）带 `Retry-After`；失败样本导出；
- 前端：
  - 同步状态总览 + 详情面板 + 导出；仅 Wi‑Fi/夜间策略；失败重试与退避；
- 数据：
  - Realm↔Mongo 映射表与校验脚本；统一同步标记字段；

## 验收标准
- P95 拉取 ≤ 300ms（缓存命中）；5万条增量在 2 分钟内完成；
- 同步失败样本 100% 可导出；会话统计可视化；
- 冲突率下降 ≥ 20%（字段级合并上线后）。

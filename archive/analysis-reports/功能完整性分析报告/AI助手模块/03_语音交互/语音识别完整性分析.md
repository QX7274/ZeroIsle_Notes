# 语音识别（转写）完整性分析报告

## 1. 功能概述
- 将用户的语音录音转写为文本；用于与 AI 对话或对笔记进行语音输入。
- 用户场景：在 AI 助手输入框中通过语音快速输入问题或内容。
- 关联：与 AIAssistantScreen 的消息发送流程、AI 文本处理链路衔接。

## 2. 前端实现分析
### 2.1 UI组件
- 入口页面：src/screens/ai/AIAssistantScreen.js
  - 录音控制与事件：`startVoiceInput`/`stopVoiceInput`/`transcribeAudio`（第268-379行）
  - 依赖：nativeAudioService（语音识别事件监听 speechResults/speechError/speechEnd）
  - 上传表单：`FormData` 包含字段名 `audio`（第321-326行）
  - API 调用：`fetch(AIAssistantModule.getApiUrl('ai-assistant/transcribe/'))`（第333行）
- UI一致性：按钮/模态遵循主题；但页头 AI 图标仍为 `psychology`（第524行），与“统一为 smart-toy”的规划不一致（见 FINAL_SUMMARY.md）。

### 2.2 交互逻辑
- 请求录音权限（Android），开始语音识别，结束后构造音频文件路径并上传后端进行转写 → 将结果设置到输入框。
- 离线降级：若后端调用失败，则尝试 `AIAssistantModule.transcribeAudio`；仍失败则使用模拟文本（第365-371行）。

### 2.3 数据绑定
- 数据源：RNFS 缓存目录下录音文件；识别结果回填 `inputText`。

## 3. 后端实现分析
### 3.1 API端点
- 使用的端点：`POST /ai-assistant/transcribe/`（backend/ai_assistant/urls.py legacy_urls 定义）。
- 视图：backend/ai_assistant/legacy_views.py → `transcribe_audio`：
  - 解析上传文件字段名为 `file`（第138行校验：`if 'file' not in request.FILES:`）。
  - 校验扩展名与大小，保存临时文件，调用 WhisperService.transcribe。

### 3.2 服务层
- backend/ai_assistant/services/whisper_service.py：
  - 使用 OpenAI 旧式 `openai.Audio.transcribe(model='whisper-1', file=...)`；
  - 与 text_processing_service.py 采用的新 SDK `openai.OpenAI(...).chat.completions.create` 不一致。

### 3.3 发现的契约问题（严重）
- 前端表单字段名为 `audio`，后端期待 `file` → 将导致 400 “未上传音频文件”。
  - 证据：AIAssistantScreen.js 第321-326行为 `formData.append('audio', { ... })`；
  - 后端：`'file' not in request.FILES` → 错误。

## 4. 规划一致性检查
- 规划：支持语音转写；
- 实际：流程完整，但存在“字段名不一致”和“SDK混用”的实现偏差；页头图标未统一。

## 6. 问题清单
### 6.1 高优先级
- 前后端字段名不一致：前端 `audio` → 后端期望 `file`（修改任一侧保持一致）。

### 6.2 中优先级
- OpenAI SDK 混用：Whisper 使用旧接口；TextProcessing 使用新 SDK；建议统一客户库与错误分类处理。
- AIAssistantScreen 页头 AI 图标仍为 `psychology`，与规划不一致。

### 6.3 低优先级
- 未做速率限制与大小限制的前端提示；
- 无断点续传与进度提示。

## 7. 改进建议
- 将前端表单字段改为 `file` 或后端兼容 `audio` 别名：`request.FILES.get('audio') or request.FILES.get('file')`。
- 统一 OpenAI SDK：全部迁移到 `openai.OpenAI(...)` 新式客户端；Whisper 改用 `client.audio.transcriptions.create(...)`。
- UI：将 AIAssistantScreen 页头图标统一为 `smart-toy`。
- 加入前端文件大小/时长限制与用户提示；失败时的统一错误对话。

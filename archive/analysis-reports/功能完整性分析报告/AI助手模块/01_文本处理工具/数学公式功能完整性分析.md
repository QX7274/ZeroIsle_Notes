# 数学公式功能完整性分析报告

## 1. 功能概述
- 将文本中的数学公式解析并输出 LaTeX 表达，用于后续渲染或导出。
- 场景：数学/理工笔记的公式录入与排版。

## 2. 前端实现分析
- 入口：src/components/common/AllInOneToolbar.js → id:`math_formula`（第1041行分支）。
- 调用：src/services/notes/noteAIService.js → `recognizeMathFormula(text)`（159-211行）。
- 解析：前端对 `response.data.result` 同时支持字符串与JSON两种返回，尝试解析并兜底（返回 `latex` 文本）。
- UI：与其他AI工具一致；未提供所见即所得渲染预览开关。

## 3. 后端实现分析
- 端点：POST /ai-assistant/process/ { text, tool:'math_formula' }
- 服务：backend/ai_assistant/services/text_processing_service.py → task='math_formula'（仅返回 LaTeX）。
- SDK：使用新式 `openai.OpenAI(...).chat.completions.create`；

## 4. 规划一致性
- 符合“统一 /process”策略；前端做了多分支解析，说明历史上返回格式不稳定。

## 6. 问题与建议
- 建议：
  - 后端固定 JSON Schema：`{ latex: string }`，避免字符串/JSON混返。
  - 前端增加“渲染预览”与“复制 LaTeX”快捷操作；允许选择渲染引擎（MathJax/KaTeX）。

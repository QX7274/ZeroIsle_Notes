# 代码识别功能完整性分析报告

## 1. 功能概述
- 将文本中的代码片段识别并格式化，尽量识别语言类型，便于高亮与复制。
- 场景：在学习笔记中粘贴代码、从PDF提取代码后进行自动格式化与标注。

## 2. 前端实现分析
### 2.1 UI组件
- 入口：src/components/common/AllInOneToolbar.js → AI_TOOLS: `code_recognition`
- 风格：与其他AI工具一致（图标、尺寸、圆角、阴影、间距）。

### 2.2 交互逻辑
- 选中文本 → 调用 `noteAIService.recognizeCode(text)` → 返回 `formatted_code` 与（可选）`language`。
- 离线降级：返回 `{ language:'unknown', formatted_code:text }`。

### 2.3 数据绑定
- 数据源：选区文本；同步返回格式化结果，由工具栏回写或粘贴到编辑器。

## 3. 后端实现分析
### 3.1 API端点
- 前端调用：`POST /ai-assistant/process/`，Body: `{ text, tool:'code_recognition' }`。
- 视图：backend/ai_assistant/views/ai_process_views.py → `process_ai`。
- 服务：backend/ai_assistant/services/text_processing_service.py → task='code_recognition'（提示词仅返回格式化后的代码）。

### 3.2 数据模型/业务
- 纯处理，不持久化；如需历史可写入会话模型。

## 4. 规划一致性检查
- 与“统一 /process”策略一致；返回结构未完全固定（前端含多重解析）。

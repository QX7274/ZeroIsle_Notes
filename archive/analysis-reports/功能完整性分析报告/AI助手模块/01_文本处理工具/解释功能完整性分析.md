# 解释功能完整性分析报告

## 1. 功能概述
- 将选中文本进行“通俗解释/概念讲解”。
- 场景：阅读难懂段落、术语释义。

## 2. 前端实现分析
- 入口：src/components/common/AllInOneToolbar.js → id: `explain`（第1033起switch分支）。
- 调用：noteAIService.explainText(text)（src/services/notes/noteAIService.js 第306-334行）。
- 离线降级：返回固定提示“离线模式下无法提供详细解释”。
- UI：与其他AI工具风格一致。

## 3. 后端实现分析
- 建议统一端点：POST /ai-assistant/process/ { text, tool: 'explain' }
- 服务：TextProcessingService.task='explain'（backend/ai_assistant/services/text_processing_service.py）。

## 4. 规划一致性
- 与“统一 /process”策略一致。

# 提取关键词功能完整性分析报告

## 1. 功能概述
- 从文本中提取关键短语/关键词，便于索引、标注与搜索。
- 场景：笔记自动打标签、知识图谱入库前的实体候选。
- 关联：与搜索/知识图谱模块协同。

## 2. 前端实现分析
### 2.1 UI组件
- 入口：src/components/common/AllInOneToolbar.js → AI_TOOLS: `extract_keywords`
- 风格：与其他AI工具一致。

### 2.2 交互逻辑
- 选中文本 → 调用 noteAIService.extractKeywords(text) → 结果回写或提示。
- 离线降级：取前5个分词作为简单关键词。

### 2.3 数据绑定
- 数据源：选区文本。
- 数据流：Toolbar → noteAIService(axios) → `/ai-assistant/process/`（tool='extract_keywords'）→ 返回数组。

## 3. 后端实现分析
### 3.1 API端点
- 统一端点：POST /ai-assistant/process/，参数：{ text, tool: 'extract_keywords' }
- 视图：backend/ai_assistant/views/ai_process_views.py → process_ai
- 服务：backend/ai_assistant/services/text_processing_service.py（task='extract_keywords'）

### 3.2 数据模型
- 纯处理，不显式持久化。

### 3.3 业务逻辑
- 返回字符串或JSON时前端均做解析与兜底分割（,，、\n）。

## 4. 规划一致性
- 符合“统一 /process”策略。

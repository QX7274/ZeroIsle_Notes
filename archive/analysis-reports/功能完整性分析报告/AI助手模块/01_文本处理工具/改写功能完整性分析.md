# 改写功能完整性分析报告

## 1. 功能概述
- 对输入文本进行语义等价的表达优化（更清晰/更简洁/更专业）。
- 场景：润色学习笔记、博客草稿、会议纪要。
- 关联：AI工具栏统一入口；与摘要、语法检查功能配合使用。

## 2. 前端实现分析
### 2.1 UI组件
- 入口：src/components/common/AllInOneToolbar.js → AI_TOOLS id: `rewrite`
- 风格：与其他AI工具一致（图标、尺寸、圆角、阴影、间距）。

### 2.2 交互逻辑
- 选中文本 → 点击“改写” → `noteAIService.rewriteText(text)` → 回写结果。
- 离线降级：直接返回原文。

### 2.3 数据绑定
- 源数据：选区文本。
- 数据流：Toolbar → noteAIService(axios) → /ai-assistant/process(tool='rewrite') → 返回结果。

## 3. 后端实现分析
### 3.1 API端点
- 前端：`POST /ai-assistant/process/ { text, tool:'rewrite' }`
- 视图：backend/ai_assistant/views/ai_process_views.py → `process_ai`
- 服务：backend/ai_assistant/services/text_processing_service.py → task='rewrite'

### 3.2 数据模型
- 纯处理型，无持久化；可选纳入会话记录。

### 3.3 业务逻辑
- 系统/用户提示词在 TextProcessingService 中集中管理；新 OpenAI SDK；超时与错误分类处理。

## 4. 规划一致性
- 与“统一走 /process”策略一致（相对翻译/摘要的 legacy 差异）。

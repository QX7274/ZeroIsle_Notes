## 🔧 技术细节

### 后端API

#### 创建构建任务
```
POST /api/knowledge-graph/task/build/
Content-Type: application/json
Authorization: Bearer <token>

{
  "scope": "all|user|notes",
  "parameters": {...}
}

Response (202):
{
  "data": {
    "task_id": "uuid",
    "status": "pending",
    "created_at": "2025-12-14T13:44:01Z"
  },
  "error": null
}
```

#### 获取任务状态
```
GET /api/knowledge-graph/task/{task_id}/status/
Authorization: Bearer <token>

Response (200):
{
  "data": {
    "task_id": "uuid",
    "task_type": "build",
    "status": "running",
    "progress": 50,
    "stats": {
      "nodes_added": 100,
      "edges_added": 50,
      "skipped": 10,
      "conflicts": 5
    },
    "errors": [],
    "created_at": "2025-12-14T13:44:01Z",
    "updated_at": "2025-12-14T13:44:30Z"
  },
  "error": null
}
```

#### 列出任务
```
GET /api/knowledge-graph/task/list/?task_type=build&status=running&page=1&page_size=20
Authorization: Bearer <token>

Response (200):
{
  "data": [...],
  "pagination": {
    "total": 100,
    "page": 1,
    "page_size": 20,
    "has_next": true
  },
  "error": null
}
```

### 前端组件使用

```jsx
import { BuildProgressPanel } from '@/components/knowledge/BuildProgressPanel';

function MyComponent() {
  const [taskId, setTaskId] = useState(null);

  const handleBuildStart = async () => {
    const task = await createBuildTask({
      scope: 'all',
      parameters: {}
    });
    setTaskId(task.task_id);
  };

  const handleComplete = (task) => {
    console.log('任务完成:', task);
  };

  return (
    <>
      <button onClick={handleBuildStart}>开始构建</button>
      {taskId && (
        <BuildProgressPanel 
          taskId={taskId}
          onComplete={handleComplete}
        />
      )}
    </>
  );
}
```

- 视图: views/recommendation.py

  - POST /api/knowledge-graph/auto/ignore-suggestions
- 路由: urls.py 已注册上述三个端点
- 前端:
  - 适配器: src/adapters/knowledgeGraphAdapter.js → suggestEdges / acceptSuggestions / ignoreSuggestions
  - 组件: src/components/knowledge/SuggestionPanel.jsx（Antd 面板）

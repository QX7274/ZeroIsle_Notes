# 手写识别功能实现建议

生成时间: 2025-11-11

## 一、功能概述

手写识别功能旨在识别用户在画布上绘制的手写笔迹，并将其转换为可编辑的文本。该功能已在工具栏中预留接口，但原生层和前端逻辑尚未实现。

## 三、实现方案

### 方案A: 使用Apple Vision框架（推荐）

#### 优点
- 系统原生支持，无需第三方依赖
- 支持多种语言（中文、英文等）
- 识别准确度高
- 与现有OCR实现技术栈一致

#### 缺点
- 仅支持iOS 14+
- 需要将笔迹转换为图像

#### 实现步骤

##### 1. 原生层实现（iOS）

**文件**: `ios/NativeInfiniteCanvasView/NativeInfiniteCanvasView.m`

在文件末尾添加手写识别扩展：

```objective-c
// MARK: - Handwriting Recognition Extension

@implementation NativeInfiniteCanvasView (HandwritingRecognition)

- (void)recognizeHandwritingInStrokes:(NSArray *)strokeIds completion:(void (^)(NSString *text, NSError *error))completion
{
  if (!strokeIds || strokeIds.count == 0) {
    if (completion) completion(@"", nil);
    return;
  }
  
  // 1. 收集指定的笔迹
  NSMutableArray *targetStrokes = [NSMutableArray new];
  for (NSString *strokeId in strokeIds) {
    // 从 self.strokes 中查找对应的笔迹
    // 这里假设 self.strokes 是一个字典，key是strokeId，value是笔迹数据
    id stroke = self.strokesDict[strokeId];
    if (stroke) {
      [targetStrokes addObject:stroke];
    }
  }
  
  if (targetStrokes.count == 0) {
    if (completion) completion(@"", nil);
    return;
  }
  
  // 2. 将笔迹渲染为图像
  CGSize imageSize = CGSizeMake(800, 600); // 可根据实际笔迹范围调整
  UIGraphicsBeginImageContextWithOptions(imageSize, NO, [UIScreen mainScreen].scale);
  CGContextRef context = UIGraphicsGetCurrentContext();
  
  // 设置白色背景
  CGContextSetFillColorWithColor(context, [UIColor whiteColor].CGColor);
  CGContextFillRect(context, CGRectMake(0, 0, imageSize.width, imageSize.height));
  
  // 绘制笔迹
  CGContextSetStrokeColorWithColor(context, [UIColor blackColor].CGColor);
  CGContextSetLineWidth(context, self.currentStrokeWidth);
  CGContextSetLineCap(context, kCGLineCapRound);
  CGContextSetLineJoin(context, kCGLineJoinRound);
  
  for (NSArray *stroke in targetStrokes) {
    if (stroke.count < 2) continue;
    
    CGPoint firstPoint = [[stroke firstObject] CGPointValue];
    CGContextMoveToPoint(context, firstPoint.x, firstPoint.y);
    
    for (NSInteger i = 1; i < stroke.count; i++) {
      CGPoint point = [stroke[i] CGPointValue];
      CGContextAddLineToPoint(context, point.x, point.y);
    }
    CGContextStrokePath(context);
  }
  
  UIImage *handwritingImage = UIGraphicsGetImageFromCurrentImageContext();
  UIGraphicsEndImageContext();
  
  if (!handwritingImage) {
    if (completion) completion(nil, [NSError errorWithDomain:@"HandwritingRecognition" code:-1 userInfo:@{NSLocalizedDescriptionKey: @"渲染笔迹失败"}]);
    return;
  }
  
  // 3. 使用Vision框架识别手写文本
  VNRecognizeTextRequest *request = [[VNRecognizeTextRequest alloc] initWithCompletionHandler:^(VNRequest * _Nonnull req, NSError * _Nullable err) {
    if (err) {
      if (completion) completion(nil, err);
      return;
    }
    
    NSMutableString *result = [NSMutableString new];
    for (VNRecognizedTextObservation *obs in req.results) {
      VNRecognizedText *top = [[obs topCandidates:1] firstObject];
      if (top) {
        [result appendString:top.string];
        [result appendString:@" "];
      }
    }
    
    if (completion) completion([result stringByTrimmingCharactersInSet:[NSCharacterSet whitespaceCharacterSet]], nil);
  }];
  
  // 设置为手写识别模式（如果系统支持）
  request.recognitionLevel = VNRequestTextRecognitionLevelAccurate;
  request.recognitionLanguages = @[@"zh-Hans", @"en-US"];
  request.usesLanguageCorrection = YES;
  
  // iOS 14+ 支持手写识别
  if (@available(iOS 14.0, *)) {
    // 可以设置更多手写相关的参数
  }
  
  VNImageRequestHandler *handler = [[VNImageRequestHandler alloc] initWithCGImage:handwritingImage.CGImage options:@{}];
  NSError *e = nil;
  [handler performRequests:@[request] error:&e];
  if (e && completion) completion(nil, e);
}

@end
```

##### 2. 暴露方法到JavaScript

**文件**: `ios/NativeInfiniteCanvasView/NativeInfiniteCanvasViewManager.m`

在 `recognizeTextInRegion` 方法后添加：

```objective-c
// 手写识别：识别指定笔迹（Promise）
RCT_EXPORT_METHOD(recognizeHandwriting:(nonnull NSNumber *)reactTag
                  strokeIds:(NSArray *)strokeIds
                  resolver:(RCTPromiseResolveBlock)resolve
                  rejecter:(RCTPromiseRejectBlock)reject)
{
  [self.bridge.uiManager addUIBlock:^(__unused RCTUIManager *uiManager, NSDictionary<NSNumber *, UIView *> *viewRegistry) {
    NativeInfiniteCanvasView *view = (NativeInfiniteCanvasView *)viewRegistry[reactTag];
    if (!view || ![view isKindOfClass:[NativeInfiniteCanvasView class]]) {
      reject(@"E_VIEW_NOT_FOUND", @"Cannot find NativeInfiniteCanvasView", nil);
      return;
    }
    
    SEL sel = NSSelectorFromString(@"recognizeHandwritingInStrokes:completion:");
    if ([view respondsToSelector:sel]) {
      void (*msgSend)(id, SEL, NSArray *, void (^)(NSString *, NSError *)) = (void *)objc_msgSend;
      msgSend(view, sel, strokeIds, ^(NSString *text, NSError *error) {
        if (error) reject(@"E_HANDWRITING_FAILED", error.localizedDescription, error);
        else resolve(text ?: @"");
      });
    } else {
      reject(@"E_NOT_IMPLEMENTED", @"recognizeHandwritingInStrokes not implemented", nil);
    }
  }];
}
```

或者，如果希望通过命令系统调用，修改 `receiveCommand` 方法：

```objective-c
- (void)receiveCommand:(nonnull NSNumber *)reactTag commandID:(NSString *)commandID commandArgs:(NSArray *)commandArgs
{
  NSInteger cmd = [commandID integerValue];
  [self.bridge.uiManager addUIBlock:^(__unused RCTUIManager *uiManager, NSDictionary<NSNumber *, UIView *> *viewRegistry) {
    NativeInfiniteCanvasView *view = (NativeInfiniteCanvasView *)viewRegistry[reactTag];
    if (![view isKindOfClass:[NativeInfiniteCanvasView class]]) {
      RCTLogError(@"Cannot find NativeInfiniteCanvasView with tag #%@", reactTag);
      return;
    }
    switch (cmd) {
      case 1: // recognizeHandwriting
        if (commandArgs.count > 0) {
          NSArray *strokeIds = commandArgs[0];
          [view recognizeHandwritingInStrokes:strokeIds completion:^(NSString *text, NSError *error) {
            if (error) {
              RCTLogError(@"Handwriting recognition failed: %@", error.localizedDescription);
            } else {
              // 通过事件发送结果到JavaScript
              if (view.onHandwritingRecognized) {
                view.onHandwritingRecognized(@{@"text": text ?: @""});
              }
            }
          }];
        }
        break;
      // ... 其他case
    }
  }];
}
```

## 五、技术要点

### 5.1 笔迹数据管理

**问题**: 需要在原生层和JavaScript层之间同步笔迹ID

**解决方案**:
- 在原生层为每个笔迹生成唯一ID
- 通过事件 `onStrokeCommitted` 将ID发送到JavaScript
- 在JavaScript层维护笔迹ID列表

### 5.2 坐标转换

**问题**: 笔迹坐标可能是世界坐标，需要转换为图像坐标

**解决方案**:
- 在渲染笔迹为图像时，计算笔迹的边界框
- 将笔迹平移到图像的合适位置
- 保持笔迹的相对位置关系

### 5.3 识别准确度

**影响因素**:
- 图像分辨率
- 笔迹粗细
- 背景对比度
- 笔迹清晰度

**优化建议**:
- 使用高分辨率图像（至少2x屏幕分辨率）
- 确保笔迹与背景有足够对比度
- 对图像进行预处理（二值化、降噪等）

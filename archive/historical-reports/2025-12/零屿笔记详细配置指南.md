# 零屿笔记（ZeroIsle Notes）详细配置指南

## 📋 概述

本文档为零屿笔记项目提供完整的配置指南，包括开发环境搭建、依赖安装、数据库配置、第三方服务集成等所有必要步骤。按照本指南操作，您将能够成功运行完整的零屿笔记应用。

## 🎯 配置目标

完成以下配置后，您将拥有：
- 完整的React Native开发环境
- 功能齐全的Django后端服务
- MongoDB + Neo4j + Redis数据库集群
- AI功能集成（多模型支持）
- 完整的开发和调试环境

## 📝 配置清单

### ✅ 第一阶段：基础环境配置

#### 1. 系统环境准备
**要做什么：** 安装基础开发工具
**怎么做：**
```bash
# Windows用户
# 1. 下载并安装 Node.js 18+ (https://nodejs.org/)
# 2. 下载并安装 Python 3.10+ (https://python.org/)
# 3. 下载并安装 Git (https://git-scm.com/)

# macOS用户
brew install node python@3.10 git

# Ubuntu用户
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs python3.10 python3.10-venv git
```
**去哪做：** 在系统终端中执行

#### 2. React Native环境配置
**要做什么：** 配置React Native CLI开发环境
**怎么做：**
```bash
# 安装React Native CLI
npm install -g react-native-cli

# 安装Yarn包管理器
npm install -g yarn

# Android开发环境（需要Android Studio）
# 1. 下载Android Studio (https://developer.android.com/studio)
# 2. 安装Android SDK (API 33+)
# 3. 配置ANDROID_HOME环境变量

# iOS开发环境（仅macOS）
# 1. 安装Xcode (App Store)
# 2. 安装Xcode Command Line Tools
xcode-select --install
```
**去哪做：** 系统终端 + Android Studio/Xcode

### ✅ 第二阶段：项目代码配置

#### 3. 克隆和初始化项目
**要做什么：** 获取项目代码并安装依赖
**怎么做：**
```bash
# 克隆项目
git clone https://github.com/qx7274/ZeroIsle_Notes.git
cd ZeroIsle_Notes

# 安装前端依赖
yarn install

# 修复bcrypt依赖问题
yarn patch-bcrypt

# iOS依赖安装（仅macOS）
cd ios && pod install && cd ..
```
**去哪做：** 项目根目录

#### 4. 后端环境配置
**要做什么：** 配置Python虚拟环境和后端依赖
**怎么做：**
```bash
# 进入后端目录
cd backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# 安装后端依赖
pip install -r requirements.txt

# 返回项目根目录
cd ..
```
**去哪做：** backend目录

### ✅ 第三阶段：数据库配置

#### 5. MongoDB配置
**要做什么：** 安装并配置MongoDB数据库
**怎么做：**
```bash
# Windows: 下载MongoDB Community Server
# https://www.mongodb.com/try/download/community

# macOS:
brew tap mongodb/brew
brew install mongodb-community

# Ubuntu:
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org

# 启动MongoDB服务
# Windows: 通过服务管理器启动
# macOS/Linux:
sudo systemctl start mongod
```
**去哪做：** 系统终端

#### 6. Neo4j图数据库配置
**要做什么：** 安装Neo4j用于知识图谱功能
**怎么做：**
```bash
# 下载Neo4j Community Edition
# https://neo4j.com/download/

# 或使用包管理器安装
# macOS:
brew install neo4j

# Ubuntu:
wget -O - https://debian.neo4j.com/neotechnology.gpg.key | sudo apt-key add -
echo 'deb https://debian.neo4j.com stable 4.4' | sudo tee -a /etc/apt/sources.list.d/neo4j.list
sudo apt update
sudo apt install neo4j

# 启动Neo4j
neo4j start

# 访问Neo4j浏览器: http://localhost:7474
# 默认用户名/密码: neo4j/neo4j (首次登录需要修改密码)
```
**去哪做：** 系统终端 + 浏览器

#### 7. Redis缓存配置
**要做什么：** 安装Redis用于缓存和会话管理
**怎么做：**
```bash
# Windows: 下载Redis for Windows
# https://github.com/microsoftarchive/redis/releases

# macOS:
brew install redis

# Ubuntu:
sudo apt update
sudo apt install redis-server

# 启动Redis
# Windows: redis-server.exe
# macOS/Linux:
redis-server

# 测试Redis连接
redis-cli ping
# 应该返回: PONG
```
**去哪做：** 系统终端

### ✅ 第四阶段：环境变量配置

#### 8. 前端环境变量
**要做什么：** 配置前端API连接和功能开关
**怎么做：**
```bash
# 在项目根目录创建.env文件
touch .env

# 编辑.env文件，添加以下内容：
API_URL=http://localhost:8000/api
ENVIRONMENT=development
ENABLE_AI_FEATURES=true
ENABLE_OFFLINE_MODE=true
```
**去哪做：** 项目根目录，创建.env文件

#### 9. 后端环境变量
**要做什么：** 配置后端数据库连接和API密钥
**怎么做：**
```bash
# 在backend目录创建.env文件
cd backend
touch .env

# 编辑backend/.env文件，添加以下内容：
DEBUG=True
SECRET_KEY=your-secret-key-here
DATABASE_URL=mongodb://localhost:27017/zeroislenotes
NEO4J_URI=bolt://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=your-neo4j-password
REDIS_URL=redis://localhost:6379/0

# AI服务配置（可选）
OPENAI_API_KEY=your-openai-key
BAIDU_API_KEY=your-baidu-key
BAIDU_SECRET_KEY=your-baidu-secret
```
**去哪做：** backend目录，创建.env文件

### ✅ 第五阶段：数据库初始化

#### 10. Django数据库迁移
**要做什么：** 初始化Django应用数据库
**怎么做：**
```bash
cd backend
source venv/bin/activate  # Windows: venv\Scripts\activate

# 创建迁移文件
python manage.py makemigrations

# 执行迁移
python manage.py migrate

# 创建超级用户
python manage.py createsuperuser
```
**去哪做：** backend目录

#### 11. MongoDB数据库初始化
**要做什么：** 创建MongoDB数据库和用户
**怎么做：**
```bash
# 连接到MongoDB
mongo

# 在mongo shell中执行：
use zeroislenotes
db.createUser({
  user: "zeroisleuser",
  pwd: "your_secure_password",
  roles: [{ role: "readWrite", db: "zeroislenotes" }]
})

# 退出mongo shell
exit
```
**去哪做：** MongoDB命令行

### ✅ 第六阶段：服务启动验证

#### 12. 启动后端服务
**要做什么：** 启动Django开发服务器
**怎么做：**
```bash
cd backend
source venv/bin/activate  # Windows: venv\Scripts\activate
python manage.py runserver

# 验证服务启动：访问 http://localhost:8000/admin
```
**去哪做：** backend目录 + 浏览器验证

#### 13. 启动前端应用
**要做什么：** 启动React Native应用
**怎么做：**
```bash
# 在新终端窗口，回到项目根目录
cd ZeroIsle_Notes

# 启动Metro服务器
yarn start

# 在另一个新终端启动Android应用
yarn android

# 或启动iOS应用（仅macOS）
yarn ios
```
**去哪做：** 项目根目录（需要多个终端窗口）

## ⚠️ 常见问题解决

### 依赖安装问题
**问题：** yarn install失败
**解决：**
```bash
yarn cache clean
rm -rf node_modules
yarn install
```

### 数据库连接问题
**问题：** 无法连接MongoDB
**解决：**
1. 确认MongoDB服务已启动
2. 检查防火墙设置
3. 验证连接字符串格式

### Android构建问题
**问题：** Android构建失败
**解决：**
```bash
cd android
./gradlew clean
cd ..
yarn android
```

# 【笔记模板功能】核查详情与优化方案

## 1. 基础信息
- 模块/功能名称：笔记模板（Note Template）
- 核查日期：2025-11-18
- 核心代码所在路径：
  - backend/notes/views/template.py（NoteTemplateViewSet：列表/详情/创建/更新/删除/应用/分类/公共模板）
  - backend/notes/mongodb_models.py（NoteTemplate/Note/Category/Tag 文档模型）
  - backend/notes/serializers.py（NoteTemplateSerializer 等）

## 2. 功能实现结论
- 结论：基本可用（个人模板管理、公共模板、按分类过滤、应用模板生成笔记），但在权限、复用度、版本与统计、推荐与发现、体验与安全等方面可提升。

### 2.1 已实现能力
- 列表：按用户与可选分类过滤，返回未删除模板；
- 详情：模板创建者或公开模板可见；
- 创建：支持分类、标签、是否公开；
- 更新/删除：仅作者可操作（软删）；
- 应用模板：校验权限 → 以模板副本创建笔记（作者自己，标题后缀“副本”），若为作者本人可继承分类与标签；统计使用次数（increment_view_count）；
- 提供模板分类列表与公共模板列表。

### 2.2 功能缺陷/缺失（功能面）
1) 权限与范围
- 公开模板仅用 is_public 控制；缺组织/团队可见、共享链接等；
- 应用模板时对分类/标签继承策略简单（仅作者本人继承），缺“目标分类/标签映射”能力；

2) 模板质量与复用
- 缺模板字段校验（长度、内容安全）；
- 缺模板版本（历史、回滚）与草稿/发布状态；
- 缺模板预览与示例渲染；

3) 发现与推荐
- 无评分、收藏、搜索、标签/分类导航优化；
- 无基于使用记录的推荐；

4) 统计与治理
- increment_view_count 命名不准确（使用次数与浏览次数分离）；
- 缺模板使用量、应用成功率、放弃率、Top 模板榜等；

5) 安全与风控
- 公共模板未做内容审查（敏感词、XSS/HTML 白名单）；
- 缺发布审核流程（尤其公共模板）；

6) API 体验
- 列表无分页/排序/搜索；
- 应用模板不支持直接指定目标分类/标签；

## 3. 具体优化建议（可落地）
1) 权限与可见性（P0）
- 增加可见范围：private/team/organization/public；
- 分享链接（可选密码/过期）；

2) 模板治理（P0）
- 字段校验与内容清洗；
- 模板状态：draft/published/archived，发布需审核（管理员或工作流）；

3) 版本与统计（P1）
- 模板版本历史及回滚；
- 指标：views、applies、conversion rate、favorites；

4) 发现与推荐（P1）
- 搜索/过滤/排序（热门/最新/评分）；
- 推荐：基于用户历史与组织内热门；

5) 体验（P1）
- 应用时支持覆盖目标分类/标签；
- 应用向导：变量占位与替换（如 {{project_name}}）；

6) 安全（P1）
- 公共模板内容审查与敏感词过滤；
- XSS 处理与富文本白名单；

## 4. 关键代码改造建议（片段）
- 使用/浏览分离：
  - template.increment_apply_count(); template.increment_view_count() 分开
- 可见范围：
  - visibility in {'private','team','org','public'} 并注入过滤
- 应用向导：
  - content = content.replace('{{var}}', inputs['var'])

—— 建议先落地“可见范围+模板治理+分页搜索+应用体验”的 P0，随后推进版本与推荐体系，提升模板生态质量与复用效率。

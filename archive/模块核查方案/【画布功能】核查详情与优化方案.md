# 【画布功能】核查详情与优化方案

## 1. 基础信息
- 模块/功能名称：画布（Canvas）
- 核查日期：2025-11-18
- 核心代码所在路径：
  - backend/canvas/views/canvas.py（CanvasViewSet：列表/详情/增改删、完整数据、我的/公开、导入导出、查看次数）
  - backend/canvas/mongodb_models.py（Canvas/CanvasElement/CanvasConnection 文档模型）
  - backend/canvas/serializers.py（Canvas/Element/Connection 序列化）
  - backend/canvas/services（CanvasService、export_service）

## 2. 功能实现结论
- 结论：基本可用（画布 CRUD、分页检索、完整数据拉取、导出/导入、查看计数），但在权限联动、并发一致性、导入校验与防注入、导出能力、协作与版本、性能与索引、审计与风控等方面需要增强。

### 2.1 已实现能力（功能面）
- 可见范围与列表
  - get_queryset 返回本人或公开画布；筛选 is_public；search(title, description)；ordering(created/updated/view_count)；分页器已接入。
- 详情/创建/更新/删除
  - IsAuthenticated + IsOwnerOrReadOnly；perform_create 绑定 user。
- 查看计数 increment_view：通过 CanvasService 递增并返回最新 view_count。
- 完整数据 full_data：一次返回画布信息及其全部元素/连接列表。
- 我的/公开：my、public 两个快捷列表均支持分页。
- 导出 export：支持 json/png/svg/pdf，多种导出服务接口；失败路径报错码区分 501/500。
- 导入 import_canvas：接收 JSON 文件，结构校验后依次创建画布、元素、连接；元素旧ID到新ID的映射用于修复连接引用。

### 2.2 功能缺陷/缺失（聚焦可用性）
1) 权限与协作
- 仅“本人/公开”，未联动群组/协作权限（协作者可查看/编辑/导出/导入？）；
- 元素/连接层权限未细化；

2) 并发与事务
- import_canvas 在创建画布、元素、连接时未使用事务，部分失败会留下不完整数据；
- increment_view 未说明并发安全（但通常可接受，建议服务端原子递增）。

3) 导入安全与校验
- 仅校验 JSON 结构存在 canvas/elements/connections，未校验字段白名单、尺寸上限、恶意/注入数据（如JS片段、超长字符串、非数值坐标等）；
- 未限制导入文件大小/请求超时；

4) 导出能力与体验
- PNG/SVG/PDF 导出依赖 export_service，未见权限/水印/缩略图导出、导出任务化（大图渲染耗时）、失败重试；

5) 性能与索引
- full_data 对大画布一次性返回全部元素/连接，缺分页或范围加载（视图窗口/层级按需加载）；
- 未说明索引（user,is_public,updated_at；元素/连接上的 canvas_id,is_deleted 等）；

6) 版本与历史
- 未提供画布版本/快照、回滚与差异；

7) 审计与风控
- 关键操作（导入/导出/删除）未写审计；
- 无速率限制与配额（导入/导出可能被滥用）；

8) 可观测性
- 未记录导出/导入耗时、失败码、对象规模；

## 3. 具体优化建议（可落地）
1) 权限与协作（P0）
- 引入协作/群组联动：owner/collaborator(view|edit|export|import)/public；
- 公开画布元素/连接访问策略可配置；

2) 导入安全（P0）
- 文件大小上限（例如 ≤ 10MB，可配置）与超时；
- 严格 schema 校验与字段白名单（标题长度、描述长度、坐标范围、样式字段白名单）；
- 事务化导入：失败整体回滚；
- 节流：端点限速；

3) 导出增强（P0）
- 大画布导出任务化（202 + task_id + 进度轮询）；
- PDF/SVG 水印、防滥用；
- 导出权限明确与审计；

4) 性能与分页（P1）
- full_data 支持分页/分层：仅返回视窗内元素与连接，或按层/分组拉取；
- 建立必要索引：Canvas(user,is_public,updated_at)；Element(canvas_id,is_deleted,updated_at)；Connection(canvas_id,is_deleted,updated_at)；

5) 版本与历史（P1）
- 画布快照/版本：自动保存与手动发布；回滚与差异；

6) 审计与指标（P1）
- 审计：导入/导出/删除/公开切换；
- 指标：导入/导出耗时与失败率、画布规模分布、视图加载 P95；

7) 体验（P2）
- 元素/连接的批量导入导出、选择性导出；
- 导入前预览、字段修复建议；

## 4. 关键代码改造建议（片段）
- 事务导入（伪）：
  - with start_session() as s: with s.start_transaction(): create canvas → elements → connections
- 校验：
  - validate_canvas(data['canvas']); validate_elements(data['elements']); validate_connections(data['connections'])
- 分层加载：
  - /full_data?bbox=...&layers=... 或 /elements?canvas_id=... 分页

—— 建议优先落地“协作权限+导入安全+导出任务化+索引与分层加载”的 P0 改造，随后推进版本/审计与指标，提升画布在真实规模与多人协作下的可靠性与体验。

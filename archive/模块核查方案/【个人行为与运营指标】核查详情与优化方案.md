# 【个人行为与运营指标】核查详情与优化方案

## 1. 基础信息
- 模块/功能名称：个人行为与运营指标（Personal Activity）
- 核查日期：2025-11-18
- 核心代码所在路径：
  - backend/personal_activity/views.py（活动/分类/目标 CRUD，批量操作，仪表板、报表、洞察、趋势，导入导出，图片上传）
  - backend/personal_activity/mongodb_models.py（数据访问封装，未展开）
  - backend/personal_activity/serializers.py（序列化验证）

## 2. 功能实现结论
- 结论：功能较完整（活动/分类/目标管理，统计报表与洞察、趋势、导出导入、图片上传），适合单体部署与中等规模使用。但在权限与多租户、查询性能与索引、节流与配额、隐私与合规、数据口径一致性、可观测与可靠性、批处理一致性等方面需要增强。

## 3. 已实现能力（概览）
- 活动 Activity
  - 列表/查询过滤（状态/分类/标签/时间范围，分页）；创建/更新/删除；状态与进度更新联动；搜索（regex 构造）；批量操作（删/状态/分类/标签增删）。
- 统计
  - 仪表板（今日、本周、近期列表）；报表（按日/周/月聚合、分类分布、满意度均值）；趋势（周/月/季，完成率/数量/满意度）。
- 分类与目标
  - 分类 CRUD、分类树构造（父子关系）；目标 CRUD（状态过滤）。
- 数据交换
  - 导出 JSON/CSV；导入 JSON（逐条校验创建）。
- 媒体
  - 图片上传/缩略图/删除（default_storage）。

## 4. 主要问题清单（P0 优先级）
1) 权限与安全
- 仅按 user_id 过滤，未涵盖组织/共享/协作；
- 端点未节流，易被滥用（搜索/导出/导入）；
- 搜索使用 regex，可能引起性能与ReDoS风险；
- 图片上传未做杀毒与高并发写控制，缩略图用原文件对象重复读写；

2) 口径与一致性
- 统计维度与时间口径使用本地时间/now()，未统一时区与边界处理；
- 完成率、满意度等指标定义未固化（缺说明/版本化口径）；

3) 性能与索引
- 列表/统计均在应用层分页聚合，多处以 limit 高上限抓取；
- 搜索/时间窗口查询未见索引声明（user_id, status, category_id, created_at/start_time 等）；
- 批量操作逐条循环，无事务与部分失败回滚策略；

4) 隐私与合规
- 未对导出/导入做字段脱敏/最小化；
- 图片 URL 公开可访问（取决于 storage backend），缺签名或权限校验；

5) 可观测与可靠性
- 无请求级指标（QPS、P95、失败率）、审计（谁导出/导入）、限额（单日导出次数/数据量）；
- 错误返回统一性一般，部分分支返回 500 未归因；

## 5. 可落地优化建议
1) 权限/多租户（P0）
- 引入组织/项目/共享范围（owner/collaborator/viewer）；
- 端点权限细化与对象级权限校验；

2) 风控与节流（P0）
- DRF Throttling：对搜索、导出、导入、图片上传设置速率；
- 配额：每日导出次数/总行数上限、导入条数上限、图片空间配额；

3) 查询与索引（P0）
- 为常用查询建立索引：user_id, status, category_id, start_time/end_time/created_at, tags；
- 搜索使用文本索引或专门搜索服务（避免高成本 regex）；
- 聚合统计下沉数据库（Mongo 聚合管道）替代应用层汇总；

4) 数据与口径（P0）
- 固化指标口径（文档化）：完成率、周起始、时区、满意度定义；
- 所有统计采用 UTC 存储 + 由用户时区转换；

5) 导入导出与一致性（P1）
- 导入批处理分块/幂等键/失败报告；
- 导出异步 + 签名下载 URL；

6) 媒体安全与性能（P1）
- 图片校验：MIME/扩展名白名单、大小限、图像解码抗压（Pillow 安全打开）；
- 杀毒（ClamAV）、对象存储 + 短时签名 URL；
- 缩略图生成使用保存后的文件重新打开，避免文件指针问题；

7) 可观测与审计（P1）
- 埋点：操作人、操作对象、数量、时长、结果；
- 指标：list/search/export/import 成功率、延时分位、数据量；

8) 代码改造片段
- 索引与查询：
  - db.personal_activities.create_index([('user_id',1),('created_at',-1)])
  - 使用 aggregate 管道: $match+$group 计算完成率/分类分布
- 限流：
  - throttle_classes / scope='personal_activity_export'
- 导出异步：
  - task_id=export_task.delay(user_id, filters); 返回下载 URL；
- 安全存储：
  - url = storage.generate_presigned_url(path, expires_in=600)

—— 建议优先落地“权限/节流/索引与聚合/指标口径/媒体安全”的 P0，随后推进导入导出异步化、可观测与审计、以及数据归档与清理策略，保障稳定性与数据质量。

# 笔记管理模块 — 修复与增强任务（P0）

依据：
- 《功能完整性分析报告/笔记管理模块/03_历史与版本/版本追踪完整性分析.md》
- 《模块功能核查与优化记录/【笔记版本功能】核查详情与优化方案.md》
- 代码核查：backend/notes/*、src/screens/note/*

关键问题与修复方向：
1) 重名模块冲突与模型不一致（致命）
- 发现：backend/notes 下同时存在 mongodb_models.py 与 mongodb_models/ 包（含 __init__.py）。
- 风险：导入“from notes.mongodb_models import …”时，易出现解析歧义；且两处存在重复/不一致模型定义（NoteVersion）。
- 方案：
  - 移除或重命名 backend/notes/mongodb_models.py（保留包 notes/mongodb_models/* 为唯一来源）。
  - 全文检索替换导入，统一为 “from notes.mongodb_models import X”。

2) 版本模型/视图/序列化器字段错配（致命）
- 现状：
  - models：notes/mongodb_models/note_version.py 使用字段 user/description/is_current/is_deleted/updated_at。
  - serializer：notes/serializers/version.py 仍使用 created_by/comment 等旧字段。
  - 视图：notes/views/version.py 依赖新字段（is_deleted、is_current、user）。
- 方案：
  - 对齐序列化器字段：created_by→user，comment→description，补充 is_current、is_deleted、updated_at、restored_from 只读字段。
  - 校验视图查询均加 is_deleted=False；destroy 改为软删除 VersionService.delete_version。

3) 遗留的Django ORM服务引用（高）
- 现状：notes/services/note_service.py 仍依赖 Django ORM（from notes.models import Note, NoteVersion），与当前MongoEngine栈不一致。
- 方案：
  - 废弃或迁移 NoteService：改为基于 MongoEngine/VersionService 的调用；或标注 deprecated 并从路由移除。

4) 前端历史版本UI与API（高）
- 现状：前端未见稳定的历史对比/回滚UI组件；API端建议 compare/rollback。
- 方案：
  - 后端：在 notes/views/version.py 增加 compare(from,to) 端点（服务层产出diff结构）。
  - 前端：NoteEditorScreen 集成“历史版本列表+对比+回滚”，切换前做脏检查。

实施改动点（代码）：
- 删除/重命名：backend/notes/mongodb_models.py（并修正引用）。
- 更新：backend/notes/serializers/version.py（字段对齐、新增只读字段）。
- 校验：backend/notes/views/version.py（确保统一走 VersionService、分页、软删除）。
- 清理/迁移：backend/notes/services/note_service.py（改MongoEngine或移除）。

验收标准：
- 版本列表/详情/创建/恢复/软删除/自动保存接口全链路成功；
- 前端可浏览版本、对比差异、回滚；
- 单测：创建/恢复/自动保存/分页/软删除/权限校验≥12例；
- 导入路径唯一且无循环/歧义；

风险与回滚：
- 如迁移失败，先保留旧文件但从 import/URL 移除引用；配套回滚脚本恢复旧导入。

工期：1–2 天；依赖：无（可并行前端）。

### （补充）P0 接口定义与测试用例
- 接口：GET /notes/versions
  - 参数：note_id(uuid, required), page(int,≥1), page_size(int,1–100)
  - 返回：{count,int; results:[{id, note, title, content, version_number, user, description, is_auto_save, is_current, is_deleted, restored_from, created_at, updated_at}]}
  - 错误：400 缺少 note_id；404 笔记不存在；
- 接口：POST /notes/versions/{id}/restore/
  - 返回：{message, restored_to_version:{...同上}}
  - 错误：400 已删除版本；403 无权限；404 版本不存在；
- 接口：GET /notes/versions/compare
  - 参数：from_id(uuid, required), to_id(uuid, required)
  - 返回：{note_id, from_version, to_version, title_diff:[str], content_diff:[str]}
  - 错误：400 跨笔记比较；403 无权限；404 版本不存在；
- 测试用例（关键）：
  1) 正常列出分页（page_size边界=100）
  2) 恢复到旧版本并生成新版本，内容回写
  3) 对比返回 unified diff，空差异时数组为空
  4) 无权限/不存在/已删除版本的错误码与文案
  5) 前端脏检查三分支（放弃/保存后继续/取消）与回滚

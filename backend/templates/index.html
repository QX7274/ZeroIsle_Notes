欢迎使用零屿笔记 API

零屿笔记是一款功能强大的笔记应用，提供AI驱动的知识管理功能。

本页面提供了API文档和相关资源的链接。

API端点

所有API端点都以 /api/v1/ 为前缀，包括以下模块：

  • 用户认证: /api/v1/auth/
  • 笔记管理: /api/v1/notes/
  • 提醒事项: /api/v1/reminders/
  • 知识图谱: /api/v1/knowledge-graph/
  • AI助手: /api/v1/ai-assistant/
  • 语音识别: /api/v1/voice-recognition/
  • 搜索: /api/v1/search/
  • 社区: /api/v1/community/
  • 画布: /api/v1/canvas/
  • 代码: /api/v1/code/

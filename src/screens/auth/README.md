# 认证模块

本目录包含零屿笔记应用的认证相关屏幕组件，用于处理用户登录、注册和密码重置等功能。

## 文件结构

- **index.js**: 认证模块导出文件，集中导出所有认证相关屏幕
- **LoginScreen.js**: 登录屏幕，提供用户登录功能
- **RegisterScreen.js**: 注册屏幕，提供用户注册功能
- **ForgotPasswordScreen.js**: 忘记密码屏幕，提供密码重置功能

## 主要功能

### 登录屏幕 (LoginScreen.js)

登录屏幕提供以下主要功能：

- **多种登录方式**: 支持用户名/手机号/邮箱登录
- **密码登录**: 使用密码进行登录
- **验证码登录**: 使用手机验证码进行登录
- **第三方登录**: 支持微信、QQ等第三方平台登录
- **记住登录状态**: 可选择记住登录状态，下次自动登录
- **跳转注册**: 提供跳转到注册页面的入口
- **忘记密码**: 提供忘记密码功能入口

### 注册屏幕 (RegisterScreen.js)

注册屏幕提供以下主要功能：

- **多种注册方式**: 支持用户名、手机号、邮箱注册
- **用户名注册**: 使用用户名和密码注册
- **手机号注册**: 使用手机号和验证码注册
- **邮箱注册**: 使用邮箱和密码注册
- **密码强度检查**: 检查密码强度，确保安全性
- **用户协议**: 显示并要求同意用户协议和隐私政策
- **跳转登录**: 提供跳转到登录页面的入口

### 忘记密码屏幕 (ForgotPasswordScreen.js)

忘记密码屏幕提供以下主要功能：

- **多种验证方式**: 支持手机号、邮箱验证
- **验证码发送**: 发送验证码到手机或邮箱
- **密码重置**: 验证成功后重置密码
- **跳转登录**: 提供跳转到登录页面的入口

## 认证流程

### 登录流程

1. 用户输入用户名/手机号/邮箱和密码，或选择验证码登录
2. 前端验证输入格式
3. 发送登录请求到后端API
4. 后端验证成功后返回用户信息和认证令牌
5. 前端存储认证令牌和用户信息
6. 更新Redux状态，标记用户为已登录
7. 导航到应用主界面

### 注册流程

1. 用户选择注册方式（用户名/手机号/邮箱）
2. 用户输入注册信息和密码
3. 前端验证输入格式和密码强度
4. 发送注册请求到后端API
5. 后端创建用户账号并返回用户信息和认证令牌
6. 前端存储认证令牌和用户信息
7. 更新Redux状态，标记用户为已登录
8. 导航到应用主界面

### 密码重置流程

1. 用户输入手机号或邮箱
2. 前端验证输入格式
3. 发送验证码到用户手机或邮箱
4. 用户输入验证码和新密码
5. 前端验证验证码和密码强度
6. 发送密码重置请求到后端API
7. 后端重置密码并返回成功信息
8. 导航到登录页面

## 与其他模块的交互

认证模块与以下模块有交互：

- **Redux认证状态**: 更新用户登录状态和信息
- **API服务**: 与后端认证API通信
- **存储服务**: 存储认证令牌和用户信息
- **导航服务**: 根据认证状态导航到不同页面

## 使用的组件

认证模块使用了以下主要组件：

- **Input**: 输入框组件，用于输入用户名、密码等
- **Button**: 按钮组件，用于提交表单
- **Loading**: 加载指示器组件，显示加载状态
- **Toast**: 提示组件，显示操作结果
- **Typography**: 文本组件，显示标题和提示文本

## 注意事项

- 认证模块处理敏感信息，需要注意数据安全
- 密码应该在前端进行强度验证，但不应明文传输
- 认证令牌应安全存储，避免泄露
- 应提供清晰的错误提示，帮助用户解决问题
- 考虑网络不稳定情况，提供重试机制
- 提供适当的加载状态反馈，避免用户多次提交

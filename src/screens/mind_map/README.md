# 思维导图模块

本目录包含零屿笔记应用的思维导图功能相关屏幕组件。思维导图模块允许用户创建、编辑和管理思维导图，帮助用户进行思维整理和知识组织。

## 文件结构

- **index.js**: 思维导图模块导出文件，集中导出所有思维导图相关屏幕
- **MindMapScreen.js**: 思维导图主屏幕，显示用户的思维导图列表
- **MindMapEditorScreen.js**: 思维导图编辑器屏幕，用于创建和编辑思维导图
- **MindMapViewerScreen.js**: 思维导图查看器屏幕，用于查看思维导图
- **MindMapSettingsScreen.js**: 思维导图设置屏幕，用于管理思维导图设置
- **MindMapTemplatesScreen.js**: 思维导图模板屏幕，提供预设模板

## 主要功能

### 思维导图主屏幕 (MindMapScreen)

思维导图主屏幕是用户进入思维导图功能的入口，主要功能包括：

- 显示用户创建的思维导图列表
- 提供创建新思维导图的入口
- 支持思维导图搜索和筛选
- 支持思维导图预览
- 提供思维导图模板入口

### 思维导图编辑器屏幕 (MindMapEditorScreen)

思维导图编辑器屏幕用于创建和编辑思维导图，主要功能包括：

- 节点创建、编辑和删除
- 节点连接和关系管理
- 节点样式设置（颜色、形状、大小等）
- 支持缩放、平移和自动布局
- 支持撤销/重做操作
- 支持导出为图片或PDF

### 思维导图查看器屏幕 (MindMapViewerScreen)

思维导图查看器屏幕用于查看思维导图，主要功能包括：

- 显示完整思维导图
- 支持缩放和平移
- 支持节点展开/折叠
- 支持节点搜索
- 支持导出和分享

### 思维导图设置屏幕 (MindMapSettingsScreen)

思维导图设置屏幕用于管理思维导图设置，主要功能包括：

- 设置默认节点样式
- 设置默认连接线样式
- 设置自动布局选项
- 设置导出选项
- 管理同步设置

### 思维导图模板屏幕 (MindMapTemplatesScreen)

思维导图模板屏幕提供预设模板，主要功能包括：

- 显示可用模板列表
- 提供模板预览
- 支持基于模板创建新思维导图
- 支持自定义模板保存

## 使用的组件

思维导图模块使用了以下主要组件：

- **MindMapEditor**: 思维导图编辑器组件，用于创建和编辑思维导图
- **MindMapViewer**: 思维导图查看器组件，用于查看思维导图
- **NodeEditor**: 节点编辑器组件，用于编辑节点内容和样式
- **ConnectionEditor**: 连接编辑器组件，用于编辑节点连接
- **TemplateSelector**: 模板选择器组件，用于选择思维导图模板

## 与其他模块的交互

思维导图模块与以下模块有交互：

- **笔记模块**: 支持将思维导图转换为笔记，或从笔记生成思维导图
- **知识图谱模块**: 支持将思维导图转换为知识图谱
- **AI助手模块**: 提供智能布局和内容建议功能
- **导出模块**: 支持将思维导图导出为各种格式

## API交互

思维导图模块主要与以下API端点交互：

- **GET /api/mind-maps**: 获取用户的思维导图列表
- **GET /api/mind-maps/:id**: 获取思维导图详情
- **POST /api/mind-maps**: 创建新思维导图
- **PUT /api/mind-maps/:id**: 更新思维导图
- **DELETE /api/mind-maps/:id**: 删除思维导图
- **GET /api/mind-maps/templates**: 获取思维导图模板列表
- **POST /api/mind-maps/:id/export**: 导出思维导图

## 状态管理

思维导图模块的状态主要通过Redux进行管理，相关的状态切片包括：

- **mindMapSlice**: 管理思维导图相关状态，如思维导图列表、当前编辑的思维导图等

# 社区模块

本目录包含零屿笔记应用的社区功能相关屏幕组件。社区模块允许用户分享笔记、查看他人分享的内容、进行互动等社交功能。

## 文件结构

- **index.js**: 社区模块导出文件，集中导出所有社区相关屏幕
- **CommunityScreen.js**: 社区主屏幕，显示社区内容流
- **PostDetailScreen.js**: 帖子详情屏幕，显示完整帖子内容和评论
- **CreatePostScreen.js**: 创建帖子屏幕，用于发布新内容

## 主要功能

### 社区主屏幕 (CommunityScreen)

社区主屏幕是用户进入社区功能的入口，主要功能包括：

- 显示社区内容流，包括热门帖子、最新帖子等
- 支持内容分类筛选
- 集成搜索功能，使用UnifiedSearchBar组件
- 支持点赞、收藏等互动功能
- 提供创建新帖子的入口

### 帖子详情屏幕 (PostDetailScreen)

帖子详情屏幕用于显示帖子的完整内容，主要功能包括：

- 显示帖子完整内容，支持富文本、图片等
- 显示评论列表，支持分页加载
- 支持发表评论、回复评论
- 提供点赞、收藏等互动功能
- 显示作者信息

### 创建帖子屏幕 (CreatePostScreen)

创建帖子屏幕用于用户发布新内容，主要功能包括：

- 富文本编辑器，支持文本格式化
- 图片上传功能
- 标签选择功能
- 分类选择功能
- 隐私设置选项

## 使用的组件

社区模块使用了以下主要组件：

- **UnifiedSearchBar**: 统一搜索栏组件，用于社区内容搜索
- **PostCard**: 帖子卡片组件，用于在列表中显示帖子预览
- **CommentList**: 评论列表组件，用于显示和管理评论
- **CommentInput**: 评论输入组件，用于发表评论
- **RichTextEditor**: 富文本编辑器，用于创建和编辑帖子内容

## 与其他模块的交互

社区模块与以下模块有交互：

- **认证模块**: 用于确保用户已登录才能进行互动
- **笔记模块**: 支持将笔记分享到社区
- **搜索模块**: 提供社区内容的搜索功能
- **通知模块**: 当帖子收到评论或点赞时发送通知

## API交互

社区模块主要与以下API端点交互：

- **GET /api/community/posts**: 获取社区帖子列表
- **GET /api/community/posts/:id**: 获取帖子详情
- **POST /api/community/posts**: 创建新帖子
- **POST /api/community/posts/:id/comments**: 发表评论
- **POST /api/community/posts/:id/like**: 点赞帖子
- **POST /api/community/posts/:id/bookmark**: 收藏帖子

## 状态管理

社区模块的状态主要通过Redux进行管理，相关的状态切片包括：

- **communitySlice**: 管理社区相关状态，如帖子列表、当前查看的帖子等
- **authSlice**: 管理用户认证状态，用于确定用户是否可以进行互动

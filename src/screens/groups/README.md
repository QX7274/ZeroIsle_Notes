# 群组模块

本目录包含零屿笔记应用的群组功能相关屏幕组件。群组模块允许用户创建和加入群组，进行协作笔记编辑、文件共享和实时交流。

## 文件结构

- **index.js**: 群组模块导出文件，集中导出所有群组相关屏幕
- **GroupsScreen.js**: 群组主屏幕，显示用户加入的群组列表
- **GroupScreen.js**: 单个群组详情屏幕，显示群组内容和成员
- **CreateGroupScreen.js**: 创建群组屏幕，用于创建新群组
- **JoinGroupScreen.js**: 加入群组屏幕，用于搜索和加入现有群组
- **GroupSettingsScreen.js**: 群组设置屏幕，用于管理群组设置
- **GroupMembersScreen.js**: 群组成员屏幕，显示和管理群组成员

## 主要功能

### 群组主屏幕 (GroupsScreen)

群组主屏幕是用户进入群组功能的入口，主要功能包括：

- 显示用户创建和加入的群组列表
- 提供创建新群组的入口
- 提供加入现有群组的入口
- 支持群组搜索和筛选

### 群组详情屏幕 (GroupScreen)

群组详情屏幕用于显示单个群组的详细信息，主要功能包括：

- 显示群组基本信息（名称、描述、创建时间等）
- 显示群组共享的笔记和文件
- 提供群组内实时聊天功能
- 显示群组活动动态
- 提供群组设置入口

### 创建群组屏幕 (CreateGroupScreen)

创建群组屏幕用于用户创建新群组，主要功能包括：

- 设置群组名称和描述
- 设置群组类型（公开/私有）
- 设置群组标签
- 邀请初始成员

### 加入群组屏幕 (JoinGroupScreen)

加入群组屏幕用于用户搜索和加入现有群组，主要功能包括：

- 显示可加入的公开群组
- 支持群组搜索
- 支持通过邀请码加入私有群组
- 显示群组预览信息

## 使用的组件

群组模块使用了以下主要组件：

- **GroupList**: 群组列表组件，用于显示群组列表
- **GroupDetail**: 群组详情组件，用于显示群组详细信息
- **MemberList**: 成员列表组件，用于显示和管理群组成员
- **JoinGroup**: 加入群组组件，用于搜索和加入群组
- **CreateGroup**: 创建群组组件，用于创建新群组
- **ScreenShare**: 屏幕共享组件，用于群组内共享屏幕

## 与其他模块的交互

群组模块与以下模块有交互：

- **认证模块**: 用于确保用户已登录才能使用群组功能
- **笔记模块**: 支持在群组内共享和协作编辑笔记
- **WebRTC模块**: 提供群组内实时音视频通信功能
- **WebSocket模块**: 提供群组内实时消息通信功能

## API交互

群组模块主要与以下API端点交互：

- **GET /api/groups**: 获取用户的群组列表
- **GET /api/groups/:id**: 获取群组详情
- **POST /api/groups**: 创建新群组
- **PUT /api/groups/:id**: 更新群组信息
- **DELETE /api/groups/:id**: 删除群组
- **GET /api/groups/:id/members**: 获取群组成员
- **POST /api/groups/:id/members**: 添加群组成员
- **DELETE /api/groups/:id/members/:userId**: 移除群组成员

## 状态管理

群组模块的状态主要通过Redux进行管理，相关的状态切片包括：

- **groupsSlice**: 管理群组相关状态，如群组列表、当前查看的群组等
- **authSlice**: 管理用户认证状态，用于确定用户是否可以使用群组功能

# 语音模块

本目录包含零屿笔记应用的语音功能相关屏幕组件。语音模块允许用户进行语音输入、语音识别、语音笔记创建和语音命令控制等功能。

## 文件结构

- **index.js**: 语音模块导出文件，集中导出所有语音相关屏幕
- **VoiceRecognitionScreen.js**: 语音识别屏幕，用于语音转文字
- **VoiceNoteScreen.js**: 语音笔记屏幕，用于创建和管理语音笔记
- **VoiceCommandScreen.js**: 语音命令屏幕，用于语音控制应用
- **VoiceMemoScreen.js**: 语音备忘录屏幕，用于快速记录语音备忘
- **VoiceSettingsScreen.js**: 语音设置屏幕，用于管理语音相关设置
- **MeetingRecorderScreen.js**: 会议记录屏幕，用于记录和转写会议内容
- **VoiceTTSScreen.js**: 文字转语音屏幕，用于将文字转换为语音

## 主要功能

### 语音识别屏幕 (VoiceRecognitionScreen)

语音识别屏幕用于将语音转换为文字，主要功能包括：

- 实时语音识别，将用户语音转换为文字
- 支持多种语言和方言
- 显示识别结果和置信度
- 支持编辑和修正识别结果
- 支持将识别结果添加到笔记或创建新笔记

### 语音笔记屏幕 (VoiceNoteScreen)

语音笔记屏幕用于创建和管理语音笔记，主要功能包括：

- 录制语音笔记，支持长时间录制
- 自动转写语音内容为文字
- 支持混合模式（语音+文字+图片）
- 提供语音笔记列表和管理功能
- 支持语音笔记分类和标签

### 语音命令屏幕 (VoiceCommandScreen)

语音命令屏幕用于语音控制应用，主要功能包括：

- 提供语音命令列表和示例
- 支持自定义语音命令
- 显示语音命令识别结果
- 提供语音命令训练功能
- 支持离线语音命令

### 语音备忘录屏幕 (VoiceMemoScreen)

语音备忘录屏幕用于快速记录语音备忘，主要功能包括：

- 快速录制短语音备忘
- 自动转写和保存
- 支持设置提醒和标记重要性
- 提供备忘录列表和管理功能
- 支持分享和导出

### 会议记录屏幕 (MeetingRecorderScreen)

会议记录屏幕用于记录和转写会议内容，主要功能包括：

- 录制会议音频
- 自动转写会议内容
- 支持多人说话识别和区分
- 自动生成会议摘要和关键点
- 支持添加标记和注释
- 提供会议记录管理和分享功能

### 文字转语音屏幕 (VoiceTTSScreen)

文字转语音屏幕用于将文字转换为语音，主要功能包括：

- 将输入文字转换为语音
- 支持多种语言和声音
- 支持调整语速、音调和音量
- 支持保存为音频文件
- 支持朗读笔记内容

### 语音设置屏幕 (VoiceSettingsScreen)

语音设置屏幕用于管理语音相关设置，主要功能包括：

- 设置默认语音识别语言
- 设置语音识别敏感度
- 管理离线语音模型
- 设置文字转语音偏好
- 管理语音命令设置

## 使用的组件

语音模块使用了以下主要组件：

- **VoiceRecognizer**: 语音识别器组件，用于语音转文字
- **AudioRecorder**: 音频录制器组件，用于录制语音
- **AudioPlayer**: 音频播放器组件，用于播放语音
- **TranscriptionViewer**: 转写查看器组件，用于显示语音转写结果
- **CommandList**: 命令列表组件，用于显示可用语音命令
- **MeetingTranscriber**: 会议转写器组件，用于转写会议内容
- **TextToSpeech**: 文字转语音组件，用于将文字转换为语音

## 与其他模块的交互

语音模块与以下模块有交互：

- **笔记模块**: 支持将语音识别结果添加到笔记
- **提醒模块**: 支持为语音备忘设置提醒
- **AI助手模块**: 提供智能语音交互功能
- **设置模块**: 管理语音相关设置

## API交互

语音模块主要与以下API端点交互：

- **POST /api/voice/recognize**: 发送语音进行识别
- **POST /api/voice/transcribe**: 转写语音文件
- **GET /api/voice/commands**: 获取可用语音命令
- **POST /api/voice/tts**: 将文字转换为语音
- **POST /api/meetings/record**: 创建会议记录
- **GET /api/meetings/:id/transcript**: 获取会议转写内容
- **GET /api/voice/notes**: 获取语音笔记列表
- **POST /api/voice/notes**: 创建语音笔记

## 状态管理

语音模块的状态主要通过Redux进行管理，相关的状态切片包括：

- **voiceSlice**: 管理语音相关状态，如当前录制状态、识别结果等
- **meetingsSlice**: 管理会议记录相关状态

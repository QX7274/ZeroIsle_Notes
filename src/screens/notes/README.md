# 笔记模块

本目录包含零屿笔记应用的笔记相关屏幕组件，用于管理笔记的创建、编辑、查看和组织等功能。

## 文件结构

- **index.js**: 笔记模块导出文件，集中导出所有笔记相关屏幕
- **NoteScreen.js**: 笔记主屏幕，用于显示笔记列表和管理笔记
- **NoteListScreen.js**: 笔记列表屏幕，显示笔记列表，支持多种视图模式
- **NoteEditScreen.js**: 笔记编辑屏幕，用于创建和编辑笔记
- **NoteDetailScreen.js**: 笔记详情屏幕，用于查看笔记详情
- **ReminderScreen.js**: 提醒屏幕，用于管理笔记相关的提醒
- **SharedNoteScreen.js**: 共享笔记屏幕，用于查看和管理共享笔记
- **VoiceToTextScreen.js**: 语音转文本屏幕，用于将语音转换为文本并创建笔记
- **RealtimeTranscriptionScreen.js**: 实时转写屏幕，用于实时将语音转写为文本

## 主要功能

### 笔记主屏幕 (NoteScreen.js)

笔记主屏幕是用户进入笔记功能的入口，主要功能包括：

- **笔记列表管理**: 显示笔记列表，支持列表和网格视图切换
- **笔记创建**: 创建新笔记，支持多种笔记类型（文本、清单、日记等）
- **笔记导入**: 导入外部文件（PDF、Word等）作为笔记
- **笔记搜索**: 搜索笔记内容
- **笔记分类**: 按分类筛选笔记
- **笔记标签**: 按标签筛选笔记
- **笔记排序**: 按不同条件排序笔记
- **离线同步**: 管理离线笔记的同步

### 笔记编辑屏幕 (NoteEditScreen.js)

笔记编辑屏幕用于创建和编辑笔记，主要功能包括：

- **富文本编辑**: 支持格式化文本、列表、表格等
- **Markdown编辑**: 支持Markdown语法
- **多媒体插入**: 插入图片、音频、视频等
- **附件管理**: 添加和管理附件
- **标签管理**: 为笔记添加和管理标签
- **分类设置**: 设置笔记分类
- **自动保存**: 自动保存编辑内容
- **版本历史**: 查看和恢复历史版本

### 笔记详情屏幕 (NoteDetailScreen.js)

笔记详情屏幕用于查看笔记详情，主要功能包括：

- **笔记内容查看**: 查看笔记完整内容
- **多媒体查看**: 查看笔记中的图片、音频、视频等
- **附件查看**: 查看和下载附件
- **笔记分享**: 分享笔记给其他用户
- **笔记导出**: 导出笔记为不同格式
- **相关笔记**: 查看与当前笔记相关的其他笔记
- **笔记截图**: 对笔记内容进行截图

### 提醒屏幕 (ReminderScreen.js)

提醒屏幕用于管理笔记相关的提醒，主要功能包括：

- **提醒创建**: 创建新的提醒
- **提醒列表**: 查看所有提醒
- **提醒编辑**: 编辑现有提醒
- **提醒删除**: 删除不需要的提醒
- **提醒完成**: 标记提醒为已完成
- **重复提醒**: 设置重复提醒
- **提醒分类**: 对提醒进行分类管理

### 语音转文本屏幕 (VoiceToTextScreen.js)

语音转文本屏幕用于将语音转换为文本并创建笔记，主要功能包括：

- **语音录制**: 录制语音内容
- **语音识别**: 将语音转换为文本
- **实时转写**: 实时显示转写结果
- **转写编辑**: 编辑转写结果
- **创建笔记**: 将转写结果创建为笔记
- **多语言支持**: 支持多种语言的语音识别

### 实时转写屏幕 (RealtimeTranscriptionScreen.js)

实时转写屏幕用于实时将语音转写为文本，主要功能包括：

- **实时录音**: 持续录制语音
- **实时转写**: 实时将语音转换为文本
- **说话人分离**: 识别不同说话人
- **会议纪要生成**: 自动生成会议纪要
- **转写保存**: 将转写结果保存为笔记

## 与其他模块的交互

笔记模块与以下模块有交互：

- **Redux笔记状态**: 管理笔记数据和状态
- **API服务**: 与后端笔记API通信
- **存储服务**: 存储笔记内容和附件
- **同步服务**: 同步在线和离线笔记
- **AI服务**: 提供智能分析和建议功能

## 使用的组件

笔记模块使用了以下主要组件：

- **NoteList**: 笔记列表组件，显示笔记列表
- **NoteEditor**: 笔记编辑器组件，提供编辑功能
- **NoteDetail**: 笔记详情组件，显示笔记详情
- **NoteToolbar**: 笔记工具栏组件，提供编辑工具
- **TagSelector**: 标签选择器组件，用于选择和管理标签
- **CategorySelector**: 分类选择器组件，用于选择和管理分类
- **RealtimeTranscription**: 实时转写组件，提供语音转写功能
- **AudioWaveform**: 音频波形组件，显示音频波形
- **RecordButton**: 录音按钮组件，提供录音控制

## 注意事项

- 笔记内容应定期自动保存，避免数据丢失
- 离线编辑的笔记应在网络恢复后自动同步
- 大型笔记和多媒体内容可能需要优化加载性能
- 考虑多设备同步时的冲突解决策略
- 提供清晰的错误提示和恢复机制
- 注意用户隐私，确保敏感笔记内容的安全

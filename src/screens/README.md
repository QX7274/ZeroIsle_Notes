# 屏幕目录

这个目录包含应用中的所有屏幕/页面组件。

## 屏幕分类

- **认证相关**：登录、注册、密码重置等
- **笔记相关**：笔记列表、笔记编辑、笔记详情等
- **知识图谱**：知识图谱可视化、编辑等
- **设置相关**：用户设置、应用设置等
- **社区相关**：社区内容、分享、互动等

## 屏幕开发规范

1. 每个屏幕应该有自己的目录
2. 屏幕目录应包含主要组件文件和样式文件
3. 复杂屏幕可以包含特定于该屏幕的子组件
4. 屏幕组件应该专注于布局和数据流，具体UI细节应该委托给可重用组件
5. 屏幕组件应该连接到Redux或Context API进行状态管理

# 无限画布功能文档

## 概述

无限画布是一个强大的绘图和笔记功能，提供了一个可以无限放大、缩小和移动的画布空间，就像一张巨大的草稿纸。用户可以在上面自由绘画、添加图片、做笔记等。

## 功能特性

### 1. 画布样式选择
- **白色纸张**: 纯白色背景，适合一般绘画和笔记
- **淡黄色纸张**: 温暖的淡黄色背景，护眼舒适，适合长时间使用
- **方格纸**: 网格背景，适合绘制图表、几何图形和需要对齐的内容
- **横线纸**: 横线背景，适合书写文字和做笔记

### 2. 无限缩放和移动
- **缩放范围**: 0.1x - 5x，支持精细操作和宏观视图
- **双指缩放**: 使用双指手势进行缩放操作
- **单指移动**: 在手型工具模式下，单指拖拽移动画布
- **平滑操作**: 所有缩放和移动操作都有平滑的动画效果

### 3. 绘图工具
- **画笔工具**: 支持自由绘画，可调节颜色和粗细
- **手型工具**: 用于移动画布，不进行绘画
- **颜色选择**: 支持多种颜色选择
- **笔刷粗细**: 可调节画笔的粗细程度

### 4. 图片支持
- **图片导入**: 支持从相册导入图片到画布
- **图片定位**: 导入的图片会放置在画布中心位置
- **图片缩放**: 支持对导入的图片进行缩放操作

### 5. 书签功能
- **添加书签**: 可以为当前画布状态添加书签
- **书签管理**: 支持书签的查看、编辑和删除
- **快速跳转**: 点击书签可以快速跳转到对应的画布状态

### 6. 数据持久化
- **自动保存**: 画布内容会自动保存到本地存储
- **离线支持**: 完全支持离线使用，无需网络连接
- **数据恢复**: 重新打开画布时会恢复之前的绘画内容

## 技术实现

### 核心技术栈
- **React Native**: 基础框架
- **react-native-svg**: SVG绘图支持
- **react-native-gesture-handler**: 手势处理
- **PanResponder**: 触摸事件处理

### 关键组件

#### InfiniteCanvasScreen
主画布屏幕，负责：
- 画布状态管理（缩放、平移、绘图路径）
- 手势识别和处理
- 绘图渲染
- 数据持久化

#### CanvasStyleModal
画布样式选择模态框，负责：
- 展示不同的纸张样式选项
- 样式预览
- 用户选择处理

### 数据结构

#### 画布数据
```javascript
{
  id: string,              // 画布唯一标识
  title: string,           // 画布标题
  type: 'canvas',          // 类型标识
  canvasStyle: string,     // 画布样式（white/yellow/grid/lines）
  scale: number,           // 当前缩放比例
  translateX: number,      // X轴偏移
  translateY: number,      // Y轴偏移
  paths: Array,            // 绘图路径数组
  images: Array,           // 图片数组
  created_at: string,      // 创建时间
  updated_at: string       // 更新时间
}
```

#### 绘图路径
```javascript
{
  path: string,            // SVG路径字符串
  color: string,           // 画笔颜色
  width: number,           // 画笔粗细
  tool: string             // 使用的工具
}
```

#### 图片对象
```javascript
{
  id: number,              // 图片唯一标识
  uri: string,             // 图片URI
  x: number,               // X坐标
  y: number,               // Y坐标
  scale: number,           // 缩放比例
  rotation: number         // 旋转角度
}
```

## 使用方法

### 创建新画布
1. 在主界面点击"+"按钮
2. 选择"无限画布"选项
3. 在弹出的样式选择框中选择喜欢的纸张样式
4. 点击"创建画布"按钮

### 绘图操作
1. 使用工具栏选择画笔工具
2. 选择合适的颜色和粗细
3. 在画布上自由绘画

### 移动画布
1. 选择手型工具
2. 单指拖拽移动画布到想要的位置

### 缩放画布
1. 使用双指捏合手势进行缩放
2. 支持0.1x到5x的缩放范围

### 添加图片
1. 点击工具栏中的图片按钮
2. 从相册选择图片
3. 图片会自动添加到画布中心

### 添加书签
1. 点击工具栏中的书签按钮
2. 在弹出的书签面板中输入书签名称
3. 点击"添加"按钮保存书签

### 保存画布
1. 点击右上角的"保存"按钮
2. 画布内容会自动保存到本地

## 性能优化

### 渲染优化
- 使用SVG进行矢量绘图，保证缩放时的清晰度
- 路径数据采用字符串格式，减少内存占用
- 实现了增量渲染，只重绘变化的部分

### 内存管理
- 及时清理不需要的绘图路径
- 图片采用懒加载机制
- 定期清理临时数据

### 手势优化
- 使用PanResponder进行高效的手势识别
- 实现了手势防抖，避免误操作
- 优化了多点触控的处理逻辑

## 故障排除

### 常见问题
1. **画布卡顿**: 检查设备性能，减少复杂路径
2. **保存失败**: 检查存储权限和可用空间
3. **手势不响应**: 重启应用或检查手势冲突

### 调试方法
- 开启开发者模式查看控制台日志
- 使用性能监控工具检查渲染性能
- 检查内存使用情况

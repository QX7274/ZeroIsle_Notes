# 提醒屏幕目录

本目录包含与提醒功能相关的屏幕组件。

## 文件列表

- **AddReminderScreen.js**: 添加提醒屏幕，用于创建新的提醒
- **ReminderDetailScreen.js**: 提醒详情屏幕，显示提醒的详细信息
- **ReminderExportScreen.js**: 提醒导出屏幕，用于导出提醒数据

## 使用方法

```javascript
import { AddReminderScreen, ReminderDetailScreen, ReminderExportScreen } from '../screens/reminder';
```

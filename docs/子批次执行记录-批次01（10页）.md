## 2. 每页功能/子功能/验收标准

### 2.1 Home
- 功能：底部导航、主页入口、创建入口
- 子功能：
  - `nav.tab.home/ai/community/profile` 切换稳定
  - `action.home.create` 打开创建弹层稳定
  - 返回后状态不漂移
- 验收：
  - Android MCP 点击链 2 次重复通过
  - 关键锚点存在于 XML

### 2.2 AIAssistant
- 功能：AI 输入与历史
- 子功能：
  - 输入/发送可触发
  - 异常时页内提示，不能全局遮挡
  - 语音入口可点击且有明确反馈
- 验收：
  - 失败链不阻断导航
  - 锚点稳定存在

### 2.3 ReminderList
- 功能：提醒列表主操作
- 子功能：
  - 筛选、完成、删除、启停、同步提示
  - 同步状态卡可测锚点（offline/pending/syncing/error/ok）
  - 离线列表恢复与本地真相源优先
- 验收：
  - 完成/删除/启停各 1 次真机成功证据
  - 同步状态文案与实际结果一致
  - `state.reminder.syncStatus.*` 在对应状态可稳定命中

### 2.4 AddReminder
- 功能：新增提醒表单
- 子功能：
  - 标题/时间/优先级填写
  - 创建成功返回列表
  - 失败后可重试且不丢草稿
- 验收：
  - 创建链双次重放一致
  - 失败提示诚实、无系统遮挡

### 2.5 GroupList + GroupDetail
- 功能：群组入口与详情操作
- 子功能：
  - 创建/加入/详情进入
  - 邀请成员、生成加入码、共享入口权限可见
  - 操作结果页内状态反馈（替代阻断式弹窗）
- 验收：
  - 路由契约正确
  - 权限不足行为与提示一致
  - `state.group.inlineStatus.*` 可稳定命中

### 2.6 ScreenShare
- 功能：共享链路
- 子功能：
  - 共享中/观看中/空闲三态切换
  - 加入/离开/重连/结束逻辑
  - 连接状态可观测
- 验收：
  - 关键状态切换各至少 1 组真机证据
  - 不出现假活跃或状态回弹

### 2.7 Community
- 功能：社区流入口
- 子功能：
  - 首屏加载、刷新、发帖入口
  - 离线/错误页内展示
  - 分类筛选锚点可稳定定位
- 验收：
  - 无全局噪声弹窗遮挡主链
  - 锚点与入口稳定（含 `filter.community.*`）

### 2.8 Profile/Settings
- 功能：我的页入口分发
- 子功能：
  - 提醒/知识图谱/设置入口可达
  - 同步与主题入口可达
- 验收：
  - 入口点击链完整
  - 回退路径一致

### 2.9 KnowledgeGraph
- 功能：图谱主页面
- 子功能：
  - 空态/离线态
  - 分析入口、节点详情入口
- 验收：
  - 空态不报假错
  - 入口可达可回退

### 2.10 CodeEditor
- 功能：代码片段与执行
- 子功能：
  - CRUD、筛选、重跑
  - 失败保草稿
- 验收：
  - 与既有后端契约测试一致
  - 前端最小操作链可复现

## 3. UI整改清单（统一规范）
- 统一蓝白现代风 + 轻毛玻璃卡片。
- 主次按钮层级固定：主动作高亮、次动作描边。
- 列表卡片增加状态可视标签（成功/失败/离线/暂停）。
- 空态/错误/离线必须页内展示，禁止遮挡式全局噪声。
- 所有核心操作补稳定 `testID`，热区最小 44px。

## 4. 验证与证据命名规范
- 命名规范：`roundNN_page_action_(png|xml|logcat).ext`
- 示例：
  - `round65_home_nav.png`
  - `round65_reminder_toggle.xml`
  - `round65_shared_join_logcat.txt`
- 每页至少 1 组自动化证据 + 1 组真机证据。

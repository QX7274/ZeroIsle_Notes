# ZeroIsle Notes 架构文档

## 概述

ZeroIsle Notes 是一个跨平台的笔记应用，使用 React Native 开发，支持离线和在线模式。应用采用 MongoDB Realm 作为本地存储解决方案，并与 MongoDB Atlas 云数据库同步。

## 架构设计

### 数据存储架构

```
┌─────────────────────────────────────────┐
│              应用组件                    │
└───────────────┬───────────────┬─────────┘
                │               │
┌───────────────▼───┐   ┌───────▼───────┐
│  领域特定存储接口   │   │  同步管理器   │
│ (authStorage等)   │   │ (syncManager) │
└───────────────┬───┘   └───────┬───────┘
                │               │
┌───────────────▼───────────────▼───────┐
│            RealmService              │
└───────────────────────────────────────┘
                    │
┌───────────────────▼───────────────────┐
│            MongoDB Realm              │
└───────────────────────────────────────┘
                    │
                    ▼
┌───────────────────────────────────────┐
│            MongoDB Atlas              │
└───────────────────────────────────────┘
```

### 核心组件

1. **Realm 服务层**
   - `realmService.js`: 提供对 Realm 数据库的基本操作
   - `realmModels.js`: 定义所有 Realm 模型
   - `realmQueries.js`: 提供优化的查询方法
   - `realmConfig.js`: 配置 Realm 数据库

2. **领域特定存储接口**
   - `authStorage.js`: 提供认证相关的存储功能
   - `apiCache.js`: 提供 API 缓存功能
   - `realmStorage.js`: 为 Redux 持久化提供存储接口

3. **同步管理器**
   - `syncManager.js`: 管理本地数据与云端数据的同步

4. **服务适配器**
   - `mongoDBAdapter.js`: 提供与旧 MongoDB 服务兼容的 API

## 数据流

### 本地数据流

1. **读取数据**
   ```
   应用组件 -> 领域特定服务 -> realmQueries -> realmService -> MongoDB Realm
   ```

2. **写入数据**
   ```
   应用组件 -> 领域特定服务 -> realmQueries -> realmService -> MongoDB Realm
                                                  |
                                                  v
                                             syncManager
                                             (记录待同步操作)
   ```

### 同步数据流

1. **上传数据**
   ```
   syncManager -> 查找未同步数据 -> API 服务 -> MongoDB Atlas
                                      |
                                      v
                      更新本地数据的同步状态 (is_synced = true)
   ```

2. **下载数据**
   ```
   syncManager -> API 服务 -> MongoDB Atlas
                     |
                     v
               更新本地数据
   ```

## 离线支持

应用支持完全离线工作模式：

1. 所有操作优先保存在本地 MongoDB Realm 数据库
2. 操作被标记为未同步 (is_synced = false)
3. 当网络恢复时，syncManager 会自动同步未同步的数据
4. 同步冲突通过时间戳和版本号解决

## 优化策略

### 查询优化

1. **使用索引**
   - 所有模型的主键 (_id) 自动索引
   - 为常用查询字段添加索引，如 is_deleted, is_synced

2. **批量操作**
   - 使用批量插入、更新和删除操作减少数据库事务
   - 使用事务包装多个操作，确保原子性

3. **延迟加载**
   - 大型集合使用分页加载
   - 使用投影查询只获取必要字段

### 同步优化

1. **增量同步**
   - 只同步上次同步后更改的数据
   - 使用时间戳跟踪更改

2. **批量同步**
   - 将多个同步操作批量处理
   - 并行处理不同类型的数据同步

3. **节流和防抖**
   - 限制同步频率，避免频繁网络请求
   - 自动合并短时间内的多个同步请求

4. **优先级同步**
   - 关键数据优先同步
   - 大型数据（如附件）后台同步

## 错误处理

1. **优雅降级**
   - 当 Realm 操作失败时，尝试使用备用存储
   - 网络请求失败时，自动重试并记录失败操作

2. **数据恢复**
   - 定期备份本地数据库
   - 提供数据导入/导出功能

3. **冲突解决**
   - 使用乐观锁和版本控制解决同步冲突
   - 在必要时提供用户选择冲突解决方案的界面

## 安全性

1. **数据加密**
   - 敏感数据在本地加密存储
   - 传输中的数据使用 HTTPS 加密

2. **认证**
   - 使用 JWT 令牌进行 API 认证
   - 支持离线认证

## 性能指标

1. **启动时间**
   - 应用冷启动时间 < 2 秒
   - 数据库初始化时间 < 500 毫秒

2. **查询性能**
   - 列表查询响应时间 < 100 毫秒
   - 单条记录查询响应时间 < 50 毫秒

3. **同步性能**
   - 增量同步时间 < 5 秒
   - 全量同步时间 < 30 秒（取决于数据量）

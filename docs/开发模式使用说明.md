# 开发模式使用说明

## 概述

为了方便开发调试，项目已添加了开发模式功能，可以在开发环境下跳过登录步骤，直接进入应用进行使用和调试。

## 功能特性

- ✅ 开发模式下自动跳过登录
- ✅ 自动设置默认开发用户
- ✅ 无需网络连接即可使用
- ✅ 支持离线调试
- ✅ 可动态切换开发模式配置

## 配置说明

### 主配置文件

配置位于 `src/config/index.js` 文件中：

```javascript
// 开发模式配置
export const DEV_CONFIG = {
  // 开发模式下跳过登录
  SKIP_LOGIN: __DEV__ && true, // 设置为 true 时在开发模式下跳过登录
  
  // 开发模式下使用的默认用户信息
  DEFAULT_USER: {
    id: 'dev-user-001',
    username: 'developer',
    email: 'dev@zeroislenotes.com',
    nickname: '开发者',
    avatar: null,
    isAnonymous: false,
    isDeveloper: true,
    createdAt: new Date().toISOString(),
  },
  
  // 开发模式下使用的默认令牌
  DEFAULT_TOKEN: 'dev-token-' + Date.now(),
};
```

### 启用/禁用开发模式

1. **启用开发模式跳过登录**：
   - 将 `DEV_CONFIG.SKIP_LOGIN` 设置为 `true`
   - 重新运行 `yarn android`

2. **禁用开发模式跳过登录**：
   - 将 `DEV_CONFIG.SKIP_LOGIN` 设置为 `false`
   - 重新运行 `yarn android`

## 使用方法

### 1. 启动应用

```bash
yarn android
```

当开发模式启用时，应用会：
- 自动跳过登录屏幕
- 设置默认开发用户
- 直接进入主界面

### 1.1 启动本地共享链联调入口

当需要为“群组/协作 -> 屏幕共享”做本地双端联调时，当前仓库默认不要直接假设 Electron 或 React Native Web 主应用已经完整闭环，而是先启动本地联调壳：

```bash
yarn local:web
```

启动成功后可访问：

- `http://127.0.0.1:8091/shared-screen-lab/`
- `http://127.0.0.1:8091/index.html`

说明：

- `shared-screen-lab` 是批次05新增的本地共享链诊断页，用于汇总群组 ID、共享会话 ID、WebRTC 房间、连接现象与关键时间线，并支持复制联调摘要。
- 该入口的目标是把 `localhost:8091` 收敛成稳定可访问的本地联调入口，同时把 `localhost:8081` 留给 React Native Metro，降低共享链和真机调试的互相干扰。
- 该入口不等同于 React Native Web 主应用已补齐，也不等同于 Android 专用 MCP 真机可视化验证完成。
- Android 主链仍然统一使用 `yarn android`；真机调试继续优先使用 USB + `adb reverse tcp:8081 tcp:8081`。

### 1.2 启动共享链最小 API 联调脚本

当需要在真机前先确认“认证、群组、共享 HTTP 契约”是否可达时，统一使用正式脚本，不再继续依赖临时 `tmp_*` 调试文件：

```bash
cd backend
python scripts/shared_screen_smoke.py --base-url http://127.0.0.1:8001/api/v1
```

推荐前置：

- `DJANGO_ENV=testing`，用于最小契约联调，默认走 `mongomock`
- 若要验证更接近真实共享链的 HTTP 路径，再切到 `DJANGO_ENV=development` 并自行准备 MongoDB

脚本默认验证：

- `POST /api/v1/auth/register/username/`
- `POST /api/v1/auth/login/`
- `POST /api/v1/groups/`
- `POST /api/v1/groups/{id}/generate-join-code/`
- `POST /api/v1/groups/shared-screens/`
- `GET /api/v1/groups/shared-screens/`
- `GET /api/v1/groups/shared-screens/{id}/join/`

边界说明：

- 该脚本只证明共享 HTTP 最小契约链路可达
- 不等同于 WebRTC 端到端联调完成
- 不等同于 Android 专用 MCP 真机可视化验证完成


### 3. 动态切换配置

在React Native调试器控制台中，您可以动态切换配置：

```javascript
// 切换跳过登录状态
require('./src/utils/devMode').toggleSkipLogin()

// 启用跳过登录
require('./src/utils/devMode').enableSkipLogin()

// 禁用跳过登录
require('./src/utils/devMode').disableSkipLogin()
```

## 工作原理

### 1. 配置检查

应用启动时会检查 `DEV_CONFIG.SKIP_LOGIN` 配置：

```javascript
// 在 src/App.js 中
const { DEV_CONFIG } = require('./config');
if (DEV_CONFIG.SKIP_LOGIN) {
  console.log('开发模式：跳过令牌检查，直接进行认证状态检查');
  await dispatch(checkAuthState()).unwrap();
  return;
}
```

### 2. 认证状态管理

在Redux认证状态检查中：

```javascript
// 在 src/redux/slices/authSlice.js 中
if (DEV_CONFIG.SKIP_LOGIN) {
  console.log('Redux: 开发模式 - 跳过认证检查，自动设置为已认证');
  
  const devUser = DEV_CONFIG.DEFAULT_USER;
  const devToken = DEV_CONFIG.DEFAULT_TOKEN;
  
  // 设置Redux状态
  dispatch({ type: 'auth/setIsAuthenticated', payload: true });
  dispatch({ type: 'auth/setUserInfo', payload: devUser });
  dispatch({ type: 'auth/setAuthToken', payload: devToken });
  
  return { user: devUser, token: devToken, refreshToken: devToken };
}
```

### 3. 服务层支持

认证服务也支持开发模式：

```javascript
// 在 src/services/auth/authService.js 中
async isLoggedIn() {
  const { DEV_CONFIG } = require('../../config');
  if (DEV_CONFIG.SKIP_LOGIN) {
    console.log('开发模式：跳过登录检查，自动设置为已登录状态');
    
    if (!this.currentUser) {
      this.currentUser = DEV_CONFIG.DEFAULT_USER;
      await authStorage.saveUser(this.currentUser);
      await authStorage.saveToken(DEV_CONFIG.DEFAULT_TOKEN);
    }
    
    return true;
  }
  // ... 正常登录检查逻辑
}
```

## 注意事项

1. **仅在开发环境有效**：开发模式功能只在 `__DEV__` 为 `true` 时生效
2. **生产环境自动禁用**：在生产环境构建时，开发模式功能会被自动禁用
3. **数据隔离**：开发模式使用的是模拟数据，不会影响真实用户数据
4. **网络独立**：开发模式下不依赖网络连接，可以完全离线使用

## 故障排除

### 问题1：开发模式未生效

**解决方案**：
1. 确认 `DEV_CONFIG.SKIP_LOGIN` 设置为 `true`
2. 确认当前为开发环境（`__DEV__` 为 `true`）
3. 重新运行 `yarn android`

### 问题2：应用仍然显示登录界面

**解决方案**：
1. 检查控制台日志，确认开发模式日志是否出现
2. 清除应用缓存：`yarn android --reset-cache`
3. 重新安装应用

### 问题3：想要恢复正常登录流程

**解决方案**：
1. 将 `DEV_CONFIG.SKIP_LOGIN` 设置为 `false`
2. 重新运行 `yarn android`
3. 或者在控制台执行：`require('./src/utils/devMode').disableSkipLogin()`

## 自定义开发用户

您可以根据需要修改默认开发用户信息：

```javascript
// 在 src/config/index.js 中修改
DEFAULT_USER: {
  id: 'your-dev-user-id',
  username: 'your-username',
  email: 'your-email@example.com',
  nickname: '您的昵称',
  // ... 其他字段
},
```

这样就可以实现在开发调试时跳过登录，直接进入应用进行使用和调试了

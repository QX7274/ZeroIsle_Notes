# API 错误码手册

**版本**: 1.0  
**最后更新**: 2025-12-14

---

## 概述

所有ZeroIsle_Notes API端点都遵循统一的响应格式和错误码体系。

### 响应格式

**成功响应** (HTTP 200):
```json
{
  "code": 0,
  "message": "success",
  "data": {...}
}
```

**错误响应** (HTTP 4xx/5xx):
```json
{
  "code": 1001,
  "message": "未认证",
  "data": null
}
```

---

## 错误码分类

### 1xxx - 认证/授权错误

| 错误码 | HTTP状态 | 含义 | 说明 |
|--------|---------|------|------|
| 1001 | 401 | 未认证 | 用户未登录或Token无效 |
| 1002 | 403 | 权限不足 | 用户无权访问该资源 |
| 1003 | 401 | Token已过期 | 需要刷新Token |
| 1004 | 401 | Token无效 | Token格式错误或被篡改 |
| 1005 | 401 | 凭证无效 | 用户名或密码错误 |

**处理建议**:
- 1001/1003/1004: 清除本地Token，重定向到登录页面
- 1002: 显示权限不足提示，不允许操作
- 1005: 显示登录失败提示，允许重试

---

### 2xxx - 资源错误

| 错误码 | HTTP状态 | 含义 | 说明 |
|--------|---------|------|------|
| 2001 | 404 | 资源不存在 | 请求的资源不存在 |
| 2002 | 409 | 资源冲突 | 资源已存在或状态冲突 |
| 2003 | 410 | 资源已删除 | 请求的资源已被删除 |

**处理建议**:
- 2001: 显示"资源不存在"提示
- 2002: 显示冲突提示，可能需要刷新或重试
- 2003: 显示"资源已删除"提示

---

### 3xxx - 业务逻辑错误

| 错误码 | HTTP状态 | 含义 | 说明 |
|--------|---------|------|------|
| 3001 | 400 | 输入无效 | 请求参数不符合要求 |
| 3002 | 400 | 操作失败 | 业务操作执行失败 |
| 3003 | 400 | 状态无效 | 资源状态不允许该操作 |
| 3004 | 429 | 配额超限 | 超过使用限制 |
| 3005 | 400 | 重复条目 | 数据重复 |

**处理建议**:
- 3001: 显示验证错误提示，指出具体错误字段
- 3002: 显示操作失败提示，可能需要重试
- 3003: 显示状态错误提示，说明当前状态不允许操作
- 3004: 显示配额超限提示，建议升级或等待
- 3005: 显示重复提示，建议修改内容后重试

---

### 31xx - AI服务特定错误

| 错误码 | HTTP状态 | 含义 | 说明 |
|--------|---------|------|------|
| 3100 | 500 | AI服务错误 | AI服务调用失败 |
| 3101 | 429 | AI速率限制 | 超过API调用频率限制 |
| 3102 | 400 | AI模型无效 | 指定的模型不存在 |
| 3103 | 504 | AI超时 | AI服务响应超时 |

**处理建议**:
- 3100: 显示"AI服务暂时不可用"提示，建议稍后重试
- 3101: 显示"请求过于频繁"提示，建议等待后重试
- 3102: 显示"模型不可用"提示，检查配置
- 3103: 显示"请求超时"提示，建议重试

---

### 5xxx - 服务器错误

| 错误码 | HTTP状态 | 含义 | 说明 |
|--------|---------|------|------|
| 5000 | 500 | 服务器错误 | 内部服务器错误 |
| 5001 | 503 | 服务不可用 | 服务暂时不可用 |
| 5002 | 500 | 数据库错误 | 数据库操作失败 |
| 5003 | 502 | 外部服务错误 | 调用外部服务失败 |
| 5004 | 500 | 文件操作错误 | 文件操作失败 |

**处理建议**:
- 5000/5002/5004: 显示"服务器错误"提示，建议联系管理员
- 5001: 显示"服务维护中"提示，建议稍后重试
- 5003: 显示"外部服务错误"提示，建议稍后重试

## 使用示例

### 后端返回错误

```python
from common.api_response import APIResponse
from common.error_codes import UNAUTHORIZED, NOT_FOUND

# 未认证错误
return APIResponse.unauthorized('用户未登录')

# 资源不存在
return APIResponse.not_found('笔记不存在')

# 自定义错误
return APIResponse.error(
    message='操作失败',
    code=3002,
    status_code=status.HTTP_400_BAD_REQUEST
)
```

### 前端处理错误

```javascript
// 在API客户端中统一处理
instance.interceptors.response.use(
  response => {
    const { code, message, data } = response.data;
    if (code !== 0) {
      // 根据错误码处理
      if (code === 1001 || code === 1003) {
        // Token过期，重定向到登录
        redirectToLogin();
      } else if (code === 1002) {
        // 权限不足
        showError('权限不足');
      } else {
        // 其他错误
        showError(message);
      }
      throw new Error(message);
    }
    return data;
  }
);
```

## 错误码查询

```python
from common.error_codes import get_error_message

message = get_error_message(1001)  # 返回 '未认证'
```

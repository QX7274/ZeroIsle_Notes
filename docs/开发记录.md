## 2026-10-03：手写体验与工具栏专项（死接线收口 + iOS 分页笔迹 + 防误触/标尺/网格）

- 关联风险：`RISK-INK-001`、`RISK-INK-002`、`RISK-INK-003`（本轮关闭源码级）、`RISK-INK-004`~`RISK-INK-006`（新登记）。
- 固定环境：前端 Jest/ESLint 与 Node 22；Android 用本机 JDK17（`/Users/apple/jdk`）+ `/Users/apple/android-sdk` + AVD；iOS 用 Xcode 26.6 模拟器。
- **根因（本轮核心发现）**：工具栏「JS 发出去了、原生从未接收/从未渲染」的静默死接线共 7 类。①`setToolConfig` 在 Android 分页/无限只 `Log.d` 后丢弃 → 笔型/压感/速度/起收笔/平滑/透明度全部空转；②`setInteractionMode` JS 每步都发，三端 ViewManager 都没注册；③`onHistoryStateChange` 只有 PDF 发，分页/无限撤销按钮恒灰；④工具栏 `mode` 默认 `'canvas'` 且四个调用点都没传 → PDF 拿不到书签组、Markdown 按 canvas 渲染；⑤`showRuler`/`showGrid` 只改 JS 本地 state、从不下发原生；⑥套索 `onStrokesSelected` 在分页/无限 ViewManager 未注册；⑦Android 分页 `clear()` 忽略 scope。
- **iOS 最大缺口**：`ios/NativePagedNoteView/NativePagedNoteView.m` 的 Metal 渲染方法（`renderStrokesWithEncoder`/`renderLinesWithEncoder`/`renderGridWithEncoder`/`renderDotsWithEncoder`）全是空实现（只有 `(void)encoder;`）。iOS 分页笔记可达（路由 `FluidPagedNote`），用户能看到纸张但**看不到任何笔迹**。本轮改用稳定的 `CAShapeLayer` 图层：新增 `worldToScreen:`/`rebuildStrokeLayers`/`appendStroke:toPath:`/`effectiveStrokeWidth`/`effectiveOpacity`，并在 `layoutSubviews` 跟随尺寸重建。
- **iOS 防误触**：此前 iOS 完全不做 `UITouch.type` 判断，手指/掌托与 Apple Pencil 一样留墨。新增 `shouldDrawWithTouch:`（按 `UITouchTypePencil`）与 `updateAllowedTouchTypes`（防误触开启时把平移手势限制为 Pencil），分页与无限两端一致。
- **JS 侧**：`nativeCommandMap.js` 的 `getSurfaceCommandNames` 去重；`AllInOneToolbar.js` 新增 `paged` 工具配置、删除死常量 `FUNCTION_SHORTCUTS`、新增「防误触」「手指书写」按钮，并把 `showRuler/showGrid/palmRejectionEnabled/fingerMode` 并入 `toolConfig` 载荷；`ViewerLayout.js` 新增 `toolbarMode` prop 并由四个调用点分别传 `paged/canvas/pdf/markdown`；分页/无限屏幕接入 `toolbarHistoryState`（撤销/重做可用态）、`selectedStrokeIds`。
- **Android 原生**：`NativePagedNoteView`/`NativeInfiniteCanvasView` 的 `setToolConfig` 真正解析全部手感字段；新增 `setInteractionMode`、`shouldDrawWithTouch`、`clamp01`、`baseWidthForTool`/`effectiveWidth`/`alphaForTool`/`applyBlendMode`；`continueStroke` 加速度感线宽；`clear(scope)`、`undo/redo/endStroke/endLassoSelection` 发 `onHistoryStateChange`/`onStrokesSelected`；两个 ViewManager 注册新命令与事件；分页与无限都新增标尺/网格覆盖层绘制。
- **测试**：新增 `src/config/__tests__/nativeCommandMap.test.js`、`src/hooks/__tests__/useNativeToolbarBridge.test.js`、`src/components/common/__tests__/AllInOneToolbar.wiring.test.js`，把「工具栏点击 → toolConfig 载荷 → 原生命令」链路固定为回归门禁。
- 证据边界：以上均为**源码级 + Jest 单测**证据；Android 需 Gradle 编译 + AVD 实测、iOS 需 xcodebuild + 模拟器实测，见下一条「设备验证」结论。

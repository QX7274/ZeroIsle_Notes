# 页面能力矩阵（第一版）

> 目的：将整改从 GAP 级下钻到“页面 + 功能 + 子功能”级，直接指导开发、验证与提交流程。  
> 对齐总控：[生产上线整改总控](D:/ZeroIsle_Notes/docs/生产上线整改总控.md)  
> 对齐台账：[DOC_GAP_TRACKER](D:/ZeroIsle_Notes/docs/DOC_GAP_TRACKER.md)

## 1. 字段定义
- 页面ID：唯一标识，格式 `PAGE-域-名称`
- 路由名：导航中的 route 名称
- 业务域：主页/AI/提醒/群组/社区/我的/知识图谱/代码编辑等
- 优先级：P0/P1/P2
- 当前状态：TODO/IN_PROGRESS/DONE/BLOCKED
- 功能项：页面主职责
- 子功能项：可执行动作集合
- 依赖接口：后端 API 或本地服务
- 状态源：RTK slice 或本地状态
- 降级态：离线/失败时页内行为
- testID：关键锚点集合
- 真机证据路径：Android MCP 产物路径
- 风险：当前核心风险
- 绑定GAP：必须绑定一个活跃 GAP

## 3. 执行规则（页面级）
- 每个页面每轮至少推进 1 个“子功能验收标准”。
- 每个页面每轮至少回填 1 条“自动化或真机证据”。
- 页面未绑定 GAP 不允许进入实施状态。
- 页面级变更提交后，必须同步更新本矩阵“当前状态/风险/证据路径/最近提交”。

## 当前开发与验收口径（2026-07-15）

- **Python 环境**：后端、脚本和测试统一使用 Conda 环境 `ZeroIsle`；不要把系统 Python 或仓库内失效的 `.venv` 作为验收依据。
  - Windows 推荐：`conda activate ZeroIsle`
  - 非交互命令：`conda run -n ZeroIsle python -X utf8 <命令>`
  - 当前机器 Conda 安装目录：`D:\APP\Anaconda`；若 PowerShell 未注册 `conda`，使用 `D:\APP\Anaconda\condabin\conda.bat run -n ZeroIsle ...`。
- **移动端验收设备**：以 Android 平板真机为准，优先 USB + ADB 联调；模拟器只用于补充性回归。
- **认证范围**：开发和功能验收不测试登录、注册、验证码及第三方登录流程；启动后直接使用开发者账户进入软件，再测试登录后的业务功能。
- **开发者账号**：账号信息由本地开发环境提供；前端密码通过 \`ZEROISLE_DEV_PASSWORD\`、后端开发认证密码通过 \`ZEROISLE_DEV_USER_PASSWORD\` 注入，密码不得写入 Git、文档、截图或测试日志；生产构建不得启用开发态跳过登录或开发者直登。
- **测试重点**：笔记、同步、AI、社区、提醒、群组/共享、知识图谱、附件和页面交互等登录后链路；每轮必须保留平板真机证据。

标准命令：

```powershell
conda run -n ZeroIsle python -X utf8 -m pytest -q
yarn test --runInBand --watch=false
yarn lint
yarn android
```

## macOS 接续开发（2026-09-27 已打通）

本机（Apple Silicon）已具备可复现的构建与调试链路，命令如下：

```bash
# 1) 依赖（本机用 npm 安装；仓库仍以 yarn.lock 为准）
npm install --registry=https://registry.npmmirror.com --legacy-peer-deps

# 2) 工具链：JDK17 与 Android SDK 均为用户态安装
export JAVA_HOME=$HOME/jdk/Contents/Home          # Temurin 17
export ANDROID_HOME=$HOME/android-sdk             # platform-tools / platforms 34+35 / build-tools 34.0.0 / ndk 26.1.10909125 / cmake 3.22.1 / emulator

# 3) 构建与安装
cd android && ./gradlew assembleDebug -PreactNativeArchitectures=arm64-v8a
adb -s emulator-5554 install -r -t app/build/outputs/apk/debug/app-debug.apk

# 4) Metro（本机 8081 被占用时用 8082，并把设备端口反向映射到它）
node node_modules/react-native/cli.js start --port 8082 --no-interactive
adb -s emulator-5554 reverse tcp:8081 tcp:8082
```

已知的本机坑位与对策：

- `android/gradle/wrapper/gradle-wrapper.properties` 过去指向 `file:///D:/Gradle-8/...`，已改为官方分发地址；如需离线构建可在本机自行改回本地路径。
- `android/settings.gradle` 原自动链接命令固定使用 Windows 的 `cmd /c`，已按平台分支（macOS/Linux 直接调用 `node`）。
- 本机 macOS 系统代理指向 `127.0.0.1:7897` 但代理未运行时，Gradle 依赖下载会长时间挂起；已在 `~/.gradle/gradle.properties` 关闭系统代理并使用 `~/.gradle/init.gradle` 的国内镜像。
- `google-services.json` 与 `debug.keystore` 属本地注入资产（已被 `.gitignore` 排除）。缺失时：Firebase 插件会跳过（提供 `android/app/google-services.json.example` 模板）；debug keystore 可用 `keytool -genkeypair -storetype PKCS12 -keystore android/app/debug.keystore -alias androiddebugkey -storepass android -keypass android -dname "CN=Android Debug,O=Android,C=US"` 生成。
- 取证脚本：`node scripts/android/capture_emulator_round.js --round <名称> [--tap testID:xxx|text:xxx] [--assert a,b]`，跨平台输出 UI XML + PNG 到 `.local/android-evidence/`。
- 真机验收口径不变：平板真机优先，模拟器用于补充性回归；模拟器结论需在 `docs/测试证据索引.md` 标注 `PASS_FOR_EMULATOR`。

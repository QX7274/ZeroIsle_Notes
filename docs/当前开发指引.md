## 当前开发与验收口径（2026-07-15）

- **Python 环境**：后端、脚本和测试统一使用 Conda 环境 `ZeroIsle`；不要把系统 Python 或仓库内失效的 `.venv` 作为验收依据。
  - Windows 推荐：`conda activate ZeroIsle`
  - 非交互命令：`conda run -n ZeroIsle python -X utf8 <命令>`
  - 当前机器 Conda 安装目录：`D:\APP\Anaconda`；若 PowerShell 未注册 `conda`，使用 `D:\APP\Anaconda\condabin\conda.bat run -n ZeroIsle ...`。
- **移动端验收设备**：以 Android 平板真机为准，优先 USB + ADB 联调；模拟器只用于补充性回归。
- **认证范围**：开发和功能验收不测试登录、注册、验证码及第三方登录流程；启动后直接使用开发者账户进入软件，再测试登录后的业务功能。
- **开发者账号**：账号信息由本地开发环境提供；前端密码通过 \`ZEROISLE_DEV_PASSWORD\`、后端开发认证密码通过 \`ZEROISLE_DEV_USER_PASSWORD\` 注入，密码不得写入 Git、文档、截图或测试日志；生产构建不得启用开发态跳过登录或开发者直登。
- **测试重点**：笔记、同步、AI、社区、提醒、群组/共享、知识图谱、附件和页面交互等登录后链路；每轮必须保留平板真机证据。

标准命令：

```powershell
conda run -n ZeroIsle python -X utf8 -m pytest -q
yarn test --runInBand --watch=false
yarn lint
yarn android
```

## 当前保留原则
- 只改明显原始、明显影响体验的界面。
- 成熟区域尽量不动，保持风格一致。
- 返回按钮统一样式，网络错误统一弹窗样式。
- 顶部布局要兼容平板状态栏，避免内容被遮挡。
- `plans/` 的详细轮次文档已浓缩到 `docs/历史轮次摘要.md`，后续不再新增重复正文。
- `plans/` 当前只作为过渡目录使用，轮次结论已合并进正式文档后统一删除，不再保留详细过程稿。
- 文档只保留结论、规则和后续行动，不保留冗长过程记录。

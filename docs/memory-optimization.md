# 内存限制优化说明

## 概述
为了解决应用中的内存分配错误（OOM - Out of Memory），我们对整个应用的内存管理系统进行了全面优化，大幅提高了内存限制和优化了内存管理机制。

## 主要优化内容

### 1. Android应用配置优化

#### AndroidManifest.xml 配置
- 添加了 `android:largeHeap="true"` 启用大堆内存
- 添加了 `android:hardwareAccelerated="true"` 启用硬件加速
- 这些配置允许应用使用更多的系统内存

#### gradle.properties 配置
- 将JVM内存从4GB提升到8GB：`-Xmx8192m`
- 增加元空间大小到2GB：`-XX:MaxMetaspaceSize=2048m`
- 启用G1垃圾收集器：`-XX:+UseG1GC`
- 优化GC暂停时间：`-XX:MaxGCPauseMillis=200`

### 2. 内存管理器配置优化

#### MemoryManager.js 配置提升
- 警告阈值：从30MB提升到200MB
- 严重阈值：从50MB提升到400MB
- 最大内存：从80MB提升到1GB
- 压缩级别：从0.8降低到0.6，提高性能
- 缓存项目数：从100增加到500

#### UniversalMemoryAllocator.js 配置提升
- 最大内存：从4GB提升到8GB
- 文档类型内存倍数大幅提升：
  - PDF：从2倍提升到3倍，最大4GB
  - Word/PPT：从3倍提升到4倍，最大8GB
  - Excel：从2倍提升到3倍，最大4GB
- 图片类型：从1.5倍提升到2倍，最大2GB
- 视频类型：从1.2倍提升到1.5倍，最大4GB
- 音频类型：从1.1倍提升到1.5倍，最大1GB
- 文本类型：从1.5倍提升到2倍，最大512MB

#### LargeMemoryAllocator.js 配置提升
- 最大内存：从4GB提升到8GB
- PPT处理内存：从3倍提升到4倍，最大4GB

### 3. 新增内存监控系统

#### MemoryMonitor.js 服务
- 实时监控内存使用情况
- 自动内存清理机制
- 内存优化策略
- 应用状态监听
- 内存使用统计

#### 监控配置
- 监控间隔：5秒
- 警告阈值：60%内存使用率
- 严重阈值：80%内存使用率
- 紧急阈值：90%内存使用率
- 自动清理：启用
- 清理延迟：2秒

### 4. 统一内存配置

#### memoryConfig.js 配置文件
- 统一管理所有内存相关配置
- 支持不同文件类型的内存配置
- 提供内存计算和检查工具函数
- 支持Android和iOS平台特定配置

## 技术特性

### 自动内存管理
- 实时监控内存使用情况
- 根据内存使用率自动执行清理
- 应用进入后台时自动清理内存
- 紧急情况下执行强制清理

### 智能内存分配
- 根据文件类型智能分配内存
- 支持大文件处理（最大8GB）
- 内存不足时自动优化和清理
- 防止内存泄漏和OOM错误

### 性能优化
- 使用G1垃圾收集器提高性能
- 硬件加速支持
- 内存压缩和缓存优化
- 异步内存操作避免阻塞UI

## 使用说明

### 自动启动
内存监控会在分页笔记屏幕启动时自动开始，无需手动配置。

### 内存清理
系统会在以下情况自动清理内存：
- 内存使用率达到60%时开始优化
- 内存使用率达到80%时执行清理
- 内存使用率达到90%时执行紧急清理
- 应用进入后台时自动清理

### 手动控制
如果需要手动控制内存，可以使用以下方法：
```javascript
import MemoryMonitor from '../services/memory/MemoryMonitor';

// 获取内存状态
const status = MemoryMonitor.getCurrentStatus();

// 手动执行清理
await MemoryMonitor.performCleanup();

// 停止监控
MemoryMonitor.stopMonitoring();
```

## 效果预期

通过这些优化，应用现在可以：
- 处理更大的文件（最大8GB内存）
- 避免OOM错误
- 自动管理内存使用
- 提供更好的用户体验
- 支持更复杂的文档处理任务

## 注意事项

1. 大内存使用可能会影响设备性能，建议在内存充足的设备上使用
2. 系统会自动监控和优化内存使用，无需手动干预
3. 如果仍然遇到内存问题，可以尝试重启应用或关闭其他应用
4. 内存监控会消耗少量系统资源，但相比内存优化带来的好处是值得的

## 监控和调试

可以通过以下方式监控内存使用情况：
- 查看控制台日志中的内存监控信息
- 使用MemoryMonitor.getMemoryStats()获取详细统计
- 观察应用的内存使用模式
- 根据需要进行进一步的优化调整

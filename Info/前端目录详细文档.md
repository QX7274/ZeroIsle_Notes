## 3. 前端组件详解

### 3.1 通用组件 (components/common/)

这些组件在整个应用中被广泛使用，提供基础UI功能。

- **Button.js**: 自定义按钮组件
  - 支持多种样式：主要、次要、危险、链接等
  - 支持多种状态：默认、禁用、加载中
  - 支持图标和文本组合
  - 支持自定义大小和形状
  - 支持触摸反馈效果

- **Card.js**: 卡片容器组件
  - 支持阴影和边框样式
  - 支持可折叠功能
  - 支持头部、内容、底部区域
  - 支持手势交互（滑动、长按）
  - 支持动画效果

- **Header.js**: 应用头部组件
  - 包含标题、返回按钮、操作按钮
  - 支持透明度变化效果
  - 支持搜索框集成
  - 支持自定义右侧操作区
  - 支持滚动时的样式变化

- **Input.js**: 输入框组件
  - 支持多种输入类型：文本、数字、密码等
  - 支持表单验证和错误提示
  - 支持前缀和后缀图标
  - 支持清除按钮和密码可见切换
  - 支持自动完成和建议列表

- **Loading.js**: 加载指示器组件
  - 支持全屏和局部加载状态
  - 支持多种动画样式
  - 支持进度指示
  - 支持自定义文本提示
  - 支持超时处理

- **Modal.js**: 模态框组件
  - 支持多种动画效果
  - 支持自定义头部和底部
  - 支持背景点击关闭
  - 支持键盘事件处理
  - 支持嵌套模态框

- **Toast.js**: 提示消息组件
  - 支持多种类型：成功、错误、警告、信息
  - 支持自定义显示时长
  - 支持队列管理
  - 支持手势关闭
  - 支持位置自定义

- **Avatar.js**: 头像组件
  - 支持图片和文字头像
  - 支持多种尺寸和形状
  - 支持徽章显示
  - 支持组合头像

- **Badge.js**: 徽章组件
  - 支持数字和文本显示
  - 支持最大值设置
  - 支持自定义颜色和位置
  - 支持动画效果
  - 支持点状徽章

- **Divider.js**: 分割线组件
  - 支持水平和垂直方向
  - 支持带文本的分割线

## 5. 导航结构

### 5.1 AppNavigator.js

应用主导航器，根据认证状态决定显示认证导航还是主功能导航。

```javascript
const AppNavigator = () => {
  // ...
  return (
    <NavigationContainer onStateChange={onStateChange}>
      <Stack.Navigator screenOptions={{ headerShown: false }}>
        {isAuthenticated ? (
          <Stack.Screen name="MainTabs" component={MainTabs} />
        ) : (
          <Stack.Screen name="Auth" component={AuthNavigator} />
        )}
      </Stack.Navigator>
    </NavigationContainer>
  );
};
```

### 5.2 主标签导航 (MainTabs)

底部标签导航，包含主要功能模块。

```javascript
const MainTabs = () => {
  return (
    <Tab.Navigator>
      <Tab.Screen name="HomeStack" component={HomeStack} options={{ title: '首页' }} />
      <Tab.Screen name="CategoryStack" component={CategoryStack} options={{ title: '分类' }} />
      <Tab.Screen name="CommunityStack" component={CommunityStack} options={{ title: '社区' }} />
      <Tab.Screen name="Settings" component={SettingsScreen} options={{ title: '设置' }} />
    </Tab.Navigator>
  );
};
```

### 5.3 功能堆栈导航

各功能模块的堆栈导航，用于在相关屏幕间导航。

```javascript
const HomeStack = () => (
  <Stack.Navigator>
    <Stack.Screen name="Home" component={HomeScreen} />
    <Stack.Screen name="Note" component={NoteScreen} />
  </Stack.Navigator>
);

const CategoryStack = () => (
  <Stack.Navigator>
    <Stack.Screen name="CategoryList" component={CategoryScreen} />
    <Stack.Screen name="NoteList" component={NoteScreen} />
  </Stack.Navigator>
);

const CommunityStack = () => (
  <Stack.Navigator>
    <Stack.Screen name="Community" component={CommunityScreen} />
    <Stack.Screen name="PostDetail" component={PostDetailScreen} />
  </Stack.Navigator>
);
```

## 6. Redux状态管理

### 6.1 store.js

Redux存储配置，集成了各个功能模块的reducer。

```javascript
const store = configureStore({
  reducer: {
    auth: authReducer,
    notes: notesReducer,
    ui: uiReducer,
    knowledgeGraph: knowledgeGraphReducer,
    community: communityReducer,
    search: searchReducer,
  },
  middleware: (getDefaultMiddleware) =>
    getDefaultMiddleware({
      serializableCheck: false
    }),
});
```

### 6.2 主要状态切片

- **authSlice.js**: 认证相关状态，包含用户信息、登录状态等
- **notesSlice.js**: 笔记相关状态，包含笔记列表、当前编辑笔记等
- **uiSlice.js**: UI相关状态，包含主题设置、当前屏幕等
- **knowledgeGraphSlice.js**: 知识图谱相关状态，包含节点和关系数据
- **communitySlice.js**: 社区相关状态，包含帖子列表、评论等
- **searchSlice.js**: 搜索相关状态，包含搜索结果、搜索历史等

## 9. 原生模块

### 9.1 Android原生模块

- **MainActivity.java**: Android应用主活动
- **MainApplication.java**: Android应用主应用类，注册React Native包
- **ZeroIsleNotesPackage.java**: 零屿笔记原生模块包，注册自定义原生模块
- **ZeroIsleUtilsModule.java**: 工具模块，提供文件操作、分享等原生功能
- **FileSystemModule.java**: 文件系统模块，提供文件读写、目录操作等功能
- **HandwritingRecognitionModule.java**: 手写识别模块，集成OCR功能
- **NotificationModule.java**: 通知模块，提供本地通知和推送功能

### 9.2 iOS原生模块

- **AppDelegate.m**: iOS应用委托类
- **ZeroIsleUtils.m**: 工具模块，提供iOS平台特定功能
- **FileSystem.m**: 文件系统模块，iOS实现
- **HandwritingRecognition.m**: 手写识别模块，iOS实现
- **NotificationManager.m**: 通知管理模块，iOS实现

## 10. 配置文件

### 10.1 package.json

项目依赖和脚本配置。

```json
{
  "name": "ZeroIsle_Notes",
  "version": "0.0.1",
  "private": true,
  "scripts": {
    "android": "react-native run-android",
    "ios": "react-native run-ios",
    "lint": "eslint .",
    "start": "react-native start",
    "test": "jest",
    "install-deps": "npm install --registry=https://registry.npmmirror.com",
    "install-deps-yarn": "yarn --registry=https://registry.npmmirror.com",
    "pod-install": "cd ios && pod install"
  },
  "dependencies": {
    // 依赖列表
  }
}
```

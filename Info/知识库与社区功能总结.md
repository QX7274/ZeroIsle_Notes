# 零屿笔记 - 知识库与社区功能总结

> 本文档总结了零屿笔记应用中知识库构建和社区功能的实现情况。

## 一、知识库构建功能 ✅ 已完整实现

### 1.1 核心能力

零屿笔记**完全支持**用户构建自己的个人知识库，类似于其他知识管理工具（如 Notion、Obsidian、IMA 等）。

### 1.2 实现方式

#### 自动知识提取与构建

系统通过以下模块实现智能化的知识库构建：

1.  **知识图谱模块** (`backend/knowledge_graph/`)
    *   **实体提取**：自动识别笔记中的人名、地名、组织机构等专有名词
    *   **关系提取**：识别实体之间的关系（如"属于"、"包含"、"导致"等）
    *   **概念提取**：提取文本中的核心概念和术语
    *   **三元组生成**：将知识结构化为（主体-关系-客体）的标准形式

2.  **自动分类服务** (`auto_classification_service.py`)
    *   **智能分类**：基于内容相似度自动为笔记推荐分类
    *   **关键词提取**：使用 TF-IDF 和 TextRank 算法提取关键词
    *   **标签推荐**：智能推荐相关标签
    *   **相似笔记发现**：自动找到内容相似的笔记并建立关联

3.  **知识图谱构建服务** (`knowledge_graph_builder_service.py`)
    *   **从笔记构建**：将单个或多个笔记转化为知识图谱节点和关系
    *   **关联分析**：分析笔记之间的关联，构建知识网络
    *   **内容推荐**：基于知识图谱推荐相关内容

#### 新增：专门的知识库模块

为了更好地组织和管理知识，我们新增了 `knowledge_base` 模块，提供以下功能：

1.  **知识库管理** (`management_service.py`)
    *   创建多个独立的知识库（个人、项目、团队、公开）
    *   成员权限管理
    *   知识库快照和版本控制
    *   知识库归档和删除

2.  **知识库构建** (`builder_service.py`)
    *   从笔记批量构建知识库
    *   从 Markdown 文件导入知识
    *   自动解析文档结构并创建知识节点
    *   建立层级关系和概念关联

3.  **知识库问答** (`qa_service.py`)
    *   基于知识库内容的智能问答
    *   自动搜索相关知识节点
    *   使用 AI 生成准确的答案
    *   记录查询历史和用户反馈

4.  **知识库应用** (`application_service.py`)
    *   智能内容推荐
    *   学习路径规划
    *   知识缺口识别和分析

### 1.3 使用场景

用户可以通过以下方式构建和使用知识库：

1.  **自动构建**：创建笔记后，系统自动提取知识并加入知识库
2.  **批量导入**：从现有笔记批量构建知识库
3.  **文件导入**：从 Markdown、OPML 等格式导入外部知识
4.  **手动编辑**：在可视化界面中手动添加和编辑知识节点
5.  **智能问答**：向知识库提问，获得基于已有知识的答案
6.  **知识探索**：通过可视化图谱探索知识之间的关联

### 1.4 技术特点

*   **智能化**：使用 NLP 和 AI 技术自动提取和组织知识
*   **结构化**：知识以图谱形式存储，支持复杂的关系表达
*   **可视化**：提供多种视图展示知识结构
*   **可扩展**：支持多种导入格式和自定义扩展

## 二、社区功能 ✅ 已完善实现

### 2.1 核心能力

零屿笔记的社区功能已经非常完善，具备现代社区应用的所有核心特性。

### 2.2 已实现功能

#### 内容发布与管理

1.  **帖子系统** (`community/services/post_service.py`)
    *   发布、编辑、删除帖子
    *   支持富文本、Markdown 格式
    *   分类和标签管理
    *   草稿和发布状态管理

2.  **笔记分享** (`notes/share_views.py`)

    *   设置分享有效期
    *   查看分享统计

#### 社交互动

1.  **点赞系统** (`community/services/like_service.py`)
    *   对帖子和评论点赞
    *   点赞数统计
    *   点赞状态查询

2.  **评论系统** (`community/services/comment_service.py`)
    *   发表评论和回复
    *   多级评论支持
    *   评论排序和过滤
    *   评论通知

3.  **关注系统** (`community/services/follow_service.py`)
    *   关注用户
    *   粉丝管理
    *   关注动态推送
    *   共同关注查询

#### 内容发现

1.  **搜索功能**
    *   全文搜索
    *   按分类、标签筛选
    *   按热度、时间排序

2.  **推荐系统**
    *   热门内容推荐
    *   个性化推荐（规划中）
    *   相关内容推荐

3.  **活动流**
    *   用户活动历史
    *   关注用户动态
    *   社区热点

#### 通知系统

1.  **多种通知类型**
    *   互动通知（点赞、评论、关注）
    *   内容更新通知
    *   系统通知

2.  **通知管理**
    *   标记已读/未读
    *   通知设置
    *   通知汇总

社区功能使用了完整的数据模型：

## 四、使用指南

### 4.1 构建个人知识库

```python
# 1. 创建知识库
POST /api/knowledge-base/knowledge-bases/
{
    "name": "我的编程知识库",
    "type": "personal",
    "description": "记录编程学习的知识点"
}

# 2. 从笔记构建
POST /api/knowledge-base/knowledge-bases/{id}/build/
{
    "extract_concepts": true
}

# 3. 向知识库提问
POST /api/knowledge-base/knowledge-bases/{id}/ask/
{
    "question": "什么是闭包？"
}
```

### 4.2 参与社区

```python
# 1. 发布帖子
POST /api/community/posts/
{
    "title": "Python学习心得",
    "content": "...",
    "tags": ["Python", "学习"]
}

# 2. 评论和互动
POST /api/community/posts/{id}/comments/
{
    "content": "很有帮助！"
}

# 3. 关注用户
POST /api/community/users/{id}/follow/
```

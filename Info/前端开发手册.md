# 零屿笔记前端开发手册

## 前端架构概述

零屿笔记前端采用React Native框架开发，实现了跨平台（iOS和Android）的移动应用。前端架构采用了组件化、模块化的设计理念，结合Redux进行状态管理，使用React Navigation进行页面导航。

## 组件开发规范

### 组件结构

每个组件应该遵循以下结构：

```jsx
// 导入依赖
import React from 'react';
import { View, Text, StyleSheet } from 'react-native';
import PropTypes from 'prop-types';

/**
 * 组件描述
 * @param {Object} props - 组件属性
 * @returns {React.ReactElement} 组件
 */
const MyComponent = ({ title, onPress, disabled }) => {
  // 组件逻辑
  
  // 渲染
  return (
    <View style={styles.container}>
      <Text style={styles.title}>{title}</Text>
    </View>
  );
};

// 属性类型定义
MyComponent.propTypes = {
  title: PropTypes.string.isRequired,
  onPress: PropTypes.func,
  disabled: PropTypes.bool,
};

// 默认属性
MyComponent.defaultProps = {
  onPress: () => {},
  disabled: false,
};

// 样式
const styles = StyleSheet.create({
  container: {
    // 样式定义
  },
  title: {
    // 样式定义
  },
});

export default MyComponent;
```

### 组件分类

1. **通用组件（Common Components）**：
   - 基础UI组件，如按钮、输入框、卡片等
   - 位于`src/components/common/`目录
   - 应该是高度可复用的，不包含业务逻辑

2. **功能组件（Feature Components）**：
   - 特定功能的复杂组件，如笔记编辑器、手写识别面板等
   - 位于`src/components/<功能模块>/`目录
   - 可以包含特定的业务逻辑

3. **页面组件（Screen Components）**：
   - 完整的页面，如登录页、笔记列表页等
   - 位于`src/screens/`目录
   - 负责页面布局和数据流，具体UI细节委托给可复用组件

## 状态管理

### Redux使用规范

零屿笔记使用Redux Toolkit进行状态管理，主要包括以下几个部分：

1. **Store配置**：
   - 位于`src/redux/store.js`
   - 集成了所有reducer和中间件

2. **Slice定义**：
   - 位于`src/redux/slices/`目录
   - 使用Redux Toolkit的`createSlice`API
   - 包含状态、reducer和action creator

3. **Selector定义**：
   - 位于`src/redux/selectors/`目录
   - 使用`reselect`库进行性能优化

示例Slice：

```javascript
import { createSlice, createAsyncThunk } from '@reduxjs/toolkit';
import { notesApi } from '../../services';

// 异步Action
export const fetchNotes = createAsyncThunk(
  'notes/fetchNotes',
  async (_, { rejectWithValue }) => {
    try {
      const response = await notesApi.getNotes();
      return response.data;
    } catch (error) {
      return rejectWithValue(error.response.data);
    }
  }
);

// Slice定义
const notesSlice = createSlice({
  name: 'notes',
  initialState: {
    notes: [],
    status: 'idle', // 'idle' | 'loading' | 'succeeded' | 'failed'
    error: null,
  },
  reducers: {
    // 同步Action
    addNote: (state, action) => {
      state.notes.push(action.payload);
    },
    updateNote: (state, action) => {
      const { id, ...changes } = action.payload;
      const existingNote = state.notes.find(note => note.id === id);
      if (existingNote) {
        Object.assign(existingNote, changes);
      }
    },
    deleteNote: (state, action) => {
      const id = action.payload;
      state.notes = state.notes.filter(note => note.id !== id);
    },
  },
  extraReducers: (builder) => {
    // 异步Action处理
    builder
      .addCase(fetchNotes.pending, (state) => {
        state.status = 'loading';
      })
      .addCase(fetchNotes.fulfilled, (state, action) => {
        state.status = 'succeeded';
        state.notes = action.payload;
      })
      .addCase(fetchNotes.rejected, (state, action) => {
        state.status = 'failed';
        state.error = action.payload;
      });
  },
});

// 导出Action
export const { addNote, updateNote, deleteNote } = notesSlice.actions;

// 导出Reducer
export default notesSlice.reducer;
```

### Context使用规范

对于不需要全局共享的状态，可以使用React Context：

```javascript
import React, { createContext, useContext, useState } from 'react';

// 创建Context
const ThemeContext = createContext();

// Context Provider
export const ThemeProvider = ({ children }) => {
  const [theme, setTheme] = useState('light');

  const toggleTheme = () => {
    setTheme(prevTheme => prevTheme === 'light' ? 'dark' : 'light');
  };

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  );
};

// 自定义Hook
export const useTheme = () => {
  const context = useContext(ThemeContext);
  if (context === undefined) {
    throw new Error('useTheme must be used within a ThemeProvider');
  }
  return context;
};
```

## 导航配置

零屿笔记使用React Navigation进行页面导航，主要包括以下几个部分：

1. **AppNavigator**：
   - 位于`src/navigation/AppNavigator.js`
   - 应用的主导航器，整合所有导航堆栈
   - 处理认证状态切换

2. **AuthNavigator**：
   - 位于`src/navigation/AuthNavigator.js`
   - 认证相关的导航堆栈，包括登录、注册等页面

3. **MainNavigator**：
   - 位于`src/navigation/MainNavigator.js`
   - 主要功能的导航堆栈，包括笔记、知识图谱等功能模块

示例导航配置：

```javascript
import React from 'react';
import { NavigationContainer } from '@react-navigation/native';
import { createStackNavigator } from '@react-navigation/stack';
import { useSelector } from 'react-redux';
import { selectIsAuthenticated } from '../redux/selectors/authSelectors';

import AuthNavigator from './AuthNavigator';
import MainNavigator from './MainNavigator';

const Stack = createStackNavigator();

const AppNavigator = () => {
  const isAuthenticated = useSelector(selectIsAuthenticated);

  return (
    <NavigationContainer>
      <Stack.Navigator
        screenOptions={{
          headerShown: false,
        }}
      >
        {isAuthenticated ? (
          <Stack.Screen name="Main" component={MainNavigator} />
        ) : (
          <Stack.Screen name="Auth" component={AuthNavigator} />
        )}
      </Stack.Navigator>
    </NavigationContainer>
  );
};

export default AppNavigator;
```

## API服务

零屿笔记使用Axios进行API请求，API服务位于`src/services/api/`目录：

1. **apiClient.js**：
   - 配置Axios实例
   - 设置请求拦截器和响应拦截器
   - 处理认证Token

2. **各模块API服务**：
   - 如`authApi.js`、`notesApi.js`等
   - 封装特定模块的API请求

示例API服务：

```javascript
import apiClient from './apiClient';

// 笔记API服务
const notesApi = {
  // 获取笔记列表
  getNotes: (params) => {
    return apiClient.get('/notes/', { params });
  },
  
  // 获取笔记详情
  getNote: (id) => {
    return apiClient.get(`/notes/${id}/`);
  },
  
  // 创建笔记
  createNote: (data) => {
    return apiClient.post('/notes/', data);
  },
  
  // 更新笔记
  updateNote: (id, data) => {
    return apiClient.put(`/notes/${id}/`, data);
  },
  
  // 删除笔记
  deleteNote: (id) => {
    return apiClient.delete(`/notes/${id}/`);
  },
};

export default notesApi;
```

示例辅助函数：

```javascript
// src/utils/helpers/dateHelpers.js
import { format, parseISO } from 'date-fns';
import { zhCN } from 'date-fns/locale';

/**
 * 格式化日期
 * @param {string|Date} date - 日期字符串或Date对象
 * @param {string} formatStr - 格式化字符串
 * @returns {string} 格式化后的日期字符串
 */
export const formatDate = (date, formatStr = 'yyyy-MM-dd') => {
  if (!date) return '';
  
  const dateObj = typeof date === 'string' ? parseISO(date) : date;
  return format(dateObj, formatStr, { locale: zhCN });
};

/**
 * 获取相对时间描述
 * @param {string|Date} date - 日期字符串或Date对象
 * @returns {string} 相对时间描述
 */
export const getRelativeTime = (date) => {
  if (!date) return '';
  
  const dateObj = typeof date === 'string' ? parseISO(date) : date;
  const now = new Date();
  const diffInSeconds = Math.floor((now - dateObj) / 1000);
  
  if (diffInSeconds < 60) {
    return '刚刚';
  } else if (diffInSeconds < 3600) {
    return `${Math.floor(diffInSeconds / 60)}分钟前`;
  } else if (diffInSeconds < 86400) {
    return `${Math.floor(diffInSeconds / 3600)}小时前`;
  } else if (diffInSeconds < 604800) {
    return `${Math.floor(diffInSeconds / 86400)}天前`;
  } else {
    return formatDate(dateObj);
  }
};
```

## 样式指南

零屿笔记使用React Native的StyleSheet进行样式定义，遵循以下规范：

1. **样式分离**：
   - 将样式与组件逻辑分离
   - 使用StyleSheet.create创建样式对象

2. **样式命名**：
   - 使用驼峰命名法
   - 命名应该清晰表达样式的用途

3. **样式复用**：

## 性能优化

为了保证应用的性能，应该遵循以下优化策略：

1. **组件优化**：
   - 使用React.memo避免不必要的重渲染
   - 使用useCallback和useMemo缓存函数和计算结果
   - 使用PureComponent或shouldComponentUpdate控制组件更新

2. **列表优化**：
   - 使用FlatList或SectionList代替ScrollView
   - 实现合适的keyExtractor和getItemLayout
   - 使用onEndReached实现分页加载

3. **图片优化**：
   - 使用适当大小的图片
   - 实现图片懒加载
   - 使用缓存策略

4. **网络请求优化**：
   - 实现请求缓存
   - 使用防抖和节流控制请求频率
   - 实现请求取消和超时处理

5. **状态管理优化**：
   - 避免过度使用全局状态
   - 使用选择器（selectors）优化状态获取
   - 使用规范化数据结构存储实体数据

## 常见问题解决

### 依赖安装问题

- **问题**：依赖安装失败或速度慢
- **解决方案**：使用国内镜像源
  ```bash
  yarn install-deps-yarn  # 使用项目提供的命令
  ```

### 运行时错误

- **问题**：Metro服务器启动失败
- **解决方案**：
  ```bash
  # 清除缓存
  yarn start --reset-cache
  ```

- **问题**：Android构建失败
- **解决方案**：
  ```bash
  # 清除Gradle缓存
  cd android
  ./gradlew clean
  ```

- **问题**：iOS构建失败
- **解决方案**：
  ```bash
  # 重新安装Pod依赖
  cd ios
  pod install --repo-update
  ```

### 性能问题

- **问题**：应用卡顿
- **解决方案**：
  - 使用Performance Monitor检查性能瓶颈
  - 优化渲染性能，减少不必要的重渲染
  - 优化图片和动画

- **问题**：内存泄漏
- **解决方案**：
  - 使用React Native Debugger检查内存使用
  - 清理不再使用的资源
  - 避免闭包陷阱

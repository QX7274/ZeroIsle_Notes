## 开发环境配置

### 系统要求

- **操作系统**：Windows 10/11、macOS 10.15+、Ubuntu 20.04+
- **内存**：至少8GB RAM（推荐16GB以上）
- **存储**：至少10GB可用空间
- **处理器**：现代多核处理器

### 必要软件

1. **Node.js**：版本18.0.0或更高
   ```bash
   # Windows使用官方安装包
   # macOS使用Homebrew
   brew install node
   # Ubuntu
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```

2. **Yarn**：版本1.22.0或更高
   ```bash
   npm install -g yarn
   ```

3. **Python**：版本3.10或更高
   ```bash
   # Windows使用官方安装包
   # macOS
   brew install python@3.10
   # Ubuntu
   sudo apt install python3.10 python3.10-venv python3.10-dev
   ```

4. **Git**：最新版本
   ```bash
   # Windows使用官方安装包
   # macOS
   brew install git
   # Ubuntu
   sudo apt install git
   ```

5. **React Native环境**：
   - 按照[React Native官方文档](https://reactnative.dev/docs/environment-setup)配置环境
   - 选择"React Native CLI Quickstart"选项
   - 根据您的操作系统和目标平台(Android/iOS)按步骤操作

## 前端安装

### 克隆项目

```bash
git clone https://github.com/your-username/ZeroIsle_Notes.git
cd ZeroIsle_Notes
```

### 安装依赖

```bash
# 使用Yarn安装依赖
yarn install
```

### iOS特定步骤（仅macOS）

```bash
cd ios
pod install
cd ..
```

### 配置环境变量

1. 在项目根目录创建`.env`文件
2. 添加必要的环境变量：

```
API_URL=http://localhost:8000/api
ENVIRONMENT=development
```

## 后端安装

### 创建虚拟环境

```bash
cd backend
python -m venv venv

# Windows激活虚拟环境
venv\Scripts\activate

# macOS/Linux激活虚拟环境
source venv/bin/activate
```

### 安装依赖

```bash
pip install -r requirements.txt
```

### 初始化数据库

```bash
python manage.py migrate
```

### 创建超级用户

```bash
python manage.py createsuperuser
```

## 数据库配置

### MongoDB设置

1. 安装MongoDB（[官方安装指南](https://docs.mongodb.com/manual/installation/)）
2. 创建数据库和用户：

```bash
mongo
> use zeroislenotes
> db.createUser({
    user: "zeroisleuser",
    pwd: "your_secure_password",
    roles: [{ role: "readWrite", db: "zeroislenotes" }]
  })
```

3. 更新后端配置：
   - 编辑`backend/backend/settings.py`文件
   - 更新MongoDB连接设置

### Neo4j设置（知识图谱）

1. 安装Neo4j（[官方安装指南](https://neo4j.com/docs/operations-manual/current/installation/)）
2. 创建新数据库
3. 更新后端配置：
   - 编辑`backend/backend/settings.py`文件
   - 更新Neo4j连接设置

### Redis设置（缓存和会话）

1. 安装Redis（[官方安装指南](https://redis.io/docs/getting-started/)）
2. 更新后端配置：
   - 编辑`backend/backend/settings.py`文件
   - 更新Redis连接设置

## 第三方服务配置

### AI服务配置

1. **OpenAI API**（AI助手）
   - 注册[OpenAI API](https://openai.com/api/)账号
   - 获取API密钥
   - 在`backend/backend/settings.py`中配置密钥

2. **百度飞桨OCR**（手写识别）
   - 注册[百度AI开放平台](https://ai.baidu.com/)账号
   - 创建OCR应用并获取API密钥
   - 在`backend/backend/settings.py`中配置密钥

3. **Whisper API**（语音识别）
   - 配置OpenAI Whisper API密钥
   - 在`backend/backend/settings.py`中配置密钥

### 短信和推送服务

1. **短信服务**（用户验证）
   - 注册短信服务提供商账号（如阿里云、腾讯云）
   - 获取API密钥
   - 在`backend/backend/settings.py`中配置密钥

2. **推送通知**
   - 配置Firebase Cloud Messaging（Android）
   - 配置Apple Push Notification Service（iOS）
   - 更新相应配置文件

## 生产环境部署

### 后端部署

1. **使用Gunicorn和Nginx**

```bash
# 安装Gunicorn
pip install gunicorn

# 启动Gunicorn
gunicorn backend.wsgi:application --bind 0.0.0.0:8000 --workers 3 --timeout 120
```

2. **Nginx配置示例**

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location /static/ {
        alias /path/to/your/static/files/;
    }

    location /media/ {
        alias /path/to/your/media/files/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

3. **使用Supervisor管理进程**

```ini
[program:zeroislenotes]
command=/path/to/venv/bin/gunicorn backend.wsgi:application --bind 0.0.0.0:8000 --workers 3 --timeout 120
directory=/path/to/backend
user=www-data
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/log/zeroislenotes.log
```

### 前端部署

1. **构建React Native应用**

```bash
# Android APK
cd android
./gradlew assembleRelease

# iOS (通过Xcode)
open ios/ZeroIsleNotes.xcworkspace
# 然后使用Xcode构建和归档应用
```

2. **发布到应用商店**
   - 按照[Google Play](https://developer.android.com/studio/publish)指南发布Android应用
   - 按照[App Store](https://developer.apple.com/app-store/submissions/)指南发布iOS应用

## 常见问题

### 依赖安装问题

**问题**：安装React Native依赖时出错
**解决方案**：
```bash
# 清除缓存并重新安装
yarn cache clean
rm -rf node_modules
yarn install
```

### iOS构建问题

**问题**：Pod安装失败
**解决方案**：
```bash
cd ios
pod deintegrate
pod setup
pod install
```

### Android构建问题

**问题**：Gradle构建失败
**解决方案**：
```bash
cd android
./gradlew clean
cd ..
yarn android
```

### 后端连接问题

**问题**：前端无法连接到后端API
**解决方案**：
1. 检查API URL配置是否正确
2. 确保后端服务正在运行
3. 检查网络设置和防火墙配置
4. 对于Android模拟器，使用`10.0.2.2`代替`localhost`

### 数据库连接问题

**问题**：无法连接到MongoDB
**解决方案**：
1. 确保MongoDB服务正在运行
2. 验证连接字符串和凭据
3. 检查网络访问权限和防火墙设置

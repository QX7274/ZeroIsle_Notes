## 开发环境配置

### 系统要求

- **操作系统**：Windows 10/11、macOS 10.15+、Ubuntu 20.04+
- **内存**：至少8GB RAM（推荐16GB以上）
- **存储**：至少10GB可用空间
- **处理器**：现代多核处理器

### 必要软件

1. **Node.js**：版本18.0.0或更高
   ```bash
   # Windows使用官方安装包
   # macOS使用Homebrew
   brew install node
   # Ubuntu
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```

2. **Yarn**：版本1.22.0或更高
   ```bash
   npm install -g yarn
   ```

3. **Python**：版本3.10或更高
   ```bash
   # Windows使用官方安装包
   # macOS
   brew install python@3.10
   # Ubuntu
   sudo apt install python3.10 python3.10-venv python3.10-dev
   ```

4. **Git**：最新版本
   ```bash
   # Windows使用官方安装包
   # macOS
   brew install git
   # Ubuntu
   sudo apt install git
   ```

5. **React Native环境**：
   - 按照[React Native官方文档](https://reactnative.dev/docs/environment-setup)配置环境
   - 选择"React Native CLI Quickstart"选项
   - 根据您的操作系统和目标平台(Android/iOS)按步骤操作

## 前端安装

### 克隆项目

```bash
git clone https://github.com/qx7274/ZeroIsle_Notes.git
cd ZeroIsle_Notes
```

### 安装依赖

```bash
# 使用Yarn安装依赖
yarn install
```

#### 主要前端依赖

项目使用以下主要依赖：

- **React Native**: v0.72.6 - 跨平台移动应用开发框架
- **React Navigation**: v6.x - 导航库
- **Redux Toolkit**: v1.9.x - 状态管理
- **React Native SVG**: v13.x - SVG支持
- **React Native Vector Icons**: v10.x - 图标库
- **React Native Reanimated**: v3.x - 动画库
- **React Native Gesture Handler**: v2.x - 手势处理
- **@react-native-clipboard/clipboard**: v1.11.x - 剪贴板功能
- **@react-native-async-storage/async-storage**: v1.19.x - 本地存储
- **react-native-audio-recorder-player**: v3.5.x - 音频录制和播放
- **react-native-fs**: v2.20.x - 文件系统访问
- **react-native-image-picker**: v5.x - 图片选择器
- **react-native-markdown-display**: v7.0.x - Markdown渲染

#### 可能的依赖冲突

注意以下依赖可能存在冲突：

- **文档选择器**: 项目使用`@react-native-documents/picker`，请勿同时安装`react-native-document-picker`，以避免类定义重复。
- **图片选择器**: 确保只使用`react-native-image-picker`，避免安装其他类似功能的库。

## 数据库配置

### MongoDB设置

1. 安装MongoDB（[官方安装指南](https://docs.mongodb.com/manual/installation/)）
2. 创建数据库和用户：

```bash
mongo
> use zeroislenotes
> db.createUser({
    user: "zeroisleuser",
    pwd: "your_secure_password",
    roles: [{ role: "readWrite", db: "zeroislenotes" }]
  })
```

3. 更新后端配置：
   - 编辑`backend/backend/settings.py`文件
   - 更新MongoDB连接设置

### Neo4j设置（知识图谱）

1. 安装Neo4j（[官方安装指南](https://neo4j.com/docs/operations-manual/current/installation/)）
2. 创建新数据库
3. 更新后端配置：
   - 编辑`backend/backend/settings.py`文件
   - 更新Neo4j连接设置

### Redis设置（缓存和会话）

1. 安装Redis（[官方安装指南](https://redis.io/docs/getting-started/)）
2. 更新后端配置：
   - 编辑`backend/backend/settings.py`文件
   - 更新Redis连接设置

## 生产环境部署

### 后端部署

1. **使用Gunicorn和Nginx**

```bash
# 安装Gunicorn
pip install gunicorn

# 启动Gunicorn
gunicorn backend.wsgi:application --bind 0.0.0.0:8000 --workers 3 --timeout 120
```

2. **Nginx配置示例**

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location /static/ {
        alias /path/to/your/static/files/;
    }

    location /media/ {
        alias /path/to/your/media/files/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

3. **使用Supervisor管理进程**

```ini
[program:zeroislenotes]
command=/path/to/venv/bin/gunicorn backend.wsgi:application --bind 0.0.0.0:8000 --workers 3 --timeout 120
directory=/path/to/backend
user=www-data
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/log/zeroislenotes.log
```

### 前端部署

1. **构建React Native应用**

cd android

## 常见问题

### 依赖安装问题

**问题**：安装React Native依赖时出错
**解决方案**：
```bash
# 清除缓存并重新安装
yarn cache clean
rm -rf node_modules
yarn install
```

**问题**：文档选择器依赖冲突
**解决方案**：
```bash
# 移除冲突的依赖
yarn remove react-native-document-picker
# 确保使用正确的依赖
yarn add @react-native-documents/picker
# 清理并重新安装
cd android && ./gradlew clean && cd ..
cd ios && pod install && cd ..
```

### iOS构建问题

**问题**：Pod安装失败
**解决方案**：
```bash
cd ios
pod deintegrate
pod setup
pod install
```

### Android构建问题

**问题**：Gradle构建失败
**解决方案**：
```bash
cd android
./gradlew clean
cd ..
yarn android
```

### 后端连接问题

**问题**：前端无法连接到后端API
**解决方案**：
1. 检查API URL配置是否正确
2. 确保后端服务正在运行
3. 检查网络设置和防火墙配置
4. 对于Android模拟器，使用`10.0.2.2`代替`localhost`

### 数据库连接问题

**问题**：无法连接到MongoDB
**解决方案**：
1. 确保MongoDB服务正在运行
2. 验证连接字符串和凭据
3. 检查网络访问权限和防火墙设置

### 3.1 数据模型 (models/note.py)

```python
class Note(models.Model):
    """ 笔记模型 """
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    user = models.ForeignKey(settings.AUTH_USER_MODEL, on_delete=models.CASCADE, related_name='notes')
    title = models.CharField(max_length=255)
    content = models.TextField()
    format = models.CharField(max_length=20, choices=NOTE_FORMATS, default='markdown')
    category = models.ForeignKey('notes.Category', on_delete=models.SET_NULL, null=True, blank=True, related_name='notes')
    tags = models.ManyToManyField('notes.Tag', blank=True, related_name='notes')
    is_pinned = models.BooleanField(default=False)
    is_archived = models.BooleanField(default=False)
    is_public = models.BooleanField(default=False)
    view_count = models.PositiveIntegerField(default=0)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
    last_accessed_at = models.DateTimeField(null=True, blank=True)

    class Meta:
        ordering = ['-updated_at']
        indexes = [
            models.Index(fields=['user', '-updated_at']),
            models.Index(fields=['user', 'category']),
            models.Index(fields=['is_public', '-updated_at']),
        ]
```

### 4.1 用户模型 (models.py)

```python
class User(AbstractBaseUser, PermissionsMixin):
    """ 自定义用户模型 """
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    username = models.CharField(max_length=150, unique=True)
    email = models.EmailField(unique=True, null=True, blank=True)
    phone = models.CharField(max_length=20, unique=True, null=True, blank=True)
    nickname = models.CharField(max_length=50, blank=True)
    avatar = models.ImageField(upload_to='avatars/', null=True, blank=True)
    bio = models.TextField(blank=True)
    is_active = models.BooleanField(default=True)
    is_staff = models.BooleanField(default=False)
    date_joined = models.DateTimeField(auto_now_add=True)
    last_login = models.DateTimeField(null=True, blank=True)

    # 用户偏好设置
    preferences = models.JSONField(default=dict)

    # 第三方账号关联
    wechat_id = models.CharField(max_length=100, blank=True, null=True, unique=True)
    qq_id = models.CharField(max_length=100, blank=True, null=True, unique=True)

    objects = UserManager()

    USERNAME_FIELD = 'username'
    REQUIRED_FIELDS = []

    class Meta:
        verbose_name = '用户'
        verbose_name_plural = '用户'
        indexes = [
            models.Index(fields=['username']),
            models.Index(fields=['email']),
            models.Index(fields=['phone']),
        ]
```

### 5.1 知识图谱模型 (models/graph.py)

**KnowledgeGraph 模型**
- 主要字段：id、user、name、description、is_public、created_at、updated_at
- 图谱设置：使用JSONField存储图谱配置信息
- 索引：用户和公开状态

**Node 模型**
- 主要字段：id、graph（关联到KnowledgeGraph）、name、node_type、properties
- 位置信息：position_x、position_y（用于可视化布局）
- 时间字段：created_at、updated_at
- 索引：图谱和节点类型的组合索引，节点名称索引

**Relation 模型**
- 主要字段：id、graph（关联到KnowledgeGraph）、source（源节点）、target（目标节点）
- 关系类型：relation_type（定义节点间的关系类型）
- 属性：properties（使用JSONField存储关系的附加属性）
- 时间字段：created_at、updated_at
- 索引：图谱、源节点、目标节点和关系类型

### 5.2 Neo4j客户端 (neo4j/client.py)

**Neo4jClient 类**
- 初始化：从配置中获取Neo4j连接信息（URI、用户名、密码）
- 主要方法：
  - connect()：连接Neo4j数据库
  - close()：关闭数据库连接
  - execute_query()：执行Cypher查询语句
  - create_node()：创建新节点
  - create_relationship()：创建节点间的关系
  - get_node()：获取节点信息
  - get_nodes_by_label()：根据标签获取节点
  - get_relationships()：获取关系
  - delete_node()：删除节点
  - delete_relationship()：删除关系

## 3. 前端组件详解

### 3.1 通用组件 (components/common/)

这些组件在整个应用中被广泛使用，提供基础UI功能。

- **Button.js**: 自定义按钮组件，支持多种样式和状态
- **Card.js**: 卡片容器组件，用于展示内容块
- **Divider.js**: 分隔线组件，用于分隔内容
- **GradientButton.js**: 渐变按钮组件，支持渐变背景
- **Header.js**: 应用头部组件，包含标题、返回按钮等
- **Input.js**: 输入框组件，支持多种输入类型
- **Loading.js**: 加载指示器组件，支持全屏和局部加载状态
- **Modal.js**: 模态框组件，用于显示弹出内容
- **Typography/Text.js**: 文本组件，支持多种样式和大小

### 3.2 笔记相关组件

- **NoteToolbar.js**: 笔记编辑工具栏，提供格式化、插入媒体等功能
- **CategoryManager.js**: 分类管理组件，用于创建、编辑、删除分类
- **TagManager.js**: 标签管理组件，用于添加、删除标签
- **TagStatistics.js**: 标签统计组件，显示标签使用频率和分布

### 3.3 画布相关组件

- **Canvas.js**: 无限画布组件，支持绘制、添加元素等
- **CanvasElement.js**: 画布元素组件，如文本框、图形等
- **CanvasToolbar.js**: 画布工具栏，提供绘图工具、样式设置等
- **LayerManager.js**: 图层管理组件，控制元素的层级关系

### 3.4 知识图谱相关组件

- **KnowledgeGraph.js**: 知识图谱可视化组件，展示知识点和关系
- **MindMap.js**: 思维导图组件，用于组织思维结构

### 3.5 AI助手相关组件

- **ChatInput.js**: 聊天输入组件，支持文本输入和语音输入
- **ChatMessage.js**: 聊天消息组件，支持显示用户和AI助手的消息

### 3.6 代码相关组件

- **CodeEditor.js**: 代码编辑器组件，支持语法高亮、自动完成等
- **CodeRunner.js**: 代码运行组件，支持执行代码并显示结果

## 5. 导航结构

### 5.1 AppNavigator.js

应用主导航器，根据认证状态决定显示认证导航还是主功能导航。

```javascript
const AppNavigator = () => {
  // ...
  return (
    <NavigationContainer onStateChange={onStateChange}>
      <Stack.Navigator screenOptions={{ headerShown: false }}>
        {isAuthenticated ? (
          <Stack.Screen name="MainTabs" component={MainTabs} />
        ) : (
          <Stack.Screen name="Auth" component={AuthNavigator} />
        )}
      </Stack.Navigator>
    </NavigationContainer>
  );
};
```

### 5.2 主标签导航 (MainTabs)

底部标签导航，包含主要功能模块。

```javascript
const MainTabs = () => {
  const { theme } = useTheme();
  const { colors } = theme;

  return (
    <Tab.Navigator
      screenOptions={({ route }) => ({
        tabBarIcon: ({ color, size }) => {
          let iconName;

          if (route.name === 'HomeStack') {
            iconName = 'home';
          } else if (route.name === 'CategoryStack') {
            iconName = 'folder';
          } else if (route.name === 'AIAssistant') {
            iconName = 'smart-toy';
          } else if (route.name === 'CommunityStack') {
            iconName = 'forum';
          } else if (route.name === 'Profile') {
            iconName = 'person';
          }

          return <Icon name={iconName} size={size} color={color} />;
        },
        tabBarActiveTintColor: colors.primary,
        tabBarInactiveTintColor: colors.textSecondary,
        tabBarStyle: {
          backgroundColor: colors.card,
          borderTopColor: colors.border,
        },
      })}
    >
      <Tab.Screen
        name="HomeStack"
        component={HomeStack}
        options={{
          headerShown: false,
          title: '首页',
          tabBarLabel: '首页',
        }}
      />
      <Tab.Screen
        name="CategoryStack"
        component={CategoryStack}
        options={{
          headerShown: false,
          title: '分类',
          tabBarLabel: '分类',
        }}
      />
      <Tab.Screen
        name="AIAssistant"
        component={AIAssistantScreen}
        options={{
          title: 'AI助手',
          tabBarLabel: 'AI助手',
        }}
      />
      <Tab.Screen
        name="CommunityStack"
        component={CommunityStack}
        options={{
          headerShown: false,
          title: '社区',
          tabBarLabel: '社区',
        }}
      />
      <Tab.Screen
        name="Profile"
        component={SettingsNavigator}
        options={{
          headerShown: false,
          title: '个人中心',
          tabBarLabel: '个人中心',
        }}
      />
    </Tab.Navigator>
  );
};
```

## 6. Redux状态管理

### 6.1 store.js

Redux存储配置，集成了各个功能模块的reducer。

```javascript
const store = configureStore({
  reducer: {
    auth: authReducer,
    notes: notesReducer,
    ui: uiReducer,
    knowledgeGraph: knowledgeGraphReducer,
    community: communityReducer,
    search: searchReducer,
  },
  middleware: (getDefaultMiddleware) =>
    getDefaultMiddleware({
      serializableCheck: false
    }),
});
```

### 6.2 主要状态切片

- **authSlice.js**: 认证相关状态，包含用户信息、登录状态等
- **notesSlice.js**: 笔记相关状态，包含笔记列表、当前编辑笔记等
- **uiSlice.js**: UI相关状态，包含主题设置、当前屏幕等
- **settingsSlice.js**: 设置相关状态，包含应用设置、用户偏好等
- **aiAssistantSlice.js**: AI助手相关状态，包含聊天历史、AI引擎设置等
- **knowledgeGraphSlice.js**: 知识图谱相关状态，包含节点和关系数据
- **communitySlice.js**: 社区相关状态，包含帖子列表、评论等
- **searchSlice.js**: 搜索相关状态，包含搜索结果、搜索历史等
- **canvasSlice.js**: 画布相关状态，包含画布元素、连接等

# 零屿笔记 (ZeroIsle Notes)

## 项目简介

零屿笔记（ZeroIsle Notes）——AI驱动，从零开始构建您的知识岛屿。

零屿笔记是一款功能强大的AI驱动智能笔记应用，集成了先进的AI助手、思维导图、知识图谱、手写识别、语音转文本等多种功能，旨在帮助用户从零开始构建个人知识体系，打造专属知识岛屿。

## 主要功能

- **智能笔记系统**：支持Markdown、富文本、纯文本等多种格式
- **AI助手**：智能辅助写作、内容总结、问答等功能
- **思维导图**：可视化思维组织工具
- **知识图谱**：构建知识点之间的关联网络
- **手写识别**：将手写内容转换为数字文本
- **语音转文本**：实时将语音转换为文字记录
- **无限画布**：自由绘制和组织内容
- **代码识别**：自动识别和格式化代码片段
- **多模态搜索**：跨文本、图像、音频的内容搜索
- **实时翻译**：笔记内容的多语言翻译
- **社区功能**：笔记分享与协作

## 技术栈

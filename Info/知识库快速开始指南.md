# 零屿笔记 - 知识库快速开始指南

本指南将帮助你快速上手零屿笔记的知识库功能，从零开始构建你的个人知识体系。

## 第一步：理解知识库

### 什么是知识库？

知识库是一个结构化的知识管理系统，它能够：

*   **自动提取**：从你的笔记中自动提取关键概念、实体和关系
*   **智能组织**：将零散的笔记组织成有结构的知识网络
*   **快速检索**：通过智能问答快速找到你需要的知识
*   **发现关联**：自动发现知识点之间的关联，帮助你建立知识体系

### 知识库的类型

*   **个人知识库**：你的私人知识空间
*   **项目知识库**：特定项目的知识集合
*   **团队知识库**：与团队成员共享的知识
*   **公开知识库**：向所有人开放的知识

## 第二步：创建你的第一个知识库

### 方式一：通过 App 界面创建

1.  打开零屿笔记 App
2.  进入"知识库"页面
3.  点击"创建知识库"按钮
4.  填写以下信息：
    *   **名称**：例如"我的学习笔记"
    *   **描述**：简要说明这个知识库的用途
    *   **类型**：选择"个人知识库"
    *   **标签**：添加相关标签，如"学习"、"编程"
5.  点击"创建"

### 方式二：通过 API 创建

```bash
curl -X POST http://localhost:8000/api/knowledge-base/knowledge-bases/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "我的学习笔记",
    "description": "记录日常学习的知识点",
    "type": "personal",
    "tags": ["学习", "编程"],
    "is_public": false
  }'
```

## 第三步：向知识库添加内容

### 方法 1：从现有笔记构建

如果你已经有一些笔记，可以一键将它们转化为知识库：

```bash
curl -X POST http://localhost:8000/api/knowledge-base/knowledge-bases/{kb_id}/build/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "extract_concepts": true
  }'
```

系统会自动：
*   提取每篇笔记中的关键概念
*   识别笔记之间的相似性
*   建立知识点之间的关联
*   创建知识图谱

### 方法 2：导入 Markdown 文件

如果你有外部的 Markdown 文档，可以直接导入：

```bash
curl -X POST http://localhost:8000/api/knowledge-base/knowledge-bases/{kb_id}/import_markdown/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "# Python基础\n\n## 变量\n\n变量是...\n\n## 函数\n\n函数是...",
    "source_name": "Python学习笔记"
  }'
```

系统会：
*   解析 Markdown 的标题结构
*   为每个章节创建知识节点
*   建立章节之间的层级关系
*   提取章节中的关键概念

### 方法 3：创建新笔记时自动添加

当你创建新笔记时，系统会自动：
*   分析笔记内容
*   提取关键信息
*   将其加入你的知识库
*   建立与现有知识的关联

## 第四步：使用知识库

### 1. 智能问答

向你的知识库提问，获得基于已有知识的答案：

```bash
curl -X POST http://localhost:8000/api/knowledge-base/knowledge-bases/{kb_id}/ask/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "Python中的装饰器是什么？",
    "context_limit": 5
  }'
```

**响应示例**：
```json
{
  "success": true,
  "answer": "装饰器是Python中的一种设计模式，它允许你在不修改原函数代码的情况下，为函数添加新的功能...",
  "confidence": 0.85,
  "related_nodes": [
    {
      "id": "...",
      "title": "Python装饰器详解",
      "type": "concept",
      "relevance": 0.92
    }
  ],
  "sources": [
    {
      "title": "Python高级特性",
      "excerpt": "装饰器是一个返回函数的高阶函数..."
    }
  ]
}
```

### 2. 探索知识图谱

通过可视化界面探索你的知识网络：

1.  在 App 中打开知识库
2.  切换到"图谱视图"
3.  你会看到：
    *   **节点**：代表知识点、笔记、概念等
    *   **连线**：代表知识之间的关系
    *   **颜色**：不同类型的节点用不同颜色标识

操作：
*   **点击节点**：查看详细信息
*   **拖动节点**：调整布局
*   **缩放**：查看不同层级的知识
*   **搜索**：快速定位特定知识点

## 第五步：管理知识库

### 创建快照

为知识库创建版本快照，方便回溯：

```python
import requests

response = requests.post(
    f'http://localhost:8000/api/knowledge-base/knowledge-bases/{kb_id}/snapshot/',
    headers={'Authorization': 'Bearer YOUR_TOKEN'},
    json={
        'name': '第一阶段学习成果',
        'description': '完成Python基础学习'
    }
)
```

### 添加团队成员

如果是团队知识库，可以添加成员：

```python
response = requests.post(
    f'http://localhost:8000/api/knowledge-base/knowledge-bases/{kb_id}/members/',
    headers={'Authorization': 'Bearer YOUR_TOKEN'},
    json={
        'user_id': 'member_user_id',
        'role': 'editor'  # viewer, editor, admin
    }
)
```

### 导出知识库

将知识库导出为其他格式（功能规划中）：

*   导出为 PDF
*   导出为思维导图
*   导出为 Markdown 文件集合

## 实用技巧

### 技巧 1：定期构建知识库

建议每周运行一次知识库构建，确保新笔记被及时整合：

```bash
# 设置定时任务
crontab -e

# 添加以下行（每周日晚上执行）
0 22 * * 0 curl -X POST http://localhost:8000/api/knowledge-base/knowledge-bases/{kb_id}/build/ ...
```

### 技巧 2：使用标签组织知识

为知识库添加清晰的标签，方便分类和检索：

*   按学科：`数学`、`编程`、`历史`
*   按难度：`入门`、`进阶`、`高级`
*   按状态：`学习中`、`已掌握`、`待复习`

### 技巧 3：利用问答功能复习

定期向知识库提问，检验学习效果：

```python
questions = [
    "什么是闭包？",
    "如何实现单例模式？",
    "Python的GIL是什么？"
]

for question in questions:
    response = requests.post(
        f'http://localhost:8000/api/knowledge-base/knowledge-bases/{kb_id}/ask/',
        headers={'Authorization': 'Bearer YOUR_TOKEN'},
        json={'question': question}
    )
    print(f"Q: {question}")
    print(f"A: {response.json()['answer']}\n")
```

### 技巧 4：关注知识缺口

定期查看知识缺口分析，有针对性地补充学习：

```python
response = requests.get(
    f'http://localhost:8000/api/knowledge-base/knowledge-bases/{kb_id}/analyze_gaps/',
    headers={'Authorization': 'Bearer YOUR_TOKEN'}
)

gaps = response.json()
print("需要关注的知识点：")
for node in gaps['gaps']['isolated_nodes']:
    print(f"- {node['title']}")
```

## 常见问题

### Q1：知识库构建需要多长时间？

A：取决于笔记数量。通常：
*   10篇笔记：约10秒
*   100篇笔记：约1-2分钟
*   1000篇笔记：约10-15分钟

### Q2：知识库会占用多少存储空间？

A：知识库主要存储节点和关系的元数据，占用空间很小。通常：
*   100个节点：约1MB
*   1000个节点：约10MB

### Q3：可以创建多个知识库吗？

A：可以！你可以为不同的主题或项目创建多个独立的知识库。

### Q4：知识库可以导出吗？

A：目前支持快照功能，完整的导出功能正在开发中。

### Q5：如何提高问答的准确性？

A：
*   确保笔记内容详细、准确
*   定期更新和完善知识库
*   为重要概念添加详细说明
*   建立清晰的知识关联

# 零屿笔记（ZeroIsle Notes）项目文档

## 1. 项目介绍

零屿笔记（ZeroIsle Notes）是一款功能强大的AI驱动智能笔记应用，集成了先进的AI助手、思维导图、知识图谱、手写识别、语音转文本等多种功能，旨在帮助用户从零开始构建个人知识体系，打造专属知识岛屿。

### 1.1 项目口号

AI驱动，从零开始构建您的知识岛屿。

### 1.2 主要功能

- **智能笔记系统**：支持Markdown、富文本、纯文本等多种格式
- **AI助手**：智能辅助写作、内容总结、问答等功能
- **思维导图**：可视化思维组织工具
- **知识图谱**：构建知识点之间的关联网络
- **手写识别**：将手写内容转换为数字文本
- **语音转文本**：实时将语音转换为文字记录
- **无限画布**：自由绘制和组织内容
- **代码识别**：自动识别和格式化代码片段
- **多模态搜索**：跨文本、图像、音频的内容搜索
- **实时翻译**：笔记内容的多语言翻译
- **社区功能**：笔记分享与协作

## 4. 前端文件详解

### 4.1 核心文件

#### App.js

应用主入口，集成了Redux状态管理、主题管理和导航等基础功能。

```javascript
import React from 'react';
import { Provider } from 'react-redux';
import store from './redux/store';
import { ThemeProvider } from './context/ThemeContext';
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import { PaperProvider } from 'react-native-paper';
import AppNavigator from './navigation/AppNavigator';

const App = () => {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <Provider store={store}>
        <ThemeProvider>
          <PaperProvider>
            <AppNavigator />
          </PaperProvider>
        </ThemeProvider>
      </Provider>
    </GestureHandlerRootView>
  );
};

export default App;
```

#### navigation/AppNavigator.js

应用导航配置，根据认证状态决定显示认证导航还是主功能导航。

主要功能：
- 根据认证状态切换导航
- 配置底部标签导航
- 配置各功能模块的堆栈导航
- 监听路由变化，更新当前屏幕

#### redux/store.js

Redux存储配置，集成了各个功能模块的reducer。

```javascript
import { configureStore } from '@reduxjs/toolkit';
import { setupListeners } from '@reduxjs/toolkit/query';

// 导入reducers
import authReducer from './slices/authSlice';
import notesReducer from './slices/notesSlice';
import uiReducer from './slices/uiSlice';
import knowledgeGraphReducer from './slices/knowledgeGraphSlice';
import communityReducer from './slices/communitySlice';
import searchReducer from './slices/searchSlice';

// 配置Redux存储
const store = configureStore({
  reducer: {
    auth: authReducer,
    notes: notesReducer,
    ui: uiReducer,
    knowledgeGraph: knowledgeGraphReducer,
    community: communityReducer,
    search: searchReducer,
  },
  middleware: (getDefaultMiddleware) =>
    getDefaultMiddleware({
      serializableCheck: false
    }),
});
```

首页屏幕，显示笔记列表，支持查看、删除笔记等操作。

```java
public class ZeroIsleNotesPackage implements ReactPackage {

        List<ViewManager> viewManagers = new ArrayList<>();
        // 添加自定义视图管理器
        return viewManagers;
    }

    @Override
    public List<NativeModule> createNativeModules(ReactApplicationContext reactContext) {
        List<NativeModule> modules = new ArrayList<>();
        // 添加原生模块
        modules.add(new ZeroIsleUtilsModule(reactContext));
        modules.add(new FileSystemModule(reactContext));
        modules.add(new HandwritingRecognitionModule(reactContext));
        modules.add(new NotificationModule(reactContext));
        return modules;
    }
}
```

## 8. 技术挑战与解决方案

### 8.1 手写识别准确率

- **挑战**：不同用户的手写风格差异大
- **解决方案**：使用迁移学习和用户个性化模型调整

### 8.2 知识图谱构建

- **挑战**：自动提取知识点和关系
- **解决方案**：结合NLP技术和用户手动调整

### 8.3 离线功能与数据同步

- **挑战**：确保离线编辑的笔记能够正确同步，避免冲突
- **解决方案**：实现版本控制和冲突解决机制

### 8.4 多平台兼容性

- **挑战**：确保在不同设备上的一致体验
- **解决方案**：使用React Native确保跨平台兼容性，针对特定平台进行优化

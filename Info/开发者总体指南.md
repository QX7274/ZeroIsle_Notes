# 零屿笔记开发者总体指南

## 项目概述

零屿笔记（ZeroIsle Notes）是一款功能强大的AI驱动智能笔记应用，集成了先进的AI助手、思维导图、知识图谱、手写识别、语音转文本等多种功能，旨在帮助用户从零开始构建个人知识体系，打造专属知识岛屿。

项目口号：**AI驱动，从零开始构建您的知识岛屿**

## 项目架构

零屿笔记采用前后端分离的架构：

### 前端架构
- **框架**：React Native（跨平台移动应用）
- **状态管理**：Redux Toolkit
- **导航**：React Navigation
- **UI组件**：React Native Paper + 自定义组件
- **网络请求**：Axios

### 后端架构
- **框架**：Django + Django REST Framework
- **数据库**：MongoDB（主数据库，存储笔记内容）
- **图数据库**：Neo4j（用于知识图谱）
- **缓存**：Redis
- **消息队列**：Celery
- **实时通信**：Django Channels

### AI服务
- **手写识别**：百度飞桨OCR模型（中英文识别）
- **语音识别**：OpenAI Whisper
- **自然语言处理**：Hugging Face Transformers
- **知识图谱**：自研算法 + Neo4j

## 核心功能模块

### 1. 笔记系统
- 支持多种格式：Markdown、富文本、纯文本
- 笔记分类与标签管理
- 版本历史与回滚
- 附件管理（图片、文档等）

### 2. 手写识别
- 实时识别用户手写内容
- 支持多种书写风格和语言
- 手写校正和优化
- 在PDF、Word等文档上进行手写标记并识别

### 3. 知识图谱
- 自动分析笔记内容间的关联性
- 构建可视化知识网络
- 提供知识点关联推荐
- 知识结构分析

### 4. 语音功能
- 语音检索：通过语音命令查找笔记内容
- 语音提醒：设置重要事项的语音提醒
- 语音输入：支持语音转文字记录
- 会议录音转文字：自动生成会议纪要

### 5. 社区功能
- 笔记内容选择性分享
- 下载、收藏、点赞、评论等社交互动
- 用户关注与推荐机制

### 6. 思维导图
- 自动根据笔记内容生成思维导图
- 手动创建和编辑思维导图
- 思维导图与笔记内容的双向关联

### 7. 提醒系统
- 创建待办事项和任务清单
- 设置日程提醒和截止日期
- 任务优先级管理和进度跟踪

### 8. 用户认证
- 手机验证码登录
- 密码登录
- 微信、QQ第三方绑定登录

## 技术栈详解

### 前端技术栈
- **React Native**：跨平台移动应用开发框架
- **Redux Toolkit**：状态管理库
- **React Navigation**：导航库
- **React Native Paper**：UI组件库
- **Axios**：HTTP客户端
- **React Native Gesture Handler**：手势处理
- **React Native Reanimated**：动画库
- **React Native SVG**：SVG支持
- **React Native Camera**：相机功能
- **React Native FS**：文件系统操作
- **React Native Audio Recorder Player**：音频录制和播放

### 后端技术栈
- **Django**：Web框架
- **Django REST Framework**：RESTful API框架
- **Django Channels**：WebSocket支持
- **Djongo**：MongoDB连接器
- **PyMongo**：MongoDB Python驱动
- **Celery**：分布式任务队列
- **Redis**：缓存和消息代理
- **JWT**：身份验证
- **PaddleOCR**：手写识别
- **Whisper**：语音识别
- **Transformers**：自然语言处理
- **Py2Neo**：Neo4j Python驱动

## 开发环境搭建

### 前端环境
1. 安装Node.js（>=18.0.0）
2. 安装Yarn包管理器
3. 安装React Native CLI
4. 安装Android Studio（Android开发）
5. 安装Xcode（iOS开发，仅macOS）
6. 克隆项目并安装依赖：
   ```bash
   git clone <项目仓库URL>
   cd ZeroIsle_Notes
   yarn install-deps-yarn  # 使用国内镜像源安装依赖
   ```

### 后端环境
1. 安装Python（>=3.8）
2. 安装MongoDB
3. 安装Redis
4. 安装Neo4j（可选，用于知识图谱）
5. 安装后端依赖：
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

## 运行项目

### 运行前端
```bash
# 启动Metro服务器
yarn start

# 运行Android应用
yarn android

# 运行iOS应用（仅macOS）
yarn ios
```

### 运行后端
```bash
# 启动Django服务器
cd backend
python manage.py runserver

# 启动Celery工作进程
celery -A backend worker -l info

# 启动Redis（如果未作为服务运行）
redis-server
```

## 开发流程

### 代码规范
- 使用ESLint和Prettier进行代码格式化
- 遵循PEP 8 Python代码规范

### 版本控制
- 使用Git进行版本控制

- 后端部署到云服务器或容器平台
- 使用CI/CD自动化构建和部署

## 常见问题解决

### 依赖安装问题

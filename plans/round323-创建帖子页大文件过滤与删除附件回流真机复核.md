# round323 - 创建帖子页大文件过滤与删除附件回流真机复核

## 1. 本轮目标
- 在安卓平板真机上继续验证 `社区 -> 创建帖子` 页附件能力的剩余链路。
- 实测超过 `10MB` 文件过滤提示是否仍走项目内统一弹窗，而不是原生安卓弹窗。
- 实测删除已选附件后的回流是否正常，确认页面仍停留在 `创建帖子` 且附件区回到无附件状态。
- 仅在存在真实故障时做最小修复；若链路正常，则只更新文档，不扩大代码改动面。

## 2. 真机环境
- 设备：`HGR3Y9MA`
- 页面：`CreatePostScreen`
- 日期：`2026-06-07`

## 3. 实测路径
1. 延续 `round322` 已选中小文件 `高质量C++编程指南.pdf` 的现场，停留在 `创建帖子` 页。
2. 点击 `添加附件`，再次拉起系统文件选择器。
3. 选择大文件 `B14.pptx`（`35.71 MB`），确认页面回流后是否出现项目内统一弹窗。
4. 关闭弹窗，确认原有小附件仍保留，页面仍停留在 `创建帖子`。
5. 点击已选附件右侧删除按钮，确认附件区是否回到无附件状态，且页面不离开 `创建帖子`。

## 5. 现场结论
- 选择大文件 `B14.pptx` 后，页面会回到 `创建帖子`，并弹出项目内统一样式提示：
  - 标题：`部分文件未添加`
  - 正文：`超过 10MB 的文件已被自动过滤。`
- 该提示不是原生安卓弹窗，符合当前“网络/失败/异常反馈统一使用项目内优美弹窗”的约束。
- 关闭弹窗后，原有附件 `高质量C++编程指南.pdf` 仍保留，说明“大文件被过滤”不会破坏已选小文件状态。
- 点击删除按钮后，附件区已回到无附件态：
  - 不再出现 `附件（1）`
  - 不再出现 `高质量C++编程指南.pdf`
  - 不再出现 `action.community.removeAttachment.0`
  - 页面仍停留在 `创建帖子`
- 证据 XML 还可见底部 `Cannot connect to Metro` 调试提示条；该提示属于 React Native 开发环境与 Metro 连通性提示，不属于本轮社区业务附件链故障，也不是面向生产用户的业务弹窗。

## 6. 代码变更结论
- 本轮不做代码修改。
- 原因：
  - 大文件过滤提示链正常；
  - 删除附件回流链正常；
  - 当前没有新的真实业务故障值得冒险改动代码。

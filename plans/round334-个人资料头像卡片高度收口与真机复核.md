# round334 个人资料头像卡片高度收口与真机复核

## 本轮目标
- 延续 `round333` 之后对 `个人资料` 页的平板真机复核，继续收掉仍显原始的局部区域。
- 仅处理头像卡片在平板大屏上高度偏大、内部内容过少导致的空板感。
- 保持顶部安全区、淡蓝色方形返回按钮、功能中心卡片体系、资料表单区和整体视觉语言不被破坏。

## 问题背景
- `round333` 已经把“功能中心”六张功能卡的内部留白有效收紧。
- 但继续在真机平板上观察 `个人资料` 页时，头像区仍存在明显原始观感：
  - 头像卡片被拉得过高；
  - 中间只有头像和“更换头像”按钮一小段内容；
  - 卡片上下出现大块空白，像一整张被掏空的白板。
- 该问题不属于导航、配色或安全区故障，而是单纯的大屏纵向密度失衡，因此本轮继续坚持“只改明显原始部分，不动成熟部分”。

## 实施范围
- 修改文件：
  - `src/screens/settings/ProfileSettings.js`
- 不改动内容：
  - 顶部标题卡片；
  - 淡蓝色方形返回按钮；
  - 用户名与个人简介表单区；
  - `功能中心` 六张多色入口卡片；
  - 底部 `保存资料 / 应用设置` 操作区；
  - 项目内统一提示风格。

## 代码调整
- 收紧头像卡片自身上下内边距：
  - `avatarContainer.padding`
    - 从统一 `16`
    - 调整为 `paddingHorizontal: 16`
    - `paddingTop: 12`
    - `paddingBottom: 14`
- 略收头像尺寸，降低大屏上的视觉空耗：
  - `avatar.width/height`：`120 -> 104`
  - `avatar.borderRadius`：`60 -> 52`
- 收紧“更换头像”按钮的节奏：
  - `avatarActionBtn.marginTop`：`14 -> 10`
  - `avatarActionBtn.minHeight`：`38 -> 34`
  - `avatarActionBtn.paddingHorizontal`：`14 -> 12`

- 本轮继续符合以下既有要求：
  - 只改明显原始的 UI，不动成熟部分；

# round333 个人资料功能中心卡片留白收紧与真机复核

## 本轮目标
- 延续 `round332` 之后的真机平板复核，继续处理“我的 -> 个人资料 -> 功能中心”在大屏上仍显原始的问题。
- 在不破坏既有成熟区域的前提下，只收口功能中心卡片内部明显不合理的留白。
- 保持顶部安全区、统一淡蓝色方形返回按钮、既有配色体系与项目内统一反馈风格不被破坏。

## 问题背景
- 真机进入 `个人资料` 页后，顶部安全区、头像区、表单区和返回按钮体系整体已经稳定。
- 但底部“功能中心”六张入口卡片在平板大屏上仍存在明显的内部空壳感：
  - 每张卡片纵向高度偏大；
  - 图标、标题、说明与右箭头之间距离过松；
  - 六张卡片叠加后，整个功能区被拉得过长，视觉上像“有边框但内容没装满”。
- 该问题属于典型的大屏节奏失衡，而不是配色、导航或安全区故障，因此本轮不动成熟部分，只对卡片内部节奏做最小收口。

## 实施范围
- 修改文件：
  - `src/screens/settings/ProfileSettings.js`
- 不改动内容：
  - 顶部标题区；
  - 头像卡片与资料编辑表单；
  - 淡蓝色方形返回按钮样式；
  - 功能中心既有多色卡片体系；
  - 页面整体安全区结构与底部操作区。

## 代码调整
- 收紧功能中心标题区与网格区之间的垂直节奏：
  - `sectionHead.marginBottom`：`10 -> 8`
  - `grid.marginTop`：`10 -> 6`
- 收紧功能卡主体高度与底部占位：
  - `itemBtn.paddingVertical`：`14 -> 12`
  - `itemBtn.marginBottom`：`12 -> 10`
  - `itemBtn.minHeight`：`106 -> 84`
  - `itemBtn.justifyContent`：`space-between -> flex-start`
- 收紧图标容器体积，避免首屏卡片视觉重心过散：
  - `itemIconWrap.width/height`：`38 -> 34`
  - `itemIconWrap.borderRadius`：`12 -> 11`
  - 移除图标容器额外底部留白，避免图标行和文案行被重复拉开
- 收紧卡片内部结构节奏：
  - `itemAccentBar.marginBottom`：`10 -> 8`
  - `itemTopRow.marginBottom`：`10 -> 8`
  - `itemTopRow` 新增 `width: '100%'`
  - `itemTextWrap` 新增 `width: '100%'`
  - `itemTitle.marginBottom`：`6 -> 4`
  - `itemHint.lineHeight`：`17 -> 16`

## 与既有规范的关系
- 本轮继续遵守以下既有约束：
  - 只改明显原始、留白失衡的区域，不动已成熟部分；

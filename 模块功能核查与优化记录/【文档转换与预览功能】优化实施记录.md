# 【文档转换与预览功能】优化实施记录

## 1. 优化状态
- 状态：✅ 已实施 P0 改造（安全、权限、异步、用户绑定、短时下载令牌、页数统计、健康检查）
- 完成日期：2025-11-20
- 主要贡献者：AI Assistant (Cascade)

## 2. 本次改动范围（P0）

### 2.1 安全与权限
- 取消公开与 csrf_exempt 的端点访问，统一要求登录鉴权：
  - 上传转换（DocumentConverterView.post）
  - 下载文件（download_converted_pdf）
  - 进度查询（convert_progress）
  - Base64 转换（Base64ConvertView.post）
  - 清理临时文件（cleanup_temp_files，且需 is_staff）
- 上传安全校验：
  - 文件大小上限（默认 20MB，可通过环境变量 DOC_CONVERTER_MAX_UPLOAD_MB）
  - 扩展名白名单：.doc/.docx/.ppt/.pptx
  - 优先使用 python-magic 识别 MIME（回退使用 Content-Type）并与扩展名映射校验
  - 使用隔离目录 + UUID 随机安全文件名保存临时文件，防路径穿越/覆盖
- 下载保护：
  - 文件名正则校验（仅允许 [A-Za-z0-9_.-]+.pdf）
  - 仅文件所有者或管理员可访问
  - 新增短时下载令牌（token）机制，支持安全、有时限的分享

### 2.2 异步与进度
- 引入 Celery 异步任务（backend/document_converter/tasks.py：convert_document_task）
  - 前端上传成功后默认返回 202 + task_id，后台异步转换
  - 任务进度/结果写入 cache（key: docconv:<task_id>，TTL 1h）
  - 新增按 task_id 查询端点：GET /status/<task_id>/（受鉴权，且仅限任务所有者或管理员）
- 同步模式保留用于调试（表单/查询参数 async=false），建议生产默认异步

### 2.3 输出策略与内联阈值
- 默认不返回大文件的内联 Base64，新增内联阈值（默认 2MB，环境变量 DOC_CONVERTER_MAX_INLINE_MB）
- 始终返回受保护下载 URL 与路径

### 2.4 转换质量与准确性
- 使用 PyPDF2 统计 PDF 页数（替换原先固定返回 1 的实现）

### 2.5 健康检查
- 健康检查返回动态时间戳与依赖可用性（mammoth、weasyprint）以及临时目录可写检测

## 3. 端点变化与示例
- POST /document-converter/convert/
  - 入参：multipart/form-data（file），可选 async=false
  - 出参（默认异步）：202 { success, task_id, status_url }
- GET /document-converter/status/<task_id>/
  - 出参：{ success, data: { status, progress, message, user_id, pdf_url(完成后)… } }
- POST /document-converter/download-token/
  - Body: { "filename": "..." }
  - 出参：{ success, token, expires_in, download_url }
- GET /document-converter/download/<filename>/（受鉴权，文件名正则校验）
- POST /document-converter/convert/base64/
  - 入参：{ file_data(base64), file_extension, filename? }
  - 校验 base64 合法与大小限制
